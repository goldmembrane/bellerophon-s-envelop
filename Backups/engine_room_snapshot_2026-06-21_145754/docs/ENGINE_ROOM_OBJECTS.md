## 샘플 제작 전에 확정이 필요한 항목

- ER-07의 실제 위/아래/옆 통로 연결은 복도 작업 때 현재 선박 모델 좌표와 맞춰 확정합니다.
- ER-02~ER-06은 ER-01 작업 때 함께 처리한 상태로 보고, 추후 Unity에서 세부 조정이 필요하면 별도 승인 범위로 다룹니다.
- ER-15 손전등 충전 앵커는 대형 스크린 왼쪽 보조 스크린보다 더 왼쪽으로 떨어진 동력실 내부 곡면 벽면에 세로 충전 홈으로 배치하는 방향으로 확정했습니다. 상태등과 안내 표식은 넣지 않고, 충전 중 전기 이펙트는 추후 별도 구현합니다.
- ER-16은 별도 모델링 없이 아타의 동력실 내 준비동작 완료 시 사보타주가 발생하는 로직으로 처리합니다.
- ER-17은 별도 모델링 없이 현재 구현된 ER-09 스크린 상호작용으로 사보타주 해제를 처리합니다.
