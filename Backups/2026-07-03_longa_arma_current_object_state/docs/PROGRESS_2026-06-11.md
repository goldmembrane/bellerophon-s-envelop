## 3단계 사용자 피드백 대응

사용자가 Play view에서 확인한 문제:

- 막대기 모델이 무기처럼 보이지 않고 끝이 둥글게 읽힌다.
- 화물창 오브젝트 일부가 공중에 떠 있어 어색하다.
- 기존 MVP에서 베이지색 화물/화물 상태 오브젝트와 상호작용하도록 짜인 부분이 있는데, 3단계 오브젝트가 그 상호작용 대상과 자연스럽게 연결되어야 한다.

수정 내용:

- `Stage 3 First Person Crowbar Model`의 연속 메시를 다시 조정했다.
  - 하단 pry tip을 더 길고 작게 taper 처리해서 날카로운 무기형 실루엣으로 바꿨다.
  - 상단 hook 끝도 더 작게 taper 처리했다.
  - 1인칭 화면에서 너무 낮게 내려가지 않도록 `Player Camera` 하위 local position을 조정했다.
- 화물창 `Stage 3 Cargo Hold Status Panel`을 기존 `Interactable - Cargo Hold Cargo Status` 앞면에 붙였다.
  - panel frame, load screen, secure/overload indicator, left/right clamp, lower cable brace를 기존 상호작용 블록과 연결되게 재배치했다.
- `Stage 3 Contract Cargo Container Body`를 기존 `Cargo Hold Central Cargo` 위치와 크기에 맞춰 정렬했다.
  - 3단계 계약 화물이 기존 베이지색 중앙 화물 블록의 fitted upgrade처럼 읽히도록 했다.
- `Stage 3 Personal Cargo Container Body`와 `Stage 3 Diegetic Terminal Shell Pedestal`은 화물창 deck y=-3 기준에 닿도록 내렸다.
- 화물 경고 라벨 위치를 계약 화물 전면에 맞춰 다시 배치했다.
