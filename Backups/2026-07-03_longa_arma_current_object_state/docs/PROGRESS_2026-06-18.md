## ER-09 사용자 편집값 스크립트 반영

- 사용자가 Unity 에디터에서 `Approved Engine Room 09 Health Screen`을 직접 편집했다.
- 요청에 따라 현재 열린 씬의 ER-09 Transform 값을 캡처했다.
- 캡처 명령:
  - `CaptureApprovedEngineRoomHealthScreenCurrentObjects`
- 캡처 기록:
  - `artSample/engine_room_health_screen/editor_current/er09_current_objects.md`
- 반영 파일:
  - `Assets/_Project/Editor/Validation/ApprovedEngineRoomHealthScreenBootstrap.cs`
  - `Assets/_Project/Editor/Validation/UnityEditorValidationBridge.cs`
- 반영 방식:
  - `UserEditedRootTransformOverride`와 `UserEditedTransformOverrides`에 현재 `position`, `localPosition`, `localRotation`, `localScale` 값을 저장했다.
  - 같은 이름의 하위 오브젝트가 여러 개 있는 경우를 구분하기 위해 캡처 경로에 sibling index suffix를 붙이도록 했다. 예: `ER-09 asset screen corner bolt#0`.
  - 다음 생성 때 현재 snapshot 밖 오브젝트가 다시 살아나지 않도록 snapshot 밖 오브젝트 제거 로직을 추가했다.
- 추가 실행한 명령:
  - `.\scripts\Refresh-UnityProject.ps1`
  - `.\scripts\Invoke-UnityEditorBridge.ps1 -Command "CaptureApprovedEngineRoomHealthScreenCurrentObjects" ...`
- 실행하지 않은 것:
  - `Run-ApprovedEngineRoomHealthScreen.ps1`
  - `EnsureApprovedEngineRoomHealthScreen`
  - ER-09 재생성 또는 재배치
  - 조종실, ER-01, ER-02, ER-10 수정

## ER-09 보조 스크린 텍스처 교체

- 사용자가 가운데 메인 화면은 유지하고, 왼쪽 보조 스크린과 오른쪽 보조 스크린의 화면 텍스처만 교체하라고 요청했다.
- 반영 파일:
  - `Assets/_Project/Editor/Validation/ApprovedEngineRoomHealthScreenBootstrap.cs`
  - `Assets/_Project/Scenes/CargoRunMvp.unity`
- 변경 내용:
  - 가운데 메인 스크린은 기존 `B2_Eq41_E.png`를 유지했다.
  - 보이는 기준 왼쪽 보조 스크린은 `Assets/Heavy Station Kit/BASE/Textures/Displays/B2_Eq52_E.png`로 바꿨다.
  - 보이는 기준 오른쪽 보조 스크린은 `Assets/Heavy Station Kit/BASE/Textures/Displays/B2_Eq_23c.png`로 바꿨다.
  - `B2_Eq52_E.png`는 4열 x 3행 atlas이므로 좌상단 단일 타일 UV `(0, 2/3) ~ (1/4, 1)`만 사용했다.
  - `B2_Eq_23c.png`는 2열 x 2행 atlas이므로 좌상단 단일 타일 UV `(0, 0.5) ~ (0.5, 1)`만 사용했다.
  - 기존 사용자 편집 Transform override는 유지했다.
- 실행한 명령:
  - `.\scripts\Refresh-UnityProject.ps1`
  - `.\scripts\Run-ApprovedEngineRoomHealthScreen.ps1`
- 확인:
  - `artSample/engine_room_health_screen/unity_applied_comparison/side_by_side_01_front.png`에서 보이는 왼쪽/오른쪽 보조 스크린의 텍스처 교체를 확인했다.
  - `Logs/ApprovedEngineRoomHealthScreen.log`와 `Logs/RefreshUnityProject.log`에 컴파일/브리지 에러는 기록되지 않았다.
- 실행하지 않은 것:
  - 조종실, ER-01, ER-02, ER-10 수정
  - `Run-HarnessValidation`, `Run-EditModeTests`, `Run-PlayModeTests`, `Build-WindowsDev`
