# 0001 - Unity 6.3 LTS와 하네스 우선 구조

## 상태

Accepted

## 결정

Bellerophon은 Unity `6000.3.x LTS` 계열을 기준으로 개발한다. 현재 대상 프로젝트의 에디터는 `6000.3.16f1`이며, 패치 업데이트는 같은 `6000.3.x` 범위 안에서만 수행한다.

게임 기능 개발 전에 다음 하네스 요소를 먼저 둔다.

- 에이전트 작업 규칙
- Unity용 Git/Git LFS 설정
- Runtime/Editor/Tests 어셈블리 경계
- 커맨드라인 검증 스크립트
- 최소 EditMode/PlayMode 테스트

## 이유

Steam 출시를 목표로 하는 게임은 프로젝트 후반에 빌드, 테스트, 패키징, 플랫폼 SDK 문제가 누적되기 쉽다. 초기에 반복 가능한 검증 루프를 만들면 기능 추가와 AI 보조 개발의 리스크를 줄일 수 있다.

## 결과

- 새 기능은 검증 경로를 함께 가져야 한다.
- 프로젝트 구조 변경은 `docs/ARCHITECTURE.md`와 `docs/HARNESS.md`를 함께 갱신해야 한다.
- Unity 패치 업데이트는 `6000.3.x` 범위 안에서만 수행한다.
