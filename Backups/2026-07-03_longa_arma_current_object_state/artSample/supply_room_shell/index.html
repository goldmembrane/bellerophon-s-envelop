SR-07 HSK Open/Close 단말기 화면 요약

이번 변경은 사출대 오른쪽 단말기 화면에 Heavy Station Kit의 `HSK_Open_Close.png` GUI 이미지를 실제 화면 텍스처처럼 보이도록 얹은 샘플입니다. 기존 단말기 외형은 유지하고 화면 앞면의 표시만 교체했습니다.

포함

  • SR-07 사출대 단말기 화면 텍스처 평면
  • `HSK_Open_Close.png` 이미지 기반 Open/Close 표시
  • 기존 단말기 프레임과 버튼 구조 유지
  • 10번 근접 렌더 추가

제외

  • Unity 씬, 프리팹, 런타임 자산 반영
  • 사출대 개폐 상호작용 로직
  • 사출 판정과 쿨타임 로직
  • 비품실 기존 오브젝트 수정

승인 후 적용 범위

  • `Approved Supply Room 01 Shell` 하위 SR-07 화면만 수정
  • 사출대 단말기 위치와 각도는 유지
  • 비품실 다른 오브젝트는 수정 제외
  • 시각 기준은 10번 샘플 렌더와의 일치도
