Longa Arma 런타임 저폴리 샘플

기존 Longa Arma 고밀도 모델의 말형 머리, 네 다리 짐승 실루엣, 왼팔 칼날, 젖은 녹청색 몸체와 어두운 칼날 인상을 유지하면서 화물선 내부 다수 배치를 고려해 메시 밀도를 낮춘 검토용 샘플입니다. Unity 씬이나 런타임 프리팹에는 아직 연결하지 않았습니다.
