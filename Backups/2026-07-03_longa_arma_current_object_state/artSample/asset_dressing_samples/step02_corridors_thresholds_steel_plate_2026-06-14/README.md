# 2단계 복도 내부 철판 덮개 시안

이 폴더는 현재 프로젝트에 가져온 에셋 중 철판처럼 보이는 부품을 골라, 화물선 복도 내부를 덮는 방향을 검토하기 위한 시안입니다. 기존 낡은 시안은 이번 승인 기준에서 제외합니다.

아직 실제 유니티 게임 씬, 프리팹, 런타임 자산에는 적용하지 않았습니다. 사용자가 이 시안을 보고 승인한 뒤에만 실제 화물선 내부에 반영합니다.

## 적용 방향

- 복도의 전체 길이와 통과 폭은 유지합니다.
- `Heavy Station Kit`의 철판형 바닥 부품을 바닥, 좌우 벽, 천장 안쪽 표면에 반복 배치했습니다.
- 기존 복도 프레임은 뼈대로 남기되, 안쪽 빈 공간과 투명해 보이던 표면은 철판 덮개가 먼저 보이도록 했습니다.
- 철판 사이에는 얇은 어두운 이음매를 넣어 단일 덩어리처럼 보이지 않게 했습니다.
- 입구는 막힌 벽처럼 보이지 않도록 좌우 기둥과 상단 보강재 중심으로만 구성했습니다.
- 이번 시안은 “낡음”보다 “내부가 철판으로 덮인 화물선 복도” 느낌을 우선 확인하기 위한 버전입니다.

## 검토할 부분

- 복도 내부가 빈 껍데기처럼 보이지 않는지
- 바닥, 좌우 벽, 천장이 철판으로 덮인 느낌을 주는지
- 통로 폭과 시야가 답답하게 막히지 않는지
- 입구에 통과 불가능해 보이는 막힌 벽이 생기지 않았는지
- 철판 반복 배치가 너무 규칙적이거나 장난감처럼 보이지 않는지

## 승인 상태

현재 상태는 미승인입니다. 승인 전에는 실제 게임 씬에 반영하지 않습니다.
