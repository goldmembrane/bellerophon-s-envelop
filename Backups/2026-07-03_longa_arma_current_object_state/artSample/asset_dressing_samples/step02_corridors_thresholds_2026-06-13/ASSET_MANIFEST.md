| 역할 | 에셋 경로 | 사용 방식 |
| --- | --- | --- |
| 직선 복도 기본 골격 | `Assets/Sci-Fi Styled Modular Pack/Prefabs/Corridors/Corridor_I.prefab` | 반복 배치하여 플레이어가 지나가는 주 복도 형태를 만듭니다. |

| 벽 조명 | `Assets/Heavy Station Kit/BASE/Prefabs/Walls/Wall Lights/Wall Lights On.prefab` | 방향 인지와 분위기 보강용 조명 장식으로 사용합니다. |

| 천장 조명 | `Assets/Sci-Fi Styled Modular Pack/Prefabs/Lights/light_celing_1.prefab` | 반복 조명 리듬과 천장 깊이를 보강합니다. |
| 바닥 연결부 | `Assets/Sci-Fi Styled Modular Pack/Prefabs/Joints/Joint_X_6.prefab` | 꺾임 구간의 바닥 이음새 후보로 사용합니다. |

## 이번 시안에서 제외한 방향

- 입구 중앙을 막는 큰 문판
- 통과 가능한 벽처럼 보이는 장식 덩어리
- 벽이 뚫려 보이는 장식 벽을 주 벽면으로 쓰는 방식
- 큰 막힌 패널이 중앙에 보이는 코너 복도 프리팹
- 사무실용 가구나 단말기처럼 복도 껍데기와 직접 맞지 않는 소품
- 실제 게임 씬의 기존 복도 구조를 바꾸는 작업

## 머티리얼 처리

임포트된 원본 머티리얼이 분홍 오류 색으로 보일 수 있어, 시안 렌더에서는 프로젝트 내부의 배 재질을 임시로 입혔습니다. 이 처리는 에셋의 형태와 배치 방향을 검토하기 위한 것이며, 승인 뒤 실제 적용 단계에서 다시 조정합니다.
