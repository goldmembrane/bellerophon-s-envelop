## 직접 확인 결과

- 문제 구간은 약 2.35~2.85초이다. 오른쪽 상완이 몸 바깥에서 수평에 가깝게 놓이고 전완이 아래로 굽을 때, 오른쪽 가슴과 겨드랑이 사이 메시가 팔을 따라 앞·위쪽으로 넓게 끌려 나왔다.
- 원인은 `Hands_Draw_Back` 전용 메시의 오른쪽 가슴 정점에 남아 있던 `RightArm`·`RightShoulder` 영향이다. 팔이 올라가는 자세에서 이 혼합 가중치가 몸통이어야 할 면을 함께 이동시켰다.
- 공용 `player.fbx`는 수정하지 않고 `Hands_Draw_Back_ChestCorrected.asset`에서만 해당 영향 일부를 상부 `Spine`으로 옮겼다. 경계에는 감쇠를 적용해 어깨 접합부를 유지했다.
- `video_pose_stress_comparison.png`의 1행은 원본 메시 전면, 2행은 보정 메시 전면, 3행은 원본 메시 측면, 4행은 보정 메시 측면이다. 1행의 가슴–겨드랑이 돌출 띠와 3행의 전방 돌출이 2·4행에서 제거되며, 어깨 찢김·구멍·새 돌출은 보이지 않는다.
- 검증 포즈는 지정 영상의 문제 자세와 같은 부위·전면 및 측면·확대 수준으로 고정하고, 원본/보정 메시를 동일한 본 행렬로 CPU Bake해 비교했다. 이 포즈는 검증 중에만 사용했고 애니메이션 또는 씬에 기록하지 않았다.
