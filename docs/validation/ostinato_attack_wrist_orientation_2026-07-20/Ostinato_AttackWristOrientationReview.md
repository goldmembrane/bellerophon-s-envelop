# 오스티나토 공격 내려찍기 이후 칼날 각도 교정 결과

## 적용 결과

- 대상: `Approved Ostinato Enemy Placement/Ostinato_04_Scissor_Attack`
- 원본 유지: Unity `0~77프레임` (`60fps`)
- 수평 유지: `78~93프레임`
- 원형 복귀: `94~99프레임`
- 방향 기준: `83프레임`에서 날 부분이 몸 안쪽을 향하는 방향을 유지하며 칼날 장축을 지면과 평행하게 투영

내려찍기 전에는 아무 보정도 적용하지 않았다. 내려찍기 이후에만 프레임별 연결형 BlendShape로 칼날 형상을 수평 방향으로 바꿨으며, 기존 손목·전완·신체 애니메이션 커브는 수정하지 않았다.

## 이전 분리 문제와 현재 방식

사용자 캡처에서 이전 제어 본 방식이 칼날을 손목과 분리한 상태를 확인했다. 해당 상태는 폐기하고 다음 조건으로 다시 구성했다.

- `LeftBladeControl`·`RightBladeControl`: 제거
- 칼날 버텍스 재가중: `0개`
- 칼날/손목 경계 버텍스 분리: `0개`
- 원본 토폴로지·인덱스·본 가중치·바인드 포즈: 유지
- 칼날과 신체가 공유하는 연결 경계: `82개` 유지
- 프레임별 BlendShape: 좌 16개 + 우 16개
- 기존 `Hand`·`ForeArm` 회전 편차: `0도`

연결 경계는 이동시키지 않고 칼날 쪽 버텍스에만 거리에 따른 보정을 적용했다. 따라서 칼날 뿌리가 손목에서 떨어지지 않으며 손목 본에도 별도 회전을 가하지 않는다.

## 수치 및 직접 확인

- `0~77프레임` 원본/교정본 최대 버텍스 편차: `0`
- `78~93프레임` 칼날 장축 수평 최대 오차: `0.120301도`
- `78~93프레임` 최대 버텍스 편차: `0.977869`
- 교정 구간 최대 바운드 비율: `1.183301`
- 정확 프레임 대조: `50, 61, 67, 77, 78, 83, 93, 94, 99`

정면·3/4 비교에서 `77프레임`까지 원본과 동일하고, `78프레임`부터 칼날만 수평으로 바뀐다. `83·93프레임`에서는 수평 상태와 손목 연결을 유지하며, `94~99프레임`에서 원래 형상으로 복귀한다. 패널 순서는 `원본 정면 | 교정본 정면 | 원본 3/4 | 교정본 3/4`이다.
