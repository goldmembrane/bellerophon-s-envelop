## 2. 분석 대상 정의

원본에는 큰 칼날 두 개와 작은 보조 칼날이 함께 보인다. 이번 분석은 큰 칼날 두 개만 추적한다.

- `ReferenceBladeA`: 1프레임에서 화면 왼쪽 위에 있는 큰 칼날
- `ReferenceBladeB`: 1프레임에서 몸 아래쪽에 있는 큰 칼날

`A/B`는 화면상 추적 이름일 뿐 오스티나토의 `LeftArm/RightArm`을 뜻하지 않는다. 원본은 단일 3/4 카메라이므로 숨은 깊이와 생물의 해부학적 좌우를 화면 좌우만으로 확정하지 않는다. 오스티나토에 대입할 때는 기준 카메라에서 두 팔을 투영한 뒤 `A/B`와 대응시켜 한 번 정한 채널을 전 구간 유지한다.

## 5. 오스티나토 양팔 적용 방식

### 5.1 리그와 파일 기준

- 별도 모델·리그·Blender 프로젝트를 만들지 않는다.
- 새 모션은 현 공격 Blend가 아니라 승인 모델 원본 `artSample/enemies/ostinato/blender/Ostinato_CurrentModel_TexturedSample.blend`에서 시작한다.
- 기존 공격 Action과 생성 방식은 제거하고 새 Action을 빈 상태에서 만든다.
- 두 팔은 각각 `Shoulder → Arm → ForeArm → Hand` 계층을 그대로 사용한다.

### 5.2 A/B 채널 대응

1. 원본과 같은 상단 3/4 기준 카메라를 만든다.
2. 오스티나토 기본 자세에서 어느 해부학적 팔이 화면의 `ReferenceBladeA` 위치에 대응하고 어느 팔이 `ReferenceBladeB`에 대응하는지 투영 결과로 확정한다.
3. 화면 왼쪽을 곧바로 `LeftArm`으로 간주하지 않는다.
4. 확정된 A/B 대응은 F01~F15 사이에 바꾸지 않는다.

### 5.3 관절 구동

- 상완과 전완에 동일한 월드 회전을 직접 덮어쓰지 않는다.
- 각 팔에 독립적인 2본 IK 목표와 Pole 목표를 사용해 손/칼날 뿌리의 경로를 만든다.
- Pole은 승인 기본 자세에서 계산한 팔꿈치 굽힘 쪽과 같은 반공간에 둔다.
- IK로 15개 기준 자세를 만든 뒤 FK 키로 베이크한다. 내보내기에는 보조 IK 오브젝트를 포함하지 않는다.
- 손목만 따로 돌려 칼날 방향을 맞추지 않는다. 칼날 면 회전은 어깨·상완·전완 체인의 정상적인 축 회전으로 분산하고 `Hand`는 기본 로컬 회전을 유지한다.

### 5.4 역관절 방지 절대 조건

승인 리그의 기본 팔꿈치 내부각은 왼팔 약 89.46도, 오른팔 약 83.22도다. 기본 Pole 방향은 다음과 같다.

- 왼팔 기본 Pole: `(0.689905, 0.218110, -0.690260)`
- 오른팔 기본 Pole: `(-0.649203, 0.129019, -0.749592)`

구현 시 다음 조건을 모두 지킨다.

1. 현재 팔꿈치 Pole과 기본 Pole을 가슴/어깨 로컬 공간에서 비교했을 때 내적이 항상 `0`보다 커야 한다.
2. 팔꿈치 내부각은 기본/복귀에서 승인 자세를 유지하고, 공격 F05~F13에서는 135~170도 범위의 거의 편 팔을 사용한다.
3. 내부각이 175도 이상인 완전 신전 특이점에 들어가지 않는다.
4. 팔꿈치가 어깨-손 선의 반대편으로 넘어가는 키를 허용하지 않는다.
5. 상완이나 팔꿈치가 몸의 반대편을 횡단하지 않는다. 화면상 교차는 곡선형 칼날 부분에서만 만든다.
6. 보간된 전 프레임에서도 Pole 부호와 팔꿈치 각도를 확인한다. 기준 키만 정상이고 중간 프레임이 뒤집히는 경우도 불합격이다.

### 5.5 칼날 방향

- F03~F04에서 두 팔은 서로 다른 높이와 깊이로 장전한다.
- F05~F08에서 칼날 면은 세로로 세우지 않고 수평에 가까운 절단면을 유지한다.
- F08에서 양쪽 갈고리의 안쪽 날이 목표 영역을 향하며 실루엣이 겹친다.
- F09~F13은 팔을 갑자기 다시 벌리는 동작이 아니라, 곡선형 칼날 사이의 포획 영역이 몸 가까이 이동하는 압축 후속 동작으로 만든다.
- 칼날의 곡률과 면 방향은 렌더에서 확인하며 뼈 회전 수치만으로 판정하지 않는다.

### 5.6 몸통과 루트

- `Root`와 `Hips` 위치는 전 구간 고정한다.
- F03~F08에는 작은 몸통 반대 회전으로 큰 칼날 스윙의 힘을 보조한다.
- F09~F13에는 몸통이 다시 중심으로 돌아오며 압축을 받는다.
- 발 위치와 개체 월드 위치는 움직이지 않는다.

## 6. 구현 순서

1. 승인 모델 원본에서 새 빈 공격 Action을 만든다.
2. 기준 카메라와 A/B 팔 대응을 먼저 확정한다.
3. F01·F04·F08·F13·F15의 다섯 핵심 자세를 먼저 만든다.
4. 각 핵심 자세에서 양쪽 팔꿈치 Pole, 내부각, 칼날 면과 안쪽 날 방향을 직접 확인한다.
5. 핵심 자세가 통과한 뒤 나머지 10개 중간 자세를 원본 프레임에 맞춘다.
6. 15개 자세를 FK 키로 베이크하고 전체 4초 보간을 만든다.
7. 60fps 전 프레임에서 역관절 방지 조건을 확인한다.
8. Blender에서 원본 15프레임과 같은 순서의 1:1 비교 시트, 양쪽 팔꿈치 확대 시트, 4초 연속 재생 영상을 만든다.
9. 원본과 직접 대조해 통과하기 전에는 FBX 또는 Unity 대상에 반영하지 않는다.
10. Blender 결과가 별도 승인된 뒤에만 기존 공격 에셋을 원자적으로 교체하고 슬롯 4에 반영한다.

## 7. 직접 시각 판정 기준

다음 항목을 화면에서 모두 식별할 수 있어야 한다.

- F03~F04: 한 칼날은 위·뒤, 다른 칼날은 아래·앞으로 명확히 분리된다.
- F05~F08: 두 칼날이 서로 다른 호를 따라 빠르게 정면으로 들어온다.
- F08: 수평에 가까운 두 큰 칼날이 몸 앞에서 가위처럼 겹친다.
- F09~F13: 겹친 공격 실루엣이 몸 가까이 압축되며, 다시 T자로 벌어지지 않는다.
- 양쪽 팔꿈치는 모든 확대 프레임에서 정상 굽힘 방향을 유지한다.
- 손목만 비틀리거나 상완·전완이 반대 방향으로 접히는 프레임이 없다.
- F15~4.00초는 F01과 같은 기본 자세다.

다음 중 하나라도 보이면 즉시 불합격이다.

- 팔꿈치 역관절 또는 신전 특이점 통과
- 상완과 전완을 동일 월드 방향으로 강제해 관절이 뒤집힘
- 칼날이 머리 위에서 세로로 섬
- 양팔이 대칭 T자 자세로 벌어졌다가 동시에 닫힘
- 손목 단독 회전으로 칼날 면을 맞춤
- 교차 후 몸쪽 압축 없이 다시 바깥으로 크게 벌어짐
- 작은 검토 이미지에서 관절 방향을 확인하지 못한 채 완료 판정
