# 오스티나토 전방 폐합 베기 모션 v5 검토

## 목표와 원인

- 대상은 `Approved Ostinato Enemy Placement/Ostinato_04_Scissor_Attack`의 `Ostinato_04_Attack_Source` 상태와 FBX 내장 `mixamo.com` 클립이다.
- v4는 바깥 베기 `101~115프레임`의 평균 각속도 진행률만 `53~93프레임`에 늘려 적용했다. 네 팔 본이 하나의 진행률과 최단 Euler 직선 호를 공유해, 칼날이 넓은 호로 베기보다 팔이 동시에 접히는 동작으로 읽혔다.
- v5는 속도 비율만 복사하지 않고 관절별 공간 궤적과 시간 진행을 각각 사용한다.

## v5 적용 방식

- `LeftArm`, `LeftForeArm`, `RightArm`, `RightForeArm`의 `localEulerAnglesRaw.x/y/z` 12개 바인딩만 수정한다.
- 각 본에서 바깥 베기 `101~115프레임`의 회전 호와 누적 각속도 진행을 따로 추출한다.
- 바깥 베기의 공간 호는 역방향으로 사용해 바깥쪽에서 전방 안쪽으로 닫히는 궤적을 만들고, 시간 진행은 정방향 바깥 베기의 빠른 진입과 관절별 선행 차이를 유지한다.
- `53~67프레임`에 전체 폐합 회전의 `90%`를 진행한다. 전체 Animator가 `2배속`이므로 주 베기 시간은 바깥 베기와 같은 `0.116667초`다.
- `67~93프레임`은 속도가 감소하는 후속 회전으로 나머지 `10%`를 진행한다. 임포트 정밀도에서 마지막 구간이 정지하지 않도록 감속 곡선에 작은 선형 성분을 유지한다.
- 원본 `53·93프레임` 자세, 전체 `2배속`, `53~93` 밖 커브는 유지한다.
- FBX importer 표식은 `Bellerophon.OstinatoForwardSlashMotion.v5`다.
