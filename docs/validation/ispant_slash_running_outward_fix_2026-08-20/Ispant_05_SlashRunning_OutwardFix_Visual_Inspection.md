- 장검의 폭축은 모델 정면 방향으로 정렬해 베는 면과 궤적이 정면의 대상을 향하도록 했다.

## 직접 시각 대조

- 사용자 영상 30개 시점에서 기존 상체 전체의 왼쪽·아래 처짐과 준비·베기 중 칼날이 오른팔 안쪽 및 흉곽 앞으로 들어오는 현상을 직접 확인했다.
- 수치 검사 뒤 최종 Unity 비교 캡처를 한 번 생성하고, 실제 Slash·실제 Running·완성 개체를 `0%`, `25%`, `50%`, `75%`, `100%`로 대조했다.
- 완성 개체의 25%·50%·75%·100% 확대 프레임에서 칼날은 각 시점의 오른손으로부터 상체 반대쪽 바깥으로 뻗고, 흉곽을 향하거나 오른팔과 겹치지 않는다. 칼날은 정면에서 얇은 단면이 보이는 방향을 유지해 베기 폭축이 정면 깊이 방향에 놓인다.
