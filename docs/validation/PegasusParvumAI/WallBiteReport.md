# 파르붐 공간실 벽 섭취 및 실제 물기 접촉 — 2026-09-27

## 범위

- Pegasus 파르붐 AI의 시설 먹이 등록과 기존 물기 애니메이션에 맞춘 접근/접촉 판정.
- 감지 5m와 기획서의 공격 상한 1m를 구분. 원본 모델/클립, 방/복도/바닥 형상·충돌체·배치 변경 없음.
- 금속 화물 대상과 기존 직접 섭취 피해량(시설 500/30초, 화물 최초 내구도/120회), 반격/스피커 규칙 보존.

## 직접 관찰과 수정

- 수정 전 실제 실행에서 `CH-04 east raised handling walkway band`를 먹이로 잡고 벽에 닿지 않은 채 물었다. 기존 root 거리 판정만으로는 입의 접촉을 보장하지 못했다.
- `WallTargetsApplied.txt`: 여섯 방의 실제 구조 벽 42개만 시설 먹이로 등록. 바닥, 천장, 복도/램프 측벽, 연결부, 설비의 기존 Facility 컴포넌트를 제거했다. 오브젝트/렌더러/충돌체는 제거하지 않았다. 화물과 플레이어 컴포넌트 유지.
- `WallBiteVerified_*` 등은 실행 중 원본 애니메이션을 바꾸지 않고 관찰한 이미지이다. 정지/접근/개구/벽 접촉을 비교했다. 화면이 가려진 초반 캡처는 통과 근거에서 제외했다.
- 조사 과정에서 `BakeMesh` 축척 처리에 따라 계산 높이가 0.094m로 잘못 축소되는 것을 확인했다. `BakeMesh(..., true)`로 실제 0.4m 모델 좌표와 일치시켰다(`ContactGeometry.txt`). 이는 계산 수정이며 모델 확대가 아니다.
- 현재 물기 모션의 전방 끝은 약 0.6m까지 도달한다. 약 0.45m 이내로 접근한 뒤 입의 실제 움직임과 대상 표면 접촉으로 피해를 판정하며, 별도로 1m 상한을 유지한다. 5m는 먹이 탐지에만 사용한다.
- 공격 한 주기당 1회만 피해를 허용한다. 입이 움직이는 프레임 사이 구간도 확인한다. 실내 쪽이 메시 뒷면인 벽도 양면 삼각형 교차로 접촉을 확인하며 전역 물리 설정을 변경하지 않는다.
- 가장 가까운 벽의 한 점에만 고정하지 않고 접근 가능한 인접 지점을 찾는다. 실제로 막힌 먹이는 잠시 제외하고 다시 탐색한다.

## 보조 기록과 실패 이력

- 초기 동력실 관찰은 8초 500→459 뒤 물기 누락, 다음 관찰은 500 유지/접근 반복으로 실패했다. 축척 오류와 실제 접촉 높이를 재조사한 뒤 수정했다. 해당 실패를 성공 기록으로 대체하지 않는다.
- `BiteReach.txt`: 1m 밖에서는 피해 없음. 등 뒤 대상은 회전 중 HP 100을 유지하고 접촉 뒤 피해 발생. 실제 벽 너머 대상은 3초 동안 HP 100 유지. 정상 접촉 피해는 0.5초 간격, 한 번에 6이었다. `WallBiteReach_*`에서 실제 접근과 물기, 기존 벽 차단을 확인했다.
- 최종 AI의 `WallBiteSweep.txt` 관찰에서 실제 접촉 이벤트는 동력실 39회(20초 관찰), 조종실/통제실/무기실/창고 각 15회, 비품실 12회(각 8초 관찰, 접근 시간 포함)였다. 각 이벤트는 애니메이션의 실제 입 이동과 표면 접촉을 통과한 뒤 발생했다. 직접 섭취와 파괴 부위 지속 피해가 함께 있으므로 방의 합산 소진 시간을 직접 섭취 기준 30초와 혼동하지 않는다.
- `WallBiteBefore.unity`와 현재 Pegasus를 YAML 블록 단위 비교: 변경은 ParvumTarget 컴포넌트 및 해당 GameObject의 컴포넌트 참조뿐이며 그 밖의 변경 0. 기존 사용자 변경은 Git HEAD와의 차이만으로 되돌리지 않았다.
- 실행 관찰은 열린 Unity의 실제 Play mode에서 기존 AI를 구동하고 카메라로 연속 관찰했다. 키보드를 수동 조작했다고 주장하지 않는다. 방별 관찰 복제본/자극은 임시 실행 상태이며 저장하지 않는다.
- 비품실의 기둥에 가려진 측면 화면은 접촉 증거에서 제외하고 `WallBiteSupplyTop_4_*` 상부 시점에서 입의 전진/벽 접촉을 확인했다.
- `WallBiteCargo.txt`, `WallBiteCargo_Bites.txt`: 실제 CH-03 금속 화물에 접근하고 120번째 물기에서 내구도 0. 최초 타격 전 반 주기를 포함한 기존 계산 기준 60.0000초, 이후 탐색 복귀. 관찰용 금속 재질 지정만 실행 중 적용했으며 저장하지 않았다. 화물 옆 단상과 모델 일부의 시각적 겹침은 남아 있어 이 화면을 가림 없는 접촉 검증으로 주장하지 않는다. 기존 구조물/충돌체 문제로 이번 범위에서 변경하지 않았다.
