# 파르붐 방 진입 후 1m 전진

## 범위와 방식

- 다른 방으로 이동할 때 방 바닥에 닿는 즉시 금속을 선택하던 전환을 `AdvanceIntoRoom`으로 분리한다. 기존 방/복도/연결부/충돌체/NavMesh/모델/클립/배치 변경 없음.
- 실제 바닥 소속으로 방 진입을 확인하고, 현재 이동 방향 기준 캡슐 뒤쪽까지 해당 방 바닥에 진입한 지점부터 1m 전진한다. 벽 섭취는 그 이후에만 허용한다. 속도×시간이나 왕복 이동 누적 거리가 아니라 기준점에서 출구 진행 방향으로의 실제 변위를 사용한다.
- `RoomEntryAdvanceDistance`는 이번 사용자 지정 거리이며 공격/감지 거리와 무관하다. 전진 목표/방 정보는 전투·스피커 중단 동안 유지한다. 원래 Rigidbody 충돌 이동을 사용하며 Transform 순간이동을 사용하지 않는다.
- 직접 관찰은 열린 Pegasus 실행모드의 실제 AI를 임시 관찰 카메라로 연속 렌더링해 확인한다. 키보드로 개체를 조작한 것이 아니다. 재현용 방 내구도/임시 자극은 실행 중에만 설정하고 저장하지 않는다.

## 중간 관찰

- `EntryAdvance01`: 저장된 원래 파르붐의 창고→조종실, 조종실→통제실 이동. 조종실 화면 0214/0215/0218/0220에서 경사 출구를 떠나 전진함을 확인했다. 통제실 0528/0531/0534/0536은 부분 가림을 포함하며 단일 가림 프레임만으로 통과 판정하지 않는다.
- 초기 버전은 전진 거리 뒤 코너 도착 허용 오차 및 0.25초 탐색 주기 때문에 약 1.05m에서 잠시 정지했다. 최종 보완에서 전진 속도를 남은 거리에 맞게 제한하고, 도달 즉시 탐색 갱신한다. 이 초기 관찰은 최종 코드 완료 근거와 구분한다.

## 상태

- `EntryAdvanceFinalRun`은 이름과 달리 최종 통과가 아니다. 창고→동력실 출구에서 0.9991~0.9999m에 머물며 탐색으로 전환하지 못했다. 작은 잔여 거리에서 속도가 바닥 마찰보다 낮아지는 원인을 확인했다. 거리 기준을 낮추지 않고 끝부분 최소 진행 속도 0.25m/s를 사용해 다음 물리 프레임에서 기준을 넘도록 수정했다. 최대 마지막 프레임 초과는 0.25 × fixedDeltaTime이다.

- 요청한 진입 후 전진 로직의 구현 및 직접 실행 관찰 완료. 전체 파르붐 AI나 모든 출입구의 전수 검증을 의미하지 않는다.
- 보완 후 `EntryAdvanceResolved`: 같은 창고→동력실 출구에서 0200/0203/0206의 전진, 0212의 벽 쪽 회전을 직접 확인했다. 전진 완료 변위 1.0003m, 이후 금속 접근으로 정상 전환했다. 동력실 기존 바닥 장식과 모델 하부의 겹침은 이번 수정 대상이 아니다.
- `EntryAdvanceInterruptAttacker`: 동력실→통제실 진입 중 약 0.24m에서 임시 공격자 피격 입력. 0220/0224/0228/0240 실행 화면에서 진입, 공격자 물기, 진행 재개와 벽 접근을 확인했다. 기록 18.27초 PursueAttacker → Bite → 18.68초 AdvanceIntoRoom 복귀, 전진 완료 1.0003m 후 금속 섭취. 스크립트가 개체의 위치/행동을 강제로 완수시키지 않았다.
- `EntryAdvanceInterruptSpeaker`: 통제실→조종실 진입 중 스피커 입력. 0156/0160/0164/0172/0176에서 출구 전진, 임시 스피커 물기, 남은 전진 및 벽 쪽 회전을 확인했다. 13.35초 DestroySpeaker, 13.84초 AdvanceIntoRoom 복귀 후 1.0003m에서 금속 탐색/섭취 전환. 실제 스피커 아이템 설치 기능 검증이 아니라 기존 AI의 소리 입력 우선순위 확인이다.
- 콘솔 확인 후 `EntryAdvanceFinal.png` 최종 캡처 1회. 단일 정지 화면이 전진 거리/전체 전환의 증거는 아니며 위 연속 관찰과 함께 사용한다.
- 실행 종료: Pegasus, Play=False, Dirty=False, Compiling=False, Console Entries=0. 원래 시작 위치 `(53.9395,-4.0480,4.9777)`, Health=55 복귀. 임시 내구도/공격자/스피커 조건은 실행 종료로 제거했고 씬에 저장하지 않았다.
- 반영 명령: `Refresh-UnityProject.ps1`, `Invoke-UnityEditorBridge.ps1 -Command ReviewParvumGameplay`. Unity 재시작, 자동 테스트/빌드, Git 커밋·푸시 없음.
