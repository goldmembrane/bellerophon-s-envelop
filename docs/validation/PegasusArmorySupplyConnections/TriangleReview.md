## 1순위: 실제 실행모드 화면

- 동력실 H01: 100–107. 방 방향, 연결부 안쪽 좌우 바닥·천장, 외부 양측과 상부. 이전 사선 돌출판 대신 연속 측벽과 바닥이 보이며 확인한 경계에서 외부 노출은 보이지 않음.
- 조종실 H01: 108–112, 115, 181. 기존 안쪽 문틀 끝에 연결. 수정 중 보였던 세로 외부 노출을 동일 구도에서 다시 확인해 닫힌 면으로 바뀐 것을 확인.
- 조종실 H02: 116–120, 123, 182. 바닥·벽·천장 접속과 외부를 확인. 벽에 가려진 122는 제외.
- 통제실 H02: 124–131. 방으로 향하는 개구부가 유지되며 왼쪽 측벽과 바닥·천장이 연속됨.
- 동력실 H05: 132–139. 원형 바닥에서 입구로 이어지는 별도 데크 및 연결부 내·외부 확인.
- 통제실 H05: 140–147. 개구부와 측벽·바닥·천장 및 외부 확인.
- 180 전체 배치, 183–185 복도 본체 내부 확인. 방/복도 사이의 새 관통 구조는 보이지 않음.
- 최종 전경은 View_200.png / artSample/PegasusArmorySupplyConnections/TriangleFinal.png.

실제 열린 Unity의 실행모드 관찰 카메라를 브리지로 이동·회전하고 각 Game 화면을 직접 읽었다. 지오메트리·조명·가시성을 검증에 맞춰 바꾸지 않았다. 이것은 키보드로 플레이어를 걸어 본 검증이 아니다. 기존 닫힌 셔터·가로 리브·원본 Collider는 유지했으며 물리 통과·끼임 없음은 미검증이다.

수정 중 CPU 메시/Collider와 화면의 오래된 메시가 불일치했다. 샘플 메시 자산에 정점·삼각형·노멀을 명시적으로 갱신하고 UploadMeshData(false)로 반영한 뒤 동일 위치 화면에서 틈이 닫힌 것을 재확인했다. 수치나 Raycast 결과로 화면의 틈을 무시하지 않았다.
