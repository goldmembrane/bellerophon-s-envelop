# Grave 공격 자동 시각 캡처

## 검증 방식

- 명령: `CaptureGraveAttackCurtainEndingFrames`
- 대상: `Grave_Attack_CurtainCall_Sweep_Working`
- Unity Scene View 선택·포커스나 Play Mode 재생을 사용하지 않는다.
- 작업 클립을 지정 시점에 직접 샘플링하고, Skinned Mesh를 임시 `HideAndDontSave` 프록시로 Bake한다.
- 임시 정면 직교 카메라와 조명으로 동일한 `720x720` 구도의 PNG를 렌더한다.
- 임시 포즈, Animator 활성 상태, BlendShape 값, 카메라와 조명을 모두 복원·제거한다.
- 씬을 저장하지 않으며 실행 전후 dirty 상태가 달라지면 캡처를 실패 처리한다.
- 수치 판정이 아니라 생성된 실제 렌더 픽셀을 접촉 시트와 개별 원본으로 비교한다.

## 캡처 순서

1. `1.58초`: 커튼콜 진입 완료 시점
2. `2.15초`: 요청된 오른팔 하강 시작 시점
3. `2.25초`: 오른팔 하강 중간 시점
4. `2.35초`: 오른팔 하강 완료 및 복귀 연결 시점
5. `2.65초`: 기존 중간 복귀
6. `3.00초`: 기본 자세 복귀

파일과 시점의 정확한 대응은 `Grave_Attack_CurtainEnding_CaptureManifest.txt`에 기록했다.

## 시각 판정

- `2.15 → 2.25 → 2.35초`에서 오른팔 체인이 한 프레임에 튀지 않고 아래쪽·몸 안쪽으로 소폭 이동한다.
- 팔꿈치와 손목의 기존 곡선 형태가 유지되고, 낫 형상이 갑자기 꺾이거나 사라지지 않는다.
- `2.35 → 2.65 → 3.00초`에서 기존 복귀가 연속적으로 이어진다.
- 모든 프레임이 동일한 카메라 구도와 크기로 렌더되어 자세 차이를 직접 비교할 수 있다.
- 접촉 시트: `Grave_Attack_CurtainEnding_ContactSheet.png`
- 현재 판정은 자동 렌더 이미지 기준 통과이며 사용자 시각 승인 완료로 간주하지 않는다.
