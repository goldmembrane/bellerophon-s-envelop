# 오스티나토 공격 유지 및 기본자세 복귀 검토

## 적용 결과

- 원본 공격 FBX와 `mixamo.com` 원본 클립은 수정하지 않았다.
- 파생 클립 `Ostinato_04_Scissor_Attack_PhaseCut.anim`을 만들고 공격 Controller의 `Ostinato_04_Attack_Source` 상태에 재생 속도 `1`로 연결했다.
- 새 `0~100프레임`은 원본 `0~100프레임`을 그대로 사용한다. 양팔 폐합·타격 `85~93`과 타격 후 자세 `94~100`도 변경하지 않았다.
- 새 `101~118프레임`은 원본 100프레임 자세에서 원본 0프레임 기본자세까지 `18프레임/0.3초` 동안 감속 복귀한다.
- 회전 채널은 각 축의 최단 각도 방향으로 움직이며, 시작과 끝의 속도가 0이 되는 곡선을 사용한다.
- 새 `119~131프레임`은 기본자세를 유지한다. 원본의 수평 재전개·단계적 회수와 서로 맞지 않던 원본 151프레임 직접 접합은 재생하지 않는다.
- 최종 길이는 `131프레임`, `2.183333초`, `60fps`이며 반복 재생을 유지한다.

## 수치 검사

- Float curve binding `60개`가 원본과 동일하다.
- 새 `0~100`은 0.25프레임 간격 조밀 비교에서 원본 `0~100`과 최대 오차 `0`으로 일치한다.
- 복귀 첫 프레임의 최대 회전 채널 변화는 `0.613648도`, 전체 복귀의 최대 회전 채널 변화는 `5.711548도`다.
- 복귀의 최대 위치 채널 변화는 `0.007759`이며, 회전·위치 곡선 오버슈트는 없다.
- 118프레임에서 원본 0프레임 기본자세에 도달하고 `119~131`에서 동일 자세를 유지한다. 131→0 반복 경계도 연속이다.
- 원본 FBX SHA-256은 `0430EEE08D7D2AFBC645ECD3DFDA7B37C1DBF7BB4A6A34AF761E9AFAD1708260`으로 유지됐다.
- 공격 개체는 제공 공격 FBX의 직접 인스턴스를 유지하고, 표시 메시와 머티리얼은 정적 승인 외형을 유지한다.
- 모델링, 메시, 본 구조, 손목·칼날의 별도 보정은 수행하지 않았고 다른 오스티나토 슬롯도 변경하지 않았다.

## 최종 캡처

- 수치 검사 통과 뒤 최종 캡처를 한 번 실행했다.
- 파생 프레임 `0, 53, 84, 85, 93, 94, 100, 101, 104, 109, 114, 118, 119, 131`을 정면·3/4 시점으로 확인했다.
- `84~100`의 양팔 폐합·타격 흐름은 원본대로 유지된다. `100→101`에서 순간 전신 회전 없이 복귀가 시작되고 `104→109→114→118`에서 기본자세로 점진적으로 풀린다.
- 접합과 복귀 전 구간에 개체 소실, 메시 변형, 칼날과 손목의 분리는 보이지 않았다. `119`와 `131`은 같은 기본자세다.
