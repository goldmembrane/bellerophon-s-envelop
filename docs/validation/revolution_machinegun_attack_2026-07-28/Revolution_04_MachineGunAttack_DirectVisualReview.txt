## 폐기한 결과

- 기존 완료 기록의 `오른팔 10성분·80정점 재정렬` 결과는 무효입니다.
- 기존 오른팔 전용 선택은 앞쪽 캡 2개를 누락하고 긴 성분 10개만
  선택했습니다.
- 선택한 성분을 다시 평행 정렬하고 삽입점 평균으로 링 중심을 만든
  과정은 왼팔과 다른 형상·회전 경로를 만들었습니다.
- 기존 총구 정면 캡처는 매 프레임 회전 메시 평균 중심을 다시 따라가
  축 이탈을 화면 중앙에 숨겼습니다.
- 잘못된 문서와 영상은
  `Logs/RevolutionMachineGunInvalidDiagnostics/`에 격리했습니다.

## 최종 구조

- 왼팔과 오른팔 모두 같은 `SelectBarrelComponents` 선택 경로와 같은
  `CreateExtractedBarrelMesh` 결합 경로를 사용합니다.
- 왼팔은 원래 선택 기준을 유지해 12성분·113정점을 사용합니다.
- 오른팔 원본은 유효한 4성분의 `RightHand` 가중치가
  `0.375~0.443`이므로, 비총신 후보를 추가하지 않으면서 완전한
  12성분을 보존하는 오른팔 전용 최저 경계 `0.35`를 사용합니다.
- 최종 오른팔 회전체는 12성분·108정점입니다.
- 오른팔 원본 총신 형상은 평행 정렬·반경 재배치 없이 그대로 보존해
  하나의 결합 메시로 만들었습니다.
- 좌우 결합 메시를 각각의 링 본에 직접 연결하고, 두 링 본에 같은
  발사당 `72°` 인덱스 회전과 같은 키 시점을 적용했습니다.
- 개별 총신 자식 역회전과 별도 보정 커브는 없습니다.
- 섬광은 각 손 기준 고정 피벗에 남아 회전체와 함께 공전하지 않습니다.

## 직접 시각 비교 결과

- 사용자 영상에서 보였던 오른팔 원반·총신 묶음의 팔 아래쪽 대형
  공전과 몸체 위쪽 이탈이 사라졌습니다.
- 총구 정면 카메라는 메시 평균 중심을 따라가지 않고 각 링 본의
  고정 중심·고정 축·고정 화면 상단 방향을 기준으로 촬영했습니다.
- 같은 시점의 왼팔은 청록색, 오른팔은 자홍색으로 나란히 놓은
  30fps 연속 영상에서 두 팔 모두 같은 방향과 같은 `72°` 간격으로
  회전합니다.
- `0°`, 중간 `36°`, `72°`, `144°`, `216°`, `288°`, `360°`
  구간에서 좌우 회전체 모두 중심이 고정되고 한 덩어리로 회전합니다.
- 오른팔 12성분은 누락·개별 미끄러짐·역회전·세차·타원 공전 없이
  상대 위치와 앞뒤 깊이를 유지합니다.
- 원본 재질 연속 영상에서도 오른팔 회전체가 팔 아래로 분리되지 않고
  왼팔과 같은 발사 시점에 같은 인덱스 회전을 수행합니다.
- 양팔의 원본 무기 형상은 서로 다르므로 실루엣 크기 자체가 아니라
  회전 중심·방향·각도·시점·강체 유지 여부를 동일성 기준으로
  대조했습니다.

## 2026-07-29 11:15:45 영상 이후 최종 재정정

- 기존 `12성분·108정점 원본 형상 보존` 결과는 무효입니다.
- 유일한 판정 기준은 현재 정상인 왼팔의 상태와 모션입니다.
- 오른팔 원본 12성분 중 기울어진 총신 10성분·80정점만 제거했고,
  앞·뒤 고정 원반 2성분은 원본 스킨 메시와 오른손 하우징에
  그대로 남겼습니다.

  공간으로 변환했습니다. 좌우 손 부모의 스케일과 좌표계 차이는
  좌우 회전 본의 월드 변환을 거쳐 보정했습니다.
- 좌우 앞쪽 사선 연속 프레임의 `0·5·10·15` 프레임과 뒤쪽 사선
  연속 프레임의 `0·10·15·25` 프레임을 직접 대조했습니다.
- 오른팔 총신은 정상 왼팔과 같은 길이 방향·간격·상대 자세·회전
  위상을 유지하며, 앞 원반과 뒤 원반에 모두 삽입된 상태로
  회전합니다.
- 오른팔에서 대각선 기울기, 원뿔형 공전, 원반 밖 이탈, 앞·뒤
