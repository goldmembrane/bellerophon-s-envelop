# Accelerando 더듬이 구동 철퇴 자연 관성 수정 검증

## 목표와 입력 영상

- 대상: `Approved Accelerando Enemy Placement/Accelerando_03_Antenna_Strike`
- 입력 영상: `Bellerophon - CargoRunMvp - Windows, Mac, Linux - Unity 6.3 LTS (6000.3.16f1)_ _DX12_ 2026-07-15 10-37-54.mp4`
- 영상 사양: H.264, `1920x1000`, `262`프레임, `7.810533초`
- 목표: 철퇴를 단순히 정면으로 모으지 않고, 좌우 더듬이의 실제 위치 변화와 가속·반전에 의해 사슬과 철퇴가 서로 다른 위상으로 자연스럽게 후행하도록 수정한다.

## 영상 분석 결과

- 더듬이 끝은 좌우·높이·전후 방향으로 넓은 궤적을 만들지만, 기존 철퇴는 아래에 머무는 비중이 크고 더듬이 가속 반전과 일관된 장력 변화가 약했다.
- 원본 영상 접촉표와 구간별 프레임은 이 폴더의 `source_*.png`에 저장했다.
- 단순 전방 오프셋만으로는 더듬이와 철퇴의 물리 관계를 판정할 수 없어, 더듬이 국소 이동 범위와 더듬이 기준 철퇴 상대 이동, 더듬이 가속도 반대 방향의 관성 후행 표본을 3차원으로 측정했다.

## 원인과 수정

- 공격 사슬의 첫 번째 kinematic 프록시가 더듬이 끝 위치뿐 아니라 더듬이 본 회전까지 그대로 복사하고 있었다.
- 두 번째 링크의 연결 앵커는 첫 프록시의 질량 중심에서 떨어져 있으므로, 이 회전 복사가 앵커를 원호로 쓸어 더듬이 끝의 실제 평행 이동과 무관한 운동을 사슬에 주입했다.
- 공격 사슬은 자유 회전 고리에 연결된 구조로 취급해 첫 프록시가 더듬이 끝 `position`만 추종하고 초기 `rotation`은 유지하도록 수정했다.
- 선형 연결을 잠그지 않는 crawl 구성은 기존처럼 위치와 회전을 모두 추종하므로 영향받지 않는다.
- 정지 구간의 잔류 흔들림만 줄이기 위해 다음 수치를 조정했다.
  - 링크 선형 감쇠 `2.30 -> 2.80`
  - 링크 각 감쇠 `1.70 -> 2.00`
  - 철퇴 선형 감쇠 `2.80 -> 3.40`
  - 철퇴 각 감쇠 `1.70 -> 2.00`
  - 정지 감쇠 응답 `4.00 -> 6.00`
- 이동 중 링크 감쇠 `0.55/1.00`, 철퇴 감쇠 `0.10/0.35`, 철퇴 질량 `0.45`, 철퇴 관절 massScale `1.00`은 유지했다.
- 절대 후기 속도, 에너지 감소, 전방 범위와 3차원 관성 조건을 모두 별도로 유지하면서, 초기 속도가 작은 현재 공격의 정지 비율 기준만 `1.15 -> 1.40`으로 보정했다.
- 공격 AnimationClip, Animator, 더듬이 키프레임은 변경하지 않았다.

## 검증 기준 보강

- 각 좌우 사슬에 대해 다음 3차원 기준을 추가했다.
  - 유효 더듬이 가속 표본 `20`개 이상
  - 더듬이 가속 반대 방향 철퇴 상대 운동 표본 비율 `0.20` 이상
  - 가장 강한 가속-후행 코사인 `-0.50` 이하
- 수정 전 오른쪽은 후행 표본 `15`, 가장 강한 코사인 `-0.346`으로 새 기준을 통과하지 못했다.
- 수정 후 오른쪽은 후행 표본 `24`, 비율 `0.255`, 가장 강한 코사인 `-0.521`로 개선돼 더듬이 실제 가속과 반대 방향의 관성 후행을 확인했다.
