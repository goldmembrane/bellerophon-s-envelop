# 아타 모델 다중 개체 Play Mode 성능 확인

## 판정

- 확정 배치 수인 아타 `9개`와 여유 비교 수인 `18개`를 실제 Unity Play
  Mode에서 내장 걷기 애니메이션과 함께 반복 재생했습니다.
- 아타 모델만 분리한 측정에서 `9개`는 빈 기준보다 평균 프레임 시간이
  `0.307ms`, `18개`는 `0.376ms` 증가했습니다. `9개`와 `18개` 모두
  `33.33ms`를 넘는 프레임은 없었습니다.
- `CargoRunMvp`의 기존 런타임을 유지한 측정에서 `9개` 추가 비용은
  평균 `0.263ms`, `18개` 추가 비용은 평균 `0.595ms`였습니다. p99는
  빈 기준과 각각 `-0.938ms`, `+0.132ms` 차이로 같은 변동 범위였습니다.
- 따라서 이 PC와 현재 FBX 상태에서는 아타 `9개` 또는 `18개`의 스킨
  렌더링·내장 애니메이션 재생이 별도의 유의미한 렉을 추가하지 않았습니다.
- 단, 아타가 없는 `CargoRunMvp` 기존 런타임 자체가 Editor에서 평균
  `39.224ms`, `25.49 FPS`였습니다. 모든 기준 프레임이 `33.33ms`를
  넘었으므로 현재 씬 전체를 “렉 없이 재생된다”고 판정할 수는 없습니다.
  이번 판정은 기존 씬의 느린 기준 상태에 아타 모델이 추가 지연을 거의
  더하지 않는다는 뜻입니다.

## 대상 FBX

- 원본: `enemies model/attas.fbx`
- 파일 크기: `8,433,532 bytes` (`8.04 MiB`)
- 원본 및 임시 임포트 사본 SHA-256:
  `CF7EE9DA3D4C3C00A8F26CE2F9D71FB165043C9BF6E0407CB9503DE1F51A795D`
- 렌더러: `SkinnedMeshRenderer 1개`
- 메시: `1개`, 정점 `14,895개`, 삼각형 `10,303개`, 서브메시 `1개`
- 본: `24개`
- 머티리얼: `1개`
- 내장 애니메이션:
  `Armature|Armature|Armature|Armature|walking_man|baselayer` 1개,
  길이 `1.033333초`
- 위 내장 클립을 모든 아타 인스턴스에 Animation Playables로 연결해
  전체 측정 구간에서 반복 재생했습니다.

## 측정 환경

- Unity `6000.3.16f1`, Windows Editor Play Mode, Direct3D 12
- CPU: Intel Core i9-12900F, 논리 프로세서 `24개`
- GPU: NVIDIA GeForce RTX 3080, VRAM `10,053MB`
- 시스템 메모리: `32,577MB`
- 화면: `1920x1080`
- 각 수량별 준비 시간 `2.5초`, 정상 상태 표본 `8초`
- VSync 해제 및 목표 프레임 제한 없음
- 수량: 빈 기준 `0개`, `1개`, 확정 슬롯 수 `9개`, 여유 비교 `18개`
- `CargoRunMvp` 씬은 측정 전후 모두 저장하지 않았고 측정 시작 시
  비수정 상태였습니다.

  사용하지 않았습니다.

## 직접 화면 확인

- 최종 캡처를 원본 해상도로 직접 확인해 아타 `18개`가 모두 렌더링되고
  내장 걷기 클립의 보행 자세가 적용된 상태임을 확인했습니다.
- 임시 임포트의 자산 의존성에는 FBX와 URP Lit 셰이더만 있으며 별도
  텍스처 자산은 없었습니다. 최종 화면의 흰색 외형은 성능 확인용 원본
  임포트 상태이며 외형 품질 판정에는 사용하지 않았습니다.
- 최종 캡처는 진단 통과 후 한 번만 생성했습니다.

## 적용 한계

- 이 결과는 위 하드웨어와 Unity Editor의 현재 프로젝트 상태에 한정됩니다.
- 독립 실행 빌드, 다른 하드웨어, 최종 머티리얼·텍스처, AI, 경로 탐색,
  전투 로직, 권총·VFX·사운드가 더해진 최종 아타 프리팹 비용은 포함하지
  않습니다.
- 원본 `attas.fbx`는 수정하지 않았고, `CargoRunMvp`에 아타를 영구
  배치하거나 씬을 저장하지 않았습니다.
- 측정용 임시 FBX와 그 전용 `Ata/PerformanceProbe` 자산 폴더·메타는
  결과 생성 후 제거했습니다. 원본 FBX는 같은 SHA-256으로 남아 있습니다.
