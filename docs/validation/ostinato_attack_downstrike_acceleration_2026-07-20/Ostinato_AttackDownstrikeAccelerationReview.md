# 오스티나토 공격 내려찍기 속도 가속 적용

## 적용 방식

- 대상은 `Approved Ostinato Enemy Placement/Ostinato_04_Scissor_Attack`의 `Ostinato_04_Attack_Source` 상태다.
- Controller 상태 속도를 `2`로 설정했다.
- `OstinatoAttackAccelerationBehaviour`가 원본 정규화 재생 위치를 읽고 해당 Animator의 `speed` 추가 배율만 조절한다.
- 속도 프로필 자체는 AnimationClip 커브를 수정하지 않는다. 현재 클립에는 별도 승인된 전방 베기 임포트 보정이 `53~93프레임`의 양쪽 상완·전완 회전 커브에만 적용돼 있다.

## 승인 속도 프로필

| 원본 프레임 | 추가 배율 | 실효 속도 | 역할 |
|---:|---:|---:|---|
| `0~52` | `1` | `2배속` | 전체 기본 2배속 유지 |
| `53~84` | `3→4` | `6→8배속` | 낮은 원본 이동 밀도를 시간 압축하며 전방 베기 가속 |
| `85~93` | `4→5` | `8→10배속` | 주 타격점까지 감속 없이 연속 가속 |
| `94~196` | `1` | `2배속` | 타격 직후 전체 기본 2배속 복귀 |

사용자 영상에서는 원본 `53~84프레임`의 낮은 프레임당 이동량 때문에 고정 6배속에서도 앞부분이 기를 모으는 것처럼 읽혔다. 이를 보정해 `53~93프레임`은 0.25프레임 간격 전체 점검에서 단조 가속한다. 세부 실효 속도는 53프레임 `6`, 70프레임 `7.144708`, 84프레임 `8`, 85프레임 `8.068587`, 90프레임 `9.481482`, 93프레임 `10`이며 94프레임부터 `2`다.
