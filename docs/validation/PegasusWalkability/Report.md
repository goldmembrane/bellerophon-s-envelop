# Pegasus 보행 추락 수정

## 직접 확인

실행모드에서 기존 Player의 보행 입력과 충돌 처리를 이용해 H01~H05와 창고 연결 복도 5개를 양방향으로 이동했다. 중앙과 좌우 0.8m 경로를 각각 따라 걸었으며, 입구 도착 후 0.7초 이상 정지해 바닥 지지가 유지되는지도 확인했다. 플레이어 카메라의 이동 중 화면과 입구 도착 화면을 직접 확인했다. 복도 본체에서 바닥 아래로 추락하던 H01은 수정 후 끝까지 통과했다.

사진만으로 보행을 대체하지 않았다. 가상 키보드 W 입력 → 기존 InputAction → Motor → CharacterController의 연속 이동을 수행하고, 화면 관찰과 이동 기록을 함께 확인했다. 시작점만 배치했으며 경로 이동 중 위치를 강제로 변경하지 않았다. 방향은 경로를 따라 조향했다. 사용자의 실제 하드웨어 키보드를 직접 조작한 확인은 아니다.

`Route_0`~`Route_4`는 H01~H05, `Route_5`~`Route_9`는 창고–동력실/조종실/통제실/무기실/비품실이다. 각 폴더의 `Path.txt`, `Result.txt`, 이동 중 PNG가 근거다. `side=1/-1`, `lateral=0.0/-0.8/0.8`의 60개 경로를 확인했다. 중앙과 가장자리 모두 확인 지점에서 추락·끼임·미도착 없이 도착했다. 정상적인 경사 하강 중 일부 프레임의 비접지는 즉시 추락으로 취급하지 않았으며, 이동 경로 유지와 끝 지점 정지 접지를 확인했다.

## 원인과 수정

- H01~H05의 보이는 바닥 본체에는 BoxCollider가 있었지만 비활성화되어 있었다. 연결부에서 복도 본체로 이동할 때 바닥 지지가 사라졌다.
- 연결된 방/입구 바닥 중 기존 충돌체가 꺼졌거나 없는 곳도 있었다. 정확한 대상은 `RepairedRoomFloors.txt`에 기록했다.
- 기존 BoxCollider 13개를 활성화하고 기존 메시를 그대로 쓰는 MeshCollider 7개를 추가했다. 충돌체는 trigger가 아니다.
- 기존 메시, 외형, 머티리얼, Transform, 복도 길이·경사, 문 코드, 플레이어 이동 코드·공유 설정, 숨긴 구형 경사 복도는 바꾸지 않았다.
- 창고 경사 복도는 기존 충돌체로 확인했고 변경하지 않았다. 무관한 벽·장식물 충돌체를 일괄 켜지 않았다.

## 문 기능 및 보조 확인

- `Route_0_1_0.0_Closed`: H01에서 닫힌 셔터에 접근한 뒤 계속 전진 입력을 넣어도 문 앞에서 멈춤. 바닥 접지 유지.
- `Route_5_-1_0.0_Closed`: 창고–동력실 닫힌 문에서 같은 차단 확인.
- 위 두 기록의 `timeout=True`는 의도한 차단 결과다. `Route_0_1_0.0_Reopened`는 재개방 후 도착했다.
- 열린 경로 60개는 모두 `reached=True`, `fallen=False`, `timeout=False`. 종료 정지 시 접지 유지. 수치만으로 직접 확인을 대체하지 않는다.
- 마지막 콘솔 `Compiling=False`, `Entries=0`. 임시 입력/런타임 설정 복제본 제거, Play Mode 종료. Unity 재시작 없음.
- `Before.unity.txt`는 이번 작업 전 복구본. `AfterSnapshot.unity`는 마지막 에디터 씬 복사본이며 저장된 Pegasus와 전체 텍스트 일치. Dirty 표시만을 이유로 사용자 변경을 버리지 않았다.
- 작업 전후 씬 YAML 차이는 BoxCollider 13개, MeshCollider 추가 7개, 이를 참조하는 GameObject 7개. Transform 및 렌더링 컴포넌트 변경 없음.
- 최종 확인을 마친 뒤 `Final.png`를 한 번 캡처했다. 자동 테스트·빌드·Git 작업은 수행하지 않았다.

## 확인 도구 실패와 한계

처음 창고 경로를 렌더 MeshFilter로 읽었을 때 정적 배칭 때문에 잘못된 경로가 추출되었다. 원래 MeshCollider 메시 기준으로 고친 뒤 확인을 다시 수행했다. 초기 자료는 완료 근거가 아니다. 가장자리 오프셋 소수점 표기 불일치 시도 역시 60개 최종 경로에서 제외했다. 컴파일 중 브리지 요청 타임아웃은 재시도 후 해결했다.

이번 완료 범위는 승인된 복도와 연결 입구의 보행 추락 수정이다. 선박 모든 벽의 충돌, 방 안의 모든 가구 상호작용, 기존 표지와 표면 줄무늬, 미구현 출입구 조건 기능까지 해결했다고 판단하지 않는다.
