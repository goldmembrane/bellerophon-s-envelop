## 오른쪽 더듬이 고정점 원인

- 오른쪽 더듬이에는 같은 시작점에서 나란히 뻗는 두 본 체인이 있었다.
  - 공격 체인: `Bone_008/007/006`
  - 고정 병렬 체인: `Bone_014/013/012`
- 이전 보정 메시에서는 오른쪽 더듬이 후보 887개 중 713개 정점이 10%가 넘는 비공격 본 영향을 받고 있었다.
- 가장 심한 정점은 공격 본 영향이 약 1.7%뿐이고 고정 병렬 본 영향이 약 98.3%여서, 공격 체인만 움직일 때 특정 위치에 붙잡힌 것처럼 늘어났다.

## 수정

- 승인된 직접 애니메이션 본 6개는 그대로 유지했다.
  - 오른쪽: `Bone_008/007/006`
  - 왼쪽: `Bone_011/010/009`
- 오른쪽 더듬이의 병렬 체인 웨이트를 대응 공격 체인으로 합쳤다.
  - `Bone_014 → Bone_008`
  - `Bone_013 → Bone_007`
  - `Bone_012 → Bone_006`
- 왼쪽 기준 웨이트를 오른쪽으로 옮길 때 `Bone_017/016/015` 영향도 `Bone_008/007/006`으로 대응시켰다.
- 기존 오른쪽 웨이트 12% 재혼합을 제거했다.
- 중립 정점, 삼각형, UV, 머티리얼, 텍스처는 변경하지 않았다.
- 공격 회전 폭을 기존 `28/18/8`도에서 `40/28/14`도로 확대했다.
- 사슬·철퇴 Transform 커브와 물리 파라미터는 변경하지 않았다.
