## 최종 상태 — 샘플 제작·직접 검토 완료, 사용자 승인 대기

기존 다섯 방 바닥을 수정하지 않고 신규 연결부 소속 받침과 접합 마감으로 처리했습니다. 아래 미완료·실패·범위 확대 요청은 보완 전 이력이며 현재 상태가 아닙니다. Pegasus에는 적용하지 않았습니다.

직접 확인: 다섯 순방향 기록 Engine Forward -0.8 10(000~017), Cockpit Forward -0.8 4(000~016), Control Forward -0.8 10(000~019), Armory Forward -0.8 10(000~019), Supply Forward -0.8 10(000~016)의 전체 화면을 열어 확인했습니다. 양방향·양측 CharacterController 이동을 실행했고 역방향 접점 접근 화면도 확인했습니다. 모든 이동 기록의 모든 프레임을 검토한 것은 아닙니다.

Entrance_201/301~304는 방 쪽 바닥, 401~405는 창고 쪽 바닥, 420~424/440~444는 방 쪽 외측 상하, 430~434/450~454는 창고 쪽 외측 상하의 직접 확인 근거입니다. 관찰한 연결 경계에서 열린 틈, 통로 관통판 또는 이동 중 끼임은 확인되지 않았습니다. 최종 배치 캡처는 Entrance_500 및 artSample/PegasusCargoConnections/Final.png입니다.

직접 확인 후 보조 측정한 본체 길이(m): Engine 17.999936, Cockpit 17.999855, Control 17.999810, Armory 17.999848, Supply 17.999842. 각 4m/s 환산 약 4.5초이며 연결부는 제외합니다. 실제 이동 기록의 경과 시간과 혼동하지 않습니다.

콘솔 오류는 확인되지 않았으며 그림자 아틀라스 해상도 축소 경고는 남아 있습니다. 실제 게임 플레이어 전체 동작 검증은 하지 않았습니다. 자동 테스트·빌드·Git 작업은 실행하지 않았습니다. 원본 Pegasus 해시는 아래 보존 기록과 동일합니다.

## 2026-09-23 연결부 바닥 보완으로 처리 — 후속 진행 중

사용자 지적에 따라 기존 방 바닥 수정이 필요하다는 앞선 판단을 정정합니다. 기존 바닥은 변경하지 않고 새 복도 연결부 루트에 입구 받침 바닥과 측면·상부 접합 마감을 추가했습니다. 아래 기록의 추가 범위 결정 요청은 철회된 과거 판단입니다.

실행모드에서 조종실 역방향 이동의 바닥 빠짐이 재현되지 않았으며, 조종실 양측 이동과 통제실·무기실·비품실 역방향 이동을 추가 관찰했습니다. 통제실 순방향 왼쪽 이동 `Walk_Control_Forward_-0.8_10`은 000~019 전체 화면을 열어 벽·바닥·천장과 창고 진입을 확인했습니다. 아직 모든 접점과 이동 기록의 직접 검토를 마친 것은 아니므로 전체 완료 판정은 유보합니다. 원래 방의 바닥·충돌체·변환과 Pegasus는 수정하지 않습니다.

## 2026-09-23 후속 제작 및 직접 이동 확인

사용자가 각 입구가 제대로 연결되는 조건으로 창고 입구 조정을 허용한 뒤 별도 `Assets/_Project/ArtSamples/PegasusCargoConnections/PegasusCargoConnections.unity`를 제작했습니다. 아래 최초 조사 기록의 '아직 생성하지 않음'은 당시 상태이며 현재 상태가 아닙니다.

실제 실행모드에서 동력실·통제실·무기실·비품실에서 창고로 내려가는 경로를 이동하고 경로 화면을 관찰했습니다. 창고 바닥 충돌이 비활성화되어 아래로 떨어지던 문제는 샘플 창고에서 활성화한 뒤 재이동했습니다. 동력실에서 창고로 연결되는 기존 입구의 바닥 누락 구간은 새 연결부 바닥으로 보완했습니다. 기존 다섯 방 자체의 형상·변환·충돌체는 수정하지 않았습니다.

반대 방향 조종실 이동(`Walk_Cockpit_Back_0.0_2`)에서는 연결부를 지나 기존 조종실 바닥에 진입한 뒤 아래로 내려가므로 실패입니다. 화면에서 방 입구 진입을 확인한 뒤 충돌 구성을 조사했습니다. `ContactFloors.txt`와 원본을 읽기 전용으로 연 `SourcePhysics.txt`에서 조종실 `rear center stem floor slab`에 충돌체가 없음을 확인했습니다. 원본에도 동일하며 복사 누락이 아닙니다. 기존 방 바닥을 보완하는 것은 다섯 방 수정 금지 조건과 충돌하므로 실행하지 않았습니다.

전체 접합부 직접 시각 검토, 양방향 및 벽 가까이 이동 검토는 아직 끝나지 않았습니다. 생성 성공이나 일부 경로의 이동 결과는 완료/통과 판정이 아닙니다. 최종 캡처 및 Pegasus 반영은 하지 않았습니다. 기존 방 입구 바닥 충돌 보완까지 범위를 넓힐지 사용자 결정이 필요합니다.

샘플 글자 깊이 처리 컴포넌트의 에디터 어셈블리 참조 오류는 MonoScript를 통한 타입 조회로 수정했고 이후 브리지 명령이 정상 실행됐습니다. 최종 콘솔 검토는 별도로 필요합니다.

2026-09-23. 별도 샘플 제작 전 입구 및 배치 가능성 조사 단계입니다. 샘플 씬·복도·연결부는 아직 생성하지 않았고, 완료/통과 판정을 하지 않았습니다.

## 직접 관찰

실제 Unity 실행모드에서 Entrance_1~5.png로 동력실·조종실·통제실·무기실·비품실의 창고용 입구를 각각 관찰했습니다. Entrance_6.png는 창고 배치와 방향 표기 조사입니다. 수정 결과나 최종 검증 캡처가 아닙니다. 임시 관찰 카메라만 사용했고 기존 형상·조명·표시 상태는 변경하지 않았습니다. 조사 후 실행모드를 종료했습니다.

창고 일부 오브젝트 이름과 실제 방향 표기가 일치하지 않습니다. 현재 월드 기준 북쪽 CH-05는 조종실, 서쪽 CH-07은 동력실, 동쪽 CH-06은 통제실, 남서쪽 CH-08은 비품실, 남동쪽 CH-09는 무기실 입구입니다. 이름만으로 연결하면 안 됩니다.

## 보조 배치 조사와 한계

수송자 보행속도 4m/s 기준 복도 본체 경사 중심선 길이 목표는 각각 18m입니다. 연결부는 본체 길이에서 제외합니다. 창고 천장 상단 목표는 비품실 보행 바닥면보다 0.3m 아래입니다. 비품실 구조 바닥과 상부 보행판 높이는 약 0.052m 차이가 있어 구별해야 합니다.

실제 메시 끝단을 기반으로 창고의 평면 이동·회전 후보를 조사했으나 동일한 연결 거리를 충족하는 배치를 아직 확보하지 못했습니다. 중심점 간 거리 최적화 및 회전별 원 교차 탐색은 연결부 형상·폭·전체 충돌을 포함하지 않는 보조 모델입니다. 따라서 이 조사만으로 실제 복도 본체 조건의 불가능성을 증명하거나 최종 위치를 확정할 수 없습니다. 연결부를 임의로 늘려 본체 길이만 18m로 만드는 방식을 적용하지 않았습니다.

다음 결정 사항은 다섯 방·기존 연결을 고정하고 창고의 기존 입구 위치·방향도 조정할 수 있는지입니다. 기존 창고 형상을 임의로 변경하지 않았습니다. 그 범위가 확인되면 입구 기준선을 확정하고 별도 샘플을 제작한 뒤 실제 실행모드에서 연속 시야 이동 및 보행·끼임·외부 노출을 확인해야 합니다.
