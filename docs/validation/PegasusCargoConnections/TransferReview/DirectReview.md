## 직접 확인 결과

Unity 실제 실행모드에서 Pegasus의 복도 양 끝 10곳 정면(600–609), 양 끝 외측 상부(420–434의 각 5개), 외측 하부(440–454의 각 5개), 다섯 복도 내부 양방향 시점(1100–1109), 창고 내부 다섯 입구(1200–1204)를 직접 확인했습니다. 관찰한 접합부에 적용으로 새로 열린 틈이나 본체 안으로 관통한 부품은 보이지 않았습니다.

승인 샘플의 기존 600–609 이미지와 Pegasus를 직접 비교했고, 승인 샘플을 저장하지 않고 실행하여 창고 내부 같은 시점 1300–1304도 직접 비교했습니다. 벽·문틀·셔터·바닥 형상이 일치했습니다. [나란한 비교](Comparison.html)를 제공합니다. 기존 표지의 벽 너머 표시와 곡면 분할선은 이번 작업에서 바꾸지 않았습니다.

닫힌 셔터는 사용자 지시대로 외형만 옮겼습니다. 개폐 기능을 추가하거나 셔터를 숨겨 검증하지 않았으며, 현재 닫힌 상태의 통과·보행 완료를 주장하지 않습니다. 이번 적용은 관찰 카메라를 통한 직접 시각 비교입니다.

최종 확인 후 전체 배치 캡처를 한 번 수행했습니다: [최종 배치](Entrance_1500.png). 실행모드는 종료했으며 Pegasus가 저장된 깨끗한 상태로 열려 있습니다.
