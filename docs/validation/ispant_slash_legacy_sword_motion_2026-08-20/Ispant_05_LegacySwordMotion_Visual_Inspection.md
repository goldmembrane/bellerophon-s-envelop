# 이슈판트 5번 모델링 수정 전 장검 움직임 직접 대조

## 기준

- 모델링 수정 전 5번 원본: `Ispant_RunningSwordAttack.fbx`
- 원본 재생 클립: `Ispant_05_RunningSwordAttack_InPlace.anim`
- 원본 장검 회전 경로: 오른손 아래 `Ispant_ApprovedLongSword`
- 최종 비교 이미지의 위 행은 모델링 수정 전 승인 검토 이미지, 아래 행은 현재 5번입니다.
- 두 행은 왼쪽부터 `0%`, `25%`, `50%`, `75%`, `100%` 시점입니다.

## 직접 판독

- `0%`: 두 장검 모두 오른손에서 화면 왼쪽 아래로 뻗습니다.
- `25%`: 두 장검 모두 오른손 위로 수직에 가깝게 올라갑니다.
- `50%`: 두 장검 모두 몸 앞을 지나 화면 오른쪽 아래로 내려갑니다.
- `75%`: 두 장검 모두 화면 오른쪽을 향하는 낮은 후속 자세를 형성합니다.
- `100%`: 두 장검 모두 다시 화면 왼쪽 아래의 반복 시작 방향으로 돌아갑니다.
- 다섯 대응 시점의 칼날 방향 순서와 검의 롤 변화가 일치합니다.
- 현재 장검의 칼자루는 전 시점에서 현재 오른손 파지점에 붙어 있습니다.
- 현재 오른팔 애니메이션은 변경되지 않았고, 장검만 모델링 수정 전 5번의 방향 궤적을 사용합니다.
- 머스켓은 끊어지지 않았고, 얼굴·왼팔 안정 자세와 상체 중심 보정이 유지됩니다.

## 결론

직접 대조 결과 모델링 수정 전 5번의 장검 움직임이 현재 5번 장검에 재적용됐습니다. 현재 오른손 위치가 원본 모델의 오른손 위치와 다르므로 월드 좌표를 강제로 복사하지 않고, 원본 91프레임의 칼날·롤 방향을 현재 모델 공간에 옮긴 뒤 현재 오른손 파지점에서 재생합니다.
