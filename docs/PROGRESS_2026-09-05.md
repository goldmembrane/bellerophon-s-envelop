## 6개 화염방사기 상태

### `Flamethrower_Idle`

- 연료탱크는 수송자의 등 대부분을 덮는 가방 형태로 고정하고 두 연료통이 등 바깥쪽으로 세로로 나란히 향하게 했다.
- 분사 손잡이의 권총형 그립은 오른손에 놓고 방아쇠울과 방아쇠가 아래쪽을 향하도록 했다.
- 이전 `Flamethrower_Idle` 정면 시작 구도는 후속 `Baton_Idle` 시작 구도 작업에서 교체했다.

### `Flamethrower_Fire`

- `Flamethrower_Idle`과 같은 탱크·호스·손잡이 장착 상태에서 승인된 화염 방사 VFX를 분사구에 연결했다.
- 단일 발사 상태에서 `10초 분사 → 2.5초 대기 → 재분사`가 반복되며 상태 종료 시 새 방출을 중단한다.

### `Flamethrower_Remote_Mode`

- 양팔을 어깨너비로 나란히 전방으로 뻗고 양손이 연결된 전체 미니 화염방사기 조립체의 하단을 받치도록 했다.
- 탱크·연료통·밸브·호스·분사 손잡이는 서로 연결된 원본 상대 배치를 유지한다.
- 사용자가 Unity에서 직접 확정한 `MiniFlamethrower_Rig` 로컬 위치 `(-0.26830298, 1.4568014, 0.6099243)`를 편집 도구에 반영했다.

### `Flamethrower_Tank_Place`

- `Flamethrower_Remote_Mode` 자세를 `0.5초` 유지한 뒤 원본 `player model/transfer flame putting down.fbx`의 `mixamo.com` Take를 이어 재생하고 처음부터 반복한다.
- 원본 Take를 보존한 파생 `Flamethrower_Tank_Place_SymmetricPlace.anim`에서 왼팔도 오른팔과 함께 탱크를 받치며 내려가도록 구성했다.
- 양팔 최저점인 `80/146` 프레임, `2.667초`부터 연결된 전체 조립체를 수송자 앞 지면에 고정하고 오른손 추종을 해제한다. 반복 시작에서만 양손 앞 운반 자세로 복귀한다.
- 호스 스킨 부모 구조와 상대 Transform을 정상 상태와 맞춰 내려놓기 중 길게 늘어지던 직선 메시를 제거했다.

### `Flamethrower_Remote_Detonate`

- `Flamethrower_Tank_Place` 종료 자세의 연결된 조립체를 수송자 루트 기준 전방 총거리 `1m`의 지면에 배치했다.
- 원본 `item model/remote detonator.fbx`와 포함 텍스처를 `Assets/_Project/Art/Items/RemoteDetonator`에 가져왔다. 원격 기폭기 아랫부분을 오른손으로 받치고 버튼 면이 위를 향한다.
- 오른손은 시작 자세보다 전방 `30cm`, 위 `20cm` 이동하며 손바닥이 위를 향한다. 오른팔 전체의 상완 스위블과 팔꿈치 평면을 맞춰 손목·전완 메시의 꼬임을 해소했다.
- 현재 자산은 확정된 시작 정지 자세이며 후속 버튼 누르기 동작은 별도로 생성하지 않았다.

### `Flamethrower_Tank_Recover`

- 사용자가 손이 닿는 위치로 확정한 `Flamethrower_Tank_Place` 종료 지면 배치에서 시작한다. 탱크 하단 중심은 수송자 루트 기준 전방 약 `0.42221m`다.
- `Flamethrower_Tank_Place_SymmetricPlace.anim`의 전체 `4.867초`, `80`개 커브를 시간 순서만 반대로 복사한 `Flamethrower_Tank_Recover_Reverse.anim`을 재생한다.
- 최저점에서 양손이 조립체를 받치고 오른손 상대 위치를 따라 들어 올린다. 최고점에서는 탱크를 등에 고정하고 분사 손잡이만 오른손을 추종하는 `Flamethrower_Idle` 장비 상태로 전환한다.
- Idle 상태를 `0.5초` 유지한 뒤 지면 시작으로 돌아가 반복하며, 새 회차의 호스 본 기본값을 복원해 호스가 직선으로 늘어나지 않게 했다.

## 승인된 공격 화염 VFX의 Unity 적용

- `artSample/flamethrower_attack_vfx`의 승인 샘플을 Unity 파티클 프리팹 `Assets/_Project/Art/VFX/FlamethrowerAttack/FlamethrowerAttackVfx.prefab`으로 적용했다.
- 백열 중심, 고온 황색, 황금 압력층, 주황 외곽, 적색 연소층, 불티, 얇은 잔류 연기의 7개 파티클 레이어와 최대 파티클 `480`개를 사용한다.
- 화염은 분사구 바로 앞에서 수송자 전방으로만 시작하고 노랑·주황·적색 층이 이어진다. 검은 원형 구체와 뒤쪽 역분사는 포함하지 않았다.
- `FlamethrowerAttackVfx`와 `FlamethrowerAttackVfxStateBehaviour`가 사거리와 `10초/2.5초` 반복 주기를 담당하며 `Flamethrower_Fire.controller`와 씬에 연결돼 있다.
- 이번 범위는 시각 효과와 상태 재생까지이며 실제 피격, 피해, 연소 판정은 포함하지 않았다.

## 연료탱크 폭발 VFX 아트 샘플과 Unity 적용

- 신규 승인 검토용 샘플을 `artSample/flamethrower_tank_explosion_vfx`에 제작했다.
- 폭발 본체는 메시 덩어리가 아니라 머스켓 발사 계열과 같은 파티클 이펙트 문법으로 구성했다. 짧은 백열 코어, 황금·주황 고온 화염, 짙은 화약 연기, 불티와 소형 금속 파편을 사용하며 파편만 메시 사용 예외로 남겼다.
- 원격 폭파 모드는 탱크 중심에서 수평 반경과 상방 도달 높이가 모두 `6m`, 내구도 소진 자폭 모드는 모두 `15m`인 구형 시각 범위로 표현했다.
- 정점 단계와 감쇠 단계, 원격 `6m`와 자폭 `15m`를 비교할 수 있는 동적 HTML과 정적 프리뷰를 함께 보존했다. 마지막 부분에 고립된 검은 구체가 생기지 않도록 화염과 연기 전이를 연결했다.
- 사용자가 승인한 원격 `6m` 샘플을 `Assets/_Project/Art/VFX/FlamethrowerTankExplosion/FlamethrowerTankExplosionVfx.prefab`으로 만들고 `Flamethrower_Remote_Detonate`의 탱크 중심 본에 연결했다.
- 백열 점화 코어, 방사 압력광, 황금 화염, 주황 분기 화염, 적색 화염관, 짙은 화약 연기, 불티, 소형 금속 파편의 8개 레이어와 최대 파티클 `288`개를 사용한다. 파티클 본체의 지속시간은 약 `1.8초`다.
- 상태 진입 후 `1.0초`에 폭발을 시작하면서 탱크·연료통·밸브·호스·분사 손잡이가 연결된 미니 화염방사기 전체를 즉시 숨긴다. `3.0초`에 조립체를 다시 표시하고 처음부터 반복한다.
- 파티클 크기는 탱크 본 상위 스케일을 상속하지 않는 로컬 스케일로 고정했다. 방사형 텍스처의 모서리 알파를 `0`으로 생성하고 알파 블렌딩·낮은 알파 컷오프를 적용해 사각 파티클 카드가 드러나지 않게 했다.
- 실제 피해, 피아 식별, 보호막 배수, 연소와 충돌 판정은 이번 시각 효과 적용 범위에 포함하지 않았다.

## 기존 전류봉 모델 기반 전류 VFX 아트 샘플

- 브라우저 Canvas 합성으로만 동작하던 이전 샘플을 실제 Unity 재생 자산으로 교체했다. `Assets/_Project/ArtSamples/BatonElectricVfx`에 독립 런타임 어셈블리, 재생 컨트롤러, 활성화·방출 프리팹, 최초 시안의 5중 색층에 대응하는 전류 머티리얼 5개와 샘플 씬을 생성했다.

## 승인된 전류 모드 활성화 VFX의 Baton 상태 적용

- 사용자가 `artSample/baton_electric_vfx`의 불규칙 연속 활성화와 단일점 수렴형 방출 샘플을 승인했다. 이번 단계에서는 지시된 활성화 효과만 실제 Baton 상태 개체에 연결했으며 방출 효과 연결은 수행하지 않았다.
