- 허리띠·파우치·버클은 제거하고 가슴 대각선 스트랩은 유지했습니다. 얼굴 패턴은 눈 중앙에서 급격히 상승한 뒤 완만해지고 다시 상승해 외곽까지 이어지는 승인 형태를 적용했습니다.
- 몸통 흰색 장갑 평균 명도는 사용자 지정에 따라 기준 대비 25% 상승하도록 보정했고 Helmet과 초승달의 기존 밝기는 분리 보존했습니다.
- 현재 Unity 정적 이슈판트를 `enemies model/Ispant_Static.fbx`로 내보냈고, 눈 메시가 초승달 위로 이탈하던 내보내기 배율 문제를 교정했습니다.
- 이슈판트 애니메이션 슬롯 12개의 영문 이름을 사용자 확정 순서대로 저장했습니다.
- `Ispant_02_Idle`에는 2초 주기, 최고점–최저점 총 1.5cm, 양발 고정, 몸통·머리·팔·머스켓 동반 이동 대기 모션을 적용했습니다.
- `Ispant_03_Move`는 사용자 제공 `enemies model/išpant walking.fbx`의 Mixamo 동작을 사용합니다. 외형은 정적 이슈판트 머티리얼을 직접 참조하며 임의 생성하지 않았습니다.
- 이동 개체의 몸체 높이를 정적 개체와 같은 `1.02430773m`로 맞췄고 바닥 높이 차이는 `0m`입니다.

- 머스켓은 정적 FBX의 154삼각형 형상을 `mixamorig:Spine2`에, 장검은 정적 FBX의 78삼각형 형상을 `mixamorig:Hips`에 강체 연결했습니다. 부모 기준 변형 오차는 모두 `0`이며 몸통을 따라 이동합니다.
