## 샘플 제작 전에 확정이 필요한 항목

- 동력실의 실제 위/아래/옆 통로가 현재 선박 모델 좌표에서 어느 방향인지 확인해야 합니다.
- 원통형 동력기계의 정확한 높이, 직경, 천장/바닥 관통 여부는 원본에 없습니다.
- 손전등 충전 앵커와 사보타주 해제 앵커는 원본 기능은 명시되어 있지만 외형과 위치가 명시되어 있지 않습니다.
- 동력실 통제 모드는 업그레이드 기능으로 명시되어 있으나, 동력실 내부에 별도 장치가 필요한지는 아직 확정되지 않았습니다.
- 암전, 오버클럭, 파괴 상태는 이후 샘플에서 정상/손상/과출력 버전을 같이 비교할 수 있어야 합니다.
