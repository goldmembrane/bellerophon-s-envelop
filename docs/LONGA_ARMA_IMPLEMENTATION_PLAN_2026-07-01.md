# Longa Arma Implementation Plan 2026-07-01

## 문서 목적

이 문서는 파르붐, 푸가 다음 씨앗체로 `롱가 아르마(Longa Arma)`를 구현하기 위한 계획서다. 현재 문서는 구현 작업이 아니라, 원본 기획서와 기준 이미지를 대조해 이후 샘플 제작, Unity 적용, 애니메이션, 검증 범위를 명확히 정리하는 계획 단계 산출물이다.

## 적용 규칙

- 대화와 작업 기록은 한국어 존댓말을 기준으로 유지한다.
- 롱가 아르마는 적대 개체이므로 실제 Unity 씬, 프리팹, 런타임 자산에 연결하기 전에 `artSample/enemies/longa_arma/` 아래에 검사 가능한 샘플을 먼저 제작하고 사용자 승인을 받아야 한다.
- 승인된 샘플은 분위기 참고가 아니라 Unity 재현 대상이다.
- Unity 적용 단계에서는 승인 샘플의 실루엣, 비율, 주요 부위, 표면 재질, 텍스처, 카메라 기준을 반복 비교해야 한다.
- 런타임 루트 이동은 `Rigidbody + Collider` 기준으로 처리하고, 단순 `transform.position` 직접 이동을 기본 구현으로 삼지 않는다.
- 기능형 애니메이션은 정적 비교 상태 1개체와 대기, 이동, 공격, 피격, 사망, 섭취 상태를 분리해 확인 가능하게 구성한다.
- 기존 Harness/EditMode/PlayMode/Build 검증은 사용자가 명령명과 대상 범위를 명시적으로 승인한 경우에만 실행한다.

## 원본 기획서 기준 사양

- 분류: 적대 개체, 씨앗체
- 이름: 롱가 아르마
- 개념: 한쪽 팔이 비정상적으로 거대한 긴 팔 개체
- 외형: 4발로 기어다니는 짐승형, 왼쪽 팔이 비정상적으로 길고 칼 같은 형태
- 크기: 높이 약 80cm, 가로 약 70cm, 세로 약 150cm
- 이동속도: 3
- 체력: 110
- 1순위 목표: 금속
- 공격 사거리: 3~4
- 공격 데미지: 30
- 공격 딜레이: 2.5초
- 공격 형태: 대상에게 접근한 뒤 상체를 들어올리고, 상대를 향해 긴 팔을 내려찍는 형태
- 화물선 상호작용:
  - 화물선 내부 시설은 금속으로 취급하므로 기본 공격 대상이 된다.
  - 방치 시 해당 구역 내구도를 감소시킨다.
  - 운송 화물이 금속 재질일 경우 섭취 행동으로 운송 화물 내구도를 감소시킬 수 있다.
  - 운송 화물에는 파괴 부위를 발생시키지 않는다.
  - 일정 시간 이상 공격받은 구역에는 파괴 부위가 발생할 수 있다.
  - 화물선 내 금속 섭취 도중 공격받으면 타겟을 공격한 대상으로 변경한다.

## 2026-07-01 사용자 확정 사항

- 긴 무기 팔은 Unity 모델 로컬 기준 `왼팔`로 둔다.
- 공격 판정은 긴 왼팔 칼날의 내려찍기 순간에만 발생한다.
- 내려찍기 공격 판정 데미지는 30이다.
- 내려찍기 이후 칼날이 바닥을 쓸거나 회수되는 구간에는 공격 판정을 넣지 않는다.
- 사망 연출은 온몸이 점액처럼 녹아내리는 방향으로 구현한다.
- 기능형 애니메이션에 섭취 상태를 추가한다.
- 금속 화물 섭취는 이후 화물 로직과 상호작용할 수 있게 연결 지점을 준비하되, 현재 계획 단계에서는 임의의 금속 화물 로직을 새로 확정하지 않는다.

## 기준 이미지 분석

### 공통 실루엣

- 전체 실루엣은 말 또는 대형 사족 짐승을 닮은 긴 몸체다.
- 목과 머리가 길고, 머리 위에는 뾰족한 귀 또는 짧은 뿔처럼 보이는 돌출부가 있다.
- 뒷다리는 일반적인 사족 보행 짐승의 뒷다리 비율을 유지한다.
- 앞다리 중 한쪽, 특히 왼쪽 앞팔이 비정상적으로 길게 늘어나 있으며 몸 전체 길이의 핵심 실루엣을 만든다.
- 긴 팔 끝에는 검은 금속성 또는 단단한 껍질성 초승달형 칼날이 붙어 있다.
- 칼날은 바닥 가까이까지 내려오며, 공격 시 내려찍기 동작의 주 타격 부위로 보인다.

### 정면 이미지 기준

- 몸체는 정면에서 비대칭이다. 긴 왼팔과 칼날이 한쪽으로 크게 벌어져 전체 폭을 넓힌다.
- 머리와 흉부는 중앙에 있고, 긴 팔은 앞쪽 대각선으로 뻗어 있다.
- 칼날은 검은색에 가까운 어두운 재질이며, 가장자리에 밝은 반사선이 있다.
- 녹색 점액이 몸체와 칼날에서 아래로 흘러내린다.

### 측면 이미지 기준

- 세로 길이는 긴 몸통과 뒤로 뻗은 뒷다리, 앞으로 길게 뻗은 왼팔 때문에 매우 길다.
- 왼팔은 어깨에서 팔꿈치, 손목이 명확히 구분되는 일반 팔이라기보다, 근육과 점액이 늘어난 긴 절단 무기 지지대처럼 보인다.
- 칼날은 초승달 또는 낫 형태이며, 바닥에 닿을 정도로 아래쪽 곡률이 크다.
- 머리는 말처럼 길고 아래로 점액이 떨어진다.

### 후면 이미지 기준

- 등과 골반은 녹색 점액성 근육 덩어리처럼 보인다.
- 꼬리 또는 꼬리처럼 보이는 후면 돌출부가 짧게 아래로 흐르고, 점액이 길게 떨어진다.
- 후면에서도 긴 왼팔과 칼날이 한쪽으로 빠져나가 비대칭성을 유지한다.
- 다리 아래에는 점액 웅덩이와 방울이 남는다.

### 재질과 텍스처 기준

- 주요 몸체 재질은 어두운 녹색, 회녹색, 청록색이 섞인 젖은 유기질 표면이다.
- 표면에는 마블링처럼 흐르는 무늬, 불규칙한 밝은 점액 자국, 어두운 근섬유 같은 굴곡이 필요하다.
- 점액은 단순 선이 아니라 표면에서 흘러내리는 방울, 얇은 줄기, 바닥 웅덩이로 표현한다.
- 칼날은 몸체와 다른 어두운 검정/흑회색 재질이며, 날 끝과 절단면에 반사와 마모가 있어야 한다.
- 단색 머티리얼이나 임시 기본 셰이더만으로는 완료로 보지 않는다.

## 기능형 애니메이션 계획

### 2026-07-02 애니메이션 재구성 원칙

2026-07-02 Unity 적용 검토에서 이동/공격을 Unity Editor C# 코드로 `.anim` Transform 커브를 직접 생성하는 방식은 롱가 아르마에 맞지 않는 것으로 확인했다. 특히 다리 본의 `localPosition`을 임의로 밀어 사족보행처럼 보이게 만드는 방식은 발 접지, 관절 회전, 체중 이동이 맞지 않아 이동/공격 개체가 제대로 서 있지 못했다. 이후 이동/공격 애니메이션은 기존 방식으로 재시도하지 않는다.

다음 구현에서는 상태별 애니메이션 적용 방식을 분리한다.

- 슬라임형/액체형 변형: Shape Key 또는 BlendShape 사용 가능
  - 대기 호흡의 몸통 팽창/수축
  - 피격 시 살덩이 움찔/표면 출렁임 보조
  - 사망 시 액체화와 웅덩이화
- 팔다리/관절 기반 동작: Armature, IK, baked bone animation 사용
  - 이동 사족보행
  - 공격 준비, 상체 기립, 왼팔 칼날 내려찍기
  - 섭취의 머리/목 젖힘과 전방 내리찍기
  - 피격의 머리/목/몸통 recoil 주 동작

Unity C#에서 이동/공격 `.anim` 커브를 직접 생성하는 코드는 앞으로 승인용 또는 최종 모션 제작 방식으로 사용하지 않는다. Unity는 Blender에서 제작해 bake/export한 Action을 가져와 배치하고 검증하는 용도로 사용한다.

### 다음 구현 절차: Blender IK/Action 기반

1. `artSample/enemies/longa_arma/runtime_lowpoly/blender/longa_arma_runtime_lowpoly.blend`를 기준 파일로 연다.
2. 먼저 애니메이션용 기준 서기 포즈를 만든다.
   - 몸통이 바닥에 무너져 있지 않아야 한다.
   - 세 정상 다리와 칼날 왼팔의 접지 기준을 분리한다.
   - 이동/공격 시작 프레임은 이 기준 서기 포즈에서 출발해야 한다.
3. 사족보행용 IK 리그를 구성한다.
   - 각 정상 다리: upper leg, lower leg, foot, foot target, pole target
   - 칼날 왼팔: blade shoulder, blade forearm, blade tip, blade contact target
   - 몸통: root, pelvis/spine, chest, neck/head
4. 이동 Action을 Blender에서 제작한다.
   - 발 타겟은 접지 구간에서 바닥에 고정한다.
   - 스윙 구간에서만 발을 들어 앞으로 보낸다.
   - 항상 최소 2개 이상의 지지점이 바닥에 남아 있어야 한다.
   - 칼날 왼팔은 정상 다리처럼 걷지 않고, 늦고 무겁게 끌리거나 찍히는 보조 지지부로 처리한다.
   - 몸통은 발 접지 리듬에 맞춰 낮은 상하/좌우 체중 이동을 한다.
5. 공격 Action을 Blender에서 제작한다.
   - 기준 서기 포즈에서 시작한다.
   - 뒤다리와 몸통 하부가 먼저 체중을 버틴다.
   - 상체가 들어올라 말 기립 이미지처럼 큰 실루엣 변화를 만든다.
   - 오른 앞다리와 왼쪽 칼팔이 위로 올라간다.
   - 왼쪽 칼날과 오른 앞다리가 전방으로 내려찍는다.
   - 내려찍은 뒤 바닥을 끌며 회수하고 다시 기준 사족 자세로 돌아온다.
6. Blender에서 Action을 bake한 뒤 FBX로 export한다.
   - Unity에서 이동/공격은 bake된 bone animation을 사용한다.
   - 이동/공격 클립에는 `blendShape.Move_*`, `blendShape.Attack_*` 커브를 만들지 않는다.
7. Unity 적용 단계에서는 다음만 수행한다.
   - FBX 애니메이션 import
   - `LongaArmaApproved.prefab`에 Animator/Controller 연결
   - 정적, 이동, 공격 개체 배치
   - 발 접지, 뒤다리 지지, 상체 기립, 칼날 내려찍기 시각 검증

### 내일 구현 시작 전 확인 사항

- 현재 `CargoRunMvp`의 이동/공격 검토 개체는 잘못된 애니메이션 포즈를 제거하기 위해 `StaticReviewClipName`으로 되돌려 둔 상태다.
- 기존 `LongaArma_Move_LimpingBladeArm.anim`, `LongaArma_Attack_Slam.anim`은 삭제하지 않았지만, 씬 배치 기준으로는 더 이상 신뢰하지 않는다.
- 다음 작업은 새 `.anim` 커브를 Unity C#에서 만드는 것이 아니라, Blender 파일에서 기준 서기 포즈와 IK 리그를 먼저 확정하는 것부터 시작한다.
- Unity 검증은 Blender Action이 나온 뒤에 수행한다. Blender에서 서기/이동/공격 포즈가 무너지면 Unity로 가져가지 않는다.

- 정적 상태는 비교 기준이므로 루트 이동과 보조 흔들림을 적용하지 않는다.

### 대기 상태

- 네 다리로 낮게 버티고 있는 자세를 유지한다.
- 흉부와 긴 목이 느리게 들썩인다.
- 긴 왼팔과 칼날 끝은 무겁게 처진 상태에서 약하게 흔들린다.
- 점액 방울은 시각 보조로 흔들리거나 늘어질 수 있지만, 실제 런타임 이동 루트와 충돌하지 않도록 분리한다.

### 이동 상태

- 사족 보행을 기본으로 한다.
- 루트 이동은 `Rigidbody.linearVelocity` 또는 동등한 물리 기반 이동으로 처리한다.
- 긴 왼팔은 보행 다리처럼 완전히 동일하게 움직이지 않고, 무거운 무기 팔처럼 끌리거나 늦게 따라오는 보조 움직임을 가진다.
- 칼날은 바닥 가까이 흔들리되, 몸체와 분리되어 떠 보이면 안 된다.

### 공격 상태

원본 기획서의 핵심 모션인 “접근 후 상체를 들어올리고 내려찍기”를 기준으로 한다.

공격 단계:

1. 목표 사거리 3~4m 안에서 공격 준비에 들어간다.
2. 앞다리와 흉부가 버티고, 상체가 위로 들린다.
3. 긴 왼팔이 뒤쪽 또는 위쪽으로 크게 당겨져 칼날이 명확한 예비 동작을 만든다.
4. 몸통이 앞으로 기울며 긴 왼팔과 칼날이 대상 방향으로 내려찍힌다.
5. 칼날이 내려찍히는 순간에만 데미지 30 공격 판정을 활성화한다.
6. 내려찍은 뒤 칼날이 바닥을 쓸거나 회수되는 구간은 후속 모션으로만 두고 공격 판정을 넣지 않는다.
7. 내려찍은 뒤 무거운 팔이 바닥 가까이 떨어지고, 몸체가 다시 사족 자세로 복귀한다.

공격 검증 조건:

- 이동 모션보다 큰 실루엣 변화가 있어야 한다.
- 칼날 끝의 이동 경로가 정면 또는 대상 방향으로 명확히 내려찍혀야 한다.
- 몸체만 흔들리고 칼날이 따라오지 않는 상태는 실패로 본다.
- 긴 왼팔 루트가 몸체 어깨에서 떨어져 공중에 떠 있으면 실패로 본다.
- 내려찍기 순간 외의 바닥 쓸림/회수 구간에 공격 판정이 있으면 실패로 본다.
- 데미지 30, 딜레이 2.5초, 사거리 3~4, 내려찍기 전용 판정 구간은 런타임 데이터 또는 문서화된 설정값으로 추적한다.

### 피격 상태

- 오브젝트가 깨지거나 부품이 분리되어 보이면 안 된다.
- 피격 방향으로 몸체가 약간 밀리고, 긴 왼팔과 칼날이 관성으로 늦게 흔들린다.
- 행동이 잠깐 굼떠지는 recoil/slowdown 성격을 가진다.

### 사망 상태

- 사족 몸체가 무너지고 긴 왼팔과 칼날이 먼저 또는 함께 바닥에 떨어진다.
- 최종 연출은 온몸이 점액처럼 녹아내려 낮게 퍼지는 형태로 정착한다.
- 사망 후 반복 검토가 필요하면 리뷰용 루프와 최종 정지 포즈를 분리한다.
- 녹아내림은 몸체, 다리, 목, 긴 왼팔이 함께 무너지는 하나의 사망 연출로 구성한다.
- 칼날은 점액처럼 녹이지 않고 어두운 단단한 무기 재질을 유지한 채 바닥에 남긴다.

### 섭취 상태

- 금속 대상에 접근해 머리와 긴 목을 낮추고, 입 또는 주둥이 부근으로 금속을 뜯어먹는 의도를 보여준다.
- 긴 왼팔과 칼날은 섭취 중 공격 무기로 사용하지 않고, 바닥 가까이 내려놓거나 몸체 옆에 무겁게 고정한다.
- 섭취 애니메이션은 이후 금속 화물 로직과 연결될 수 있도록 상태 이름, 타이밍, 타겟 앵커를 분리해 둔다.
- 현재 단계에서는 금속 화물 재질 판정이나 내구도 감소 수치를 새로 확정하지 않고, 나중에 로직으로 상호작용할 수 있는 구조를 남긴다.

## 물리/리깅 구조 계획

- 루트 이동: `Rigidbody + Collider`
- 충돌 기준: 몸체 전체를 포괄하는 기본 Collider와, 내려찍기 순간에만 활성화되는 칼날 공격 판정용 별도 hit volume
- Motion Path: 실제 이동이 아니라 이동 목표 또는 검토 경로 기준으로만 사용
- Animation Rigging:
  - 머리/목 시선 보정
  - 긴 왼팔 끝점 또는 칼날 끝점 제어
  - 네 다리 접지 보정
- ConfigurableJoint:
  - 긴 왼팔과 칼날의 무게감 있는 추종이 필요할 때 검토
  - 과도하게 흔들려 공격 판정과 충돌하면 사용하지 않는다.
- Jiggle Physics 또는 동등 보조 물리:
  - 점액 방울, 표면 흐름, 칼날에 달린 점액 줄기에 제한적으로 사용
  - 같은 Transform을 AnimationClip, Rigidbody, IK, Jiggle이 동시에 직접 움직이지 않도록 역할을 분리한다.
