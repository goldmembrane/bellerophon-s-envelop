# 그라베 애니메이션 목록

## 문서 목적

이 문서는 원본 기획서와 현재 프로젝트 규칙을 기준으로 그라베에 필요한 애니메이션 상태를 정리한 계획 문서다. 애니메이션 구현 승인이나 Unity 적용 승인을 의미하지 않는다.

- `docs/GAME_DESIGN_SOURCE.txt`

  - 휴대용 스피커 반응: 178행
- `docs/MVP_IMPLEMENTATION_ORDER.md`
  - 13단계에서 구체 개체의 이동·공격 모션은 원본 또는 레퍼런스 확인 후 확정하도록 규정한다.
- `AGENTS.md`
  - 적대 개체 기능형 상태는 정적 비교, 대기, 이동, 공격, 피격, 사망을 분리해 확인하도록 규정한다.
  - 피격은 약간 물러나는 반응과 굼떠짐이 보여야 하며, 루트 이동은 `Rigidbody + Collider` 기준으로 처리하도록 규정한다.

  - 현재 Unity에는 `Approved Grave Enemy Placement/Grave_00_Static` 정적 개체만 배치되어 있다.

## 원본에서 확인된 그라베 행동

- 장중하고 느린 중대형 개체다.
- 이동속도는 `1.5`다.
- 상대 앞에서 오른팔을 들어 올린다.
- 들어 올린 오른팔이 거대한 팔로 변형된다.
- 변형된 팔을 앞으로 인사하듯 내려휩쓴다.
- 공격할 때 절삭력이 높은 반달 모양 칼 형태가 나타난다.
- 공격 시간은 `3초`, 공격 후 연사 딜레이는 `2초`다.
- 공격이 시작되면 상대가 시야에서 벗어나도 공격 모션이 끝날 때까지 계속 실행한다.
- 휴대용 스피커가 작동하면 전원을 끄고, 스피커 주변에 `10초` 동안 머문 뒤 다른 곳으로 이동한다.
- 상태이상 피해를 `1.5배`로 받고, 상태이상 지속시간이 `2배`가 되는 것은 능력치 규칙이다. 별도 모션은 명시되어 있지 않다.

## 공격 애니메이션 구성 원칙

`Grave_03_Attack_RightArm_GiantSweep`는 원본에서 하나의 공격 모션으로 설명되므로 여러 전투 클립으로 임의 분할하지 않는다. 하나의 클립 또는 하나의 연속 상태 안에서 다음 단계를 분명히 보여줘야 한다.

1. 준비: 상대 앞에서 오른팔을 들어 올린다.
2. 변형: 오른팔이 거대한 팔로 변하며 반달 칼 형태가 드러난다.
3. 타격: 상체와 오른팔이 앞으로 내려가며 전방을 휩쓴다.
4. 종료: 총 `3초` 안에 공격 동작을 마친다.

공격 후 `2초` 연사 딜레이는 다음 공격을 막는 게임 상태 시간이다. 원본이 별도 회복 모션을 명시하지 않았으므로 `5초`짜리 공격 클립으로 늘리거나 별도의 `Attack_Cooldown` 애니메이션을 만들지 않는다. 딜레이 중에는 기본적으로 대기 상태를 재사용하되, 다른 연출이 필요하면 구현 전에 사용자 확인을 받는다.

## 휴대용 스피커 반응 구성

휴대용 스피커 반응 전체를 모두 새 클립으로 만들 필요는 없다.

1. 스피커 쪽으로 이동: `Grave_02_Walk_Slow` 재사용
2. 전원 끄기: `Grave_06_Speaker_PowerOff` 사용
3. 주변에 10초 상주: `Grave_01_Idle` 재사용
4. 다른 곳으로 이동: `Grave_02_Walk_Slow` 재사용

따라서 `Speaker_Guard_10s`, `Speaker_Leave` 같은 별도 애니메이션은 현재 목록에 추가하지 않는다. `10초`는 애니메이션 길이가 아니라 AI 상태 지속시간이다.

## 별도 애니메이션으로 만들지 않는 항목

- `Attack_Cooldown`: `2초` 게임 상태이며 별도 모션이 명시되지 않았다.
- `StatusAilment_Reaction`: 상태이상 피해 `1.5배`, 지속시간 `2배`는 수치 규칙이다.
- `Speaker_Guard_10s`: 대기 애니메이션을 재사용한다.
- `Speaker_Approach`, `Speaker_Leave`: 느린 이동 애니메이션을 재사용한다.
- `Spawn` 또는 `Invasion`: 외계 생명체의 화물선 부착·침입은 공통 설정이지만 그라베 전용 등장 모션은 원본에 없다.

## 구현 전에 사용자 확인이 필요한 사항

- 대기 상태의 구체적인 장중함 표현
- 느린 이동의 보폭과 긴 팔의 물리적 흔들림
- 공격 3초 안의 준비·변형·타격·종료 시간 배분
- 오른팔 거대화 배율과 반달 칼의 정확한 실루엣
- 피격 모션의 크기와 지속시간
- 사망 방식과 최종 자세
- 스피커 전원을 끄는 팔, 자세, 조작 방식

이 항목들은 원본에 구체적인 동작이 없으므로 애니메이션 구현 승인 전에 사용자에게 하나씩 확인해야 한다.

## 구현 시 기술적 제한

- 실제 이동은 `Rigidbody + Collider`와 `FixedUpdate`가 담당하고, 이동 애니메이션이 런타임 루트 Transform을 직접 이동시키지 않는다.
- 오른팔 거대화와 반달 칼 변화는 현재 FBX 리그·메시 구조를 먼저 검사한 뒤 뼈, BlendShape 또는 승인된 기능형 방법 중 적합한 방식을 선택한다.
- 같은 Transform을 AnimationClip, Rigidbody, IK, Joint가 동시에 직접 움직이지 않게 역할을 분리한다.
- 실제 Unity 적용 전에는 대상 슬롯, 클립, 개체 수, 명령, 검증 범위를 별도 묶음으로 승인받는다.
