## 반영 내용

- 플레이어 리그에 검지 관절이 없음을 확인해, 8개 상태 모두에서 실제 스킨 메시의 오른손 손바닥이 방아쇠 아래가 아니라 머스켓 기준 방아쇠 오른쪽 표면을 덮도록 보정했다.
- `Musket_Draw`, `Musket_Idle`, `Musket_Stow`, `Musket_HipFire`, `Musket_Aim`, `Musket_Aim_Fire`, `Musket_Aim_Exit`의 양손 파지 구간에서 왼손 장갑 윗면이 머스켓 총신 전방 아래 표면에 밀착해 지지하도록 보정했다.
- `Musket_Stow`에서 머스켓이 등으로 전환된 뒤 양쪽 어깨·팔·전완·손이 `Hands_Empty_Idle` 자세로 자연스럽게 복귀하도록 했다.
- `Musket_Reload`은 왼팔과 손목이 머스켓 왼쪽 외부를 지나고, 손 메시의 손가락 영역이 장전부 표면에 접근→접촉→당김→해제→복귀하도록 보정했다.
- `Musket_Draw`은 머스켓 가시성 전환 순간부터 오른손 손바닥 파지에 완전히 고정해 꺼내는 동안 공중에 뜨지 않게 했고, 왼손은 별도 단조 접근 가중치와 안정된 팔꿈치 평면으로 총신 아래까지 이동하게 했다.
- `Musket_Stow`은 처음에만 왼손이 총신 아래를 지지하고, 오른팔이 등 뒤로 이동하기 전에 왼손이 머스켓에서 떨어져 `Hands_Empty_Idle` 왼팔 자세로 복귀하도록 했다.
- `Musket_Reload` 장전 구간의 팔꿈치 pole을 프레임 간 최대 5도로 연속 제한하고 한 프레임의 IK 반복에서 같은 굽힘 평면을 유지해 왼팔 뒤틀림과 떨림을 제거했다.
- 손 접촉 검증은 손목 본이 아니라 실제 변형된 스킨 메시 표면과 머스켓의 방아쇠 오른쪽 면·총신 아래·장전부 표면 구간 사이 거리로 계산하도록 변경했다.
- 기존 몸통·하체 원본 구간, 대상 루트, 등 뒤 머스켓 배치와 다른 애니메이터는 유지했다.

- 샘플 경로: `artSample/musket_muzzle_flash/`
- 다중 시점 체적 시안: `artSample/musket_muzzle_flash/renders/01_volumetric_multiview.png`
- 1인칭 게임 시안: `artSample/musket_muzzle_flash/renders/02_first_person_gameplay.png`
- 원본 기획서의 양손 머스켓, 화면 중앙 발사, HipFire 조준선 없음, 정밀 조준 시 조준 UI 기준을 유지했다.
- 현재 Unity 리뷰 모델 길이 1.12m가 원본 기획서의 0.8m 정의와 달라, 효과 크기는 현재 모델 총 길이에 대한 비율로 제안했다.
- 제안 수치는 최대 섬광 약 0.45m, 연기 외곽 약 0.65m, 섬광 약 0.06초, 연기 소멸 약 0.65초다.
- 평면 별 모양 시안을 폐기하고, 깊이 있는 황백색 연소체와 자체 음영의 짙은 회백색 난류 연기 입자군으로 교체했다.
- 두 시안은 OpenAI 내장 이미지 생성 도구로 만든 3D 콘셉트 렌더이며 실제 Unity 씬·머스켓 FBX 렌더가 아님을 샘플에 명시했다.
- 다중 시점과 1인칭 시안을 직접 확인해 총구 부착, 섬광 두께, 연기 깊이·자체 음영, 전방·상방 팽창과 약 6% 화면 점유를 확인했다.
- 사용자가 샘플을 승인해 승인 상태를 `승인됨 · Unity 적용 완료`로 갱신했다.
- `Assets/_Project/Art/VFX/MusketMuzzleFlash/`에 128×128 소프트 불꽃·연기 마스크 아틀라스 각 하나, 공유 머티리얼 3개, 작은 불티 메시와 재사용형 프리팹을 만들고 `Assets/_Project/Scripts/VFX/`에 런타임 제어와 발사 상태 동작을 추가했다.
- `Musket_HipFireLoop`와 `Musket_Aim_FireLoop`의 정규화 시간 0.08에 같은 총구 프리팹이 한 번씩 재생되도록 연결했다.
- 사용자 피드백에 따라 각진 연기 메시와 고정 화염·내부 가스 메시를 제거했다. 화염과 내부 가스는 네 가지 소프트 불꽃 마스크를, 연기는 네 가지 다엽형 소프트 연기 마스크를 서로 다른 위치·크기·회전으로 겹치는 Billboard 파티클 군집으로 교체했다. 작은 불티만 메시를 유지했으며, 화염 3, 내부 가스 6, 연기 14, 불티 12로 대상별 설정 상한을 35개로 제한했고 실제 두 자연 발사 루프의 최대 동시 파티클은 두 대상 모두 34개였다.
- 파티클 4계통은 발사마다 생성·삭제하지 않고 계속 재사용하며, 레이마칭, 동적 그림자, 파티클 그림자, 모션 벡터, 노이즈를 사용하지 않는다. 짧은 총구 라이트는 그림자 없이 동시 4개, 연기 효과는 동시 6개로 제한했다.
- FBX 부모 스케일로 연기 메시가 거대해지는 현상은 파티클 스케일 모드를 `Local`로 고정해 제거했고, 화염 기본 Shape를 꺼 총구 원점 밖 임의 위치에서 생성되지 않게 했다.
- 반복 발사 시 발생한 `Particle Velocity curves must all be in the same mode` 오류는 연기 Velocity over Lifetime의 X/Y/Z를 모두 같은 두 상수 모드로 통일해 수정했다. 최종 보강 적용 뒤 두 발사 상태를 반복 재생했으며 기존 마지막 오류 110452행 이후 새 동일 오류는 0건이었다.
- 기존 로컬 총구 위치 `z=0.017`에 포함됐던 전방 오프셋 0.012를 제거하고, 실제 총구 구멍 끝점 `z=0.005`에 직접 고정했다. 실제 Play Mode 전체·근접 측면·근접 정면·머스켓 근접 구도에서 총열 끝이 화염 중심과 맞닿고 공중 간격이 없음을 확인했다.
- 실제 Play Mode에서 각 대상의 자연 발사 루프를 두 번 이상 관찰했다. 황백색 화염 핵, 금빛 내부 가스, 소프트 연기 조각의 3D 군집과 불티가 전체·측면·정면·사선 시점에서 돌 같은 고정 표면 없이 팽창·소멸하고 화면 전체를 가리지 않음을 확인했다.
- 리뷰 캡처는 두 자연 발사의 예약 프레임 6개를 모두 소진하고 한 번의 복구 발사를 허용하도록 보강해, 5/6 프레임에서 조기 실패하던 비결정적 캡처를 안정화했다.
- 두 대상 모두 총구 로컬 위치·회전 변화량 0, 총구 표면 간격 0m, 네 파티클 계층 관찰, 설정 상한 내 파티클 유지와 수치 검사를 통과했다.
