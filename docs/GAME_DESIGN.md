# Game Design

Bellerophon의 현재 방향은 1인칭 3D 우주 화물 운송 협동 생존/공포 게임이다. Lethal Company는 그래픽 질감, 조명, 폐쇄적인 분위기, 협동 중 긴장감의 레퍼런스로만 사용한다. 탐사/회수, 할당량, 폐건물 스캐빈징 루프를 핵심 게임 구조로 채택하지 않는다.

## 확정된 방향

- 장르: 1인칭 우주 화물 운송 협동 생존/공포
- 카메라 시점: 1인칭
- 비주얼 레퍼런스: 낮은 채도의 산업/폐쇄 공간, 어두운 조명, 거친 표면감, 제한된 시야
- 분위기 레퍼런스: 불확실한 위협, 팀원 간 거리감, 소리와 시야 부족에서 오는 긴장
- 핵심 목표: 행성에서 준비한 화물 또는 의뢰 화물을 목적지까지 최대한 손실 없이 운송한다.
- 세션 목표: 화물선 운행을 완료하고 도착 정산에서 수익을 남긴다.
- 실패 조건: 배상, 수리, 보험, 견인, 부활 비용을 지불할 돈이 없으면 게임 오버다.
- Steam 출시 범위: Windows 우선, Steam 기능은 플랫폼 인터페이스 뒤로 격리

## 확정 필요 항목

- 핵심 30초 루프의 정확한 조작 밀도
- 네트워크 방식과 최대 인원
- 화물선 6구역의 최종 공간 치수와 이동 동선
- 위험 상황, 침입자, 화물선 손상 간 우선순위
- 장비, 상호작용, 업그레이드 진행 메타
- 상호작용 입력 맵과 UI 표현

## MVP 정의

첫 번째 MVP는 다음 조건을 만족해야 한다.

- 플레이어가 1인칭으로 이동하고 둘러볼 수 있는 상태로 시작한다.
- 최소 하나의 튜토리얼 운송 의뢰가 있다.
- 최소 하나의 화물과 화물선 구역 내구도가 있다.
- 최소 하나의 운행 중 위험 요소가 화물선 손상을 만든다.
- 도착 정산과 돈 부족 게임오버가 화면에 표현된다.
- Lethal Company풍의 어두운 저채도 조명과 폐쇄적인 분위기가 플레이 중 확인된다.
- Windows 개발 빌드가 생성된다.
- 핵심 로직에 EditMode 테스트가 있다.
- 주요 런타임 흐름에 PlayMode Smoke 테스트가 있다.
