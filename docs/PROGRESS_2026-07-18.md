## 이전 실패 기록 - Ostinato 샘플 제작 방식 오류와 Unity 적용 실패

- 사용자가 요구한 Ostinato 샘플은 Blender에서 실제 3D 모델, UV, 텍스처, 머티리얼을 구성해 제작했어야 한다. 그러나 현재 `artSample/enemies/ostinato/` 샘플은 기존 `Ostinato.fbx`의 정면·측면·후면 캡처 실루엣에 기준 이미지 픽셀을 2D 합성한 결과이며, 재현 가능한 `.blend`, 샘플용 `.fbx`, `.glb` 모델이 없다.
- 따라서 사용자가 승인한 이미지는 실제 Unity용 3D 자산이 아니라 2D 합성 이미지였고, 승인된 샘플을 Unity 모델에 그대로 옮길 수 있다는 이전 판단은 잘못됐다. 이 방식은 적대 개체 샘플에 Blender 원본/내보내기 파일과 실제 텍스처·머티리얼 적용을 요구하는 규칙을 충족하지 못한다.
- Unity 적용 과정에서는 먼저 승인 이미지 픽셀을 기존 FBX UV에 베이크했고, 이후 정면·측면·후면 이미지를 커스텀 셰이더로 직접 투영하는 방식까지 시도했다. 현재 9개 Ostinato에는 이 실험용 직접 투영 머티리얼이 연결돼 있다.

- 아래의 기존 `최신 완료` 판정, `APPROVAL_STATUS.json`의 `unity_runtime_applied=true`, 내부 통과 수치와 적용 보고는 현재 상태의 완료 근거로 사용할 수 없다. 이번 커밋은 실패 상태와 작업 이력을 보존하는 중간 체크포인트이며, 잘못된 투영 적용을 복구하거나 수정하지 않는다.
- 작업을 재개할 경우 기존 FBX 형상·리그 유지 조건을 지키면서 Blender에서 실제 UV·텍스처·머티리얼이 포함된 3D 샘플을 먼저 다시 제작하고 사용자 승인을 받은 뒤, Unity 적용을 별도 범위로 진행해야 한다.
