# Progress 2026-06-02

이 문서는 2026-06-02까지 진행한 Bellerophon MVP 구현 상태와 이어서 작업할 때 먼저 확인해야 할 사항을 정리한다.

## 반드시 먼저 확인할 것

- 이어서 작업하기 전 이 문서와 `docs/MVP_IMPLEMENTATION_ORDER.md`, `docs/GAME_DESIGN_SOURCE.txt`를 함께 확인한다.
- 열린 Unity 에디터가 있으면 닫지 말고 열린 에디터 브리지와 기능별 smoke 검증을 사용한다.
- 원본 기획서에 없거나 애매한 기능은 임의로 보강하지 않는다. 구현 전에 사용자에게 확인한다.
- 화물은 보상/운송 대상/상태 대상이다. 플레이어가 화물을 직접 집거나 내려놓는 상호작용은 현재 MVP 범위가 아니다.
- 납품/정산은 목적지 도착 후 세션 상태 기준으로 자동 처리하는 방향이다.

## 완료된 단계

### 0단계: 하네스 기반

- 열린 Unity 에디터를 감지해 batchmode 대신 에디터 브리지로 검증하는 흐름을 마련했다.
- `UnityEditorValidationBridge`와 기능별 smoke 스크립트를 추가했다.
- 생성물(`Library`, `Temp`, `Logs`, `Builds`, `TestResults`, `SceneTemplateSettings.json`)은 커밋 대상에서 제외하고 직접 편집하지 않는 규칙을 유지한다.

### 1단계: 세션과 상태 모델

- `GameSessionState`, `ShipState`, `CargoState`, `WalletState`, `SettlementCalculator` 기반을 만들었다.
- 운송 시작/완료/실패, 정산 입력과 결과를 EditMode 테스트로 검증했다.

### 2단계: 1인칭 플레이어 MVP

- 1인칭 플레이어 이동, 카메라 회전, 상호작용 감지, HUD 기본 표시를 구성했다.
- Ctrl 앉기 전환이 너무 끊겨 보이는 문제를 `SmoothDamp` 기반으로 수정했다.
- 시작 UI 같은 포인터 기반 UI가 뜬 동안에는 1인칭 커서 잠금/시점 이동을 일시 정지할 수 있게 했다.

### 3단계: 상호작용 시스템

- `IPlayerInteractable` 기반 공통 상호작용 계약을 만들었다.
- 같은 대상에 디버그 상호작용과 장치 상호작용이 함께 있을 때 장치 상호작용을 우선하도록 정리했다.

### 4단계: 화물선 6구역 Graybox

- 조종실, 운송창고, 무기실, 비품실, 동력실, 통제실 6구역을 구현했다.
- 운송창고는 다른 구역보다 낮은 위치에 두고 경사 복도로 연결했다.
- 운송창고 중앙 화물, 각 방 장치 placeholder, 방향 표지, 주요 복도 연결을 배치했다.
- 통행을 막던 벽은 제거했고, 무기실-운송창고 복도는 곡선 궤도로 수정했다.
- 현재 Armory-Cargo Hold 경로는 20개 segment 곡선 복도이며, 무기실 모서리와 겹치지 않도록 조정되어 있다.

### 5단계: 화물선/화물 상태 모델

- 6구역 내구도, 평균 내구도, 수리비, 총 손실, 견인/출발 제한, 화물 손실률 규칙을 추가했다.
- `ShipStateRules`, `ShipRepairCostProfile`, `ShipStartAssessment`를 통해 순수 로직 테스트가 가능하게 했다.

### 6단계: 방별 상호작용 1차

- 조종대, 동력실 스크린, 통제실 메인 스크린, 무기실 포탑 핸들, 비품창고, 운송창고 화물 상태 장치를 추가했다.
- 통제실 CCTV 전환 입력은 원본 기준대로 A/D를 사용한다.
- 동력실 오버클럭은 운행당 1회 사용 상태를 기록한다.
- 각 장치는 최소 UI panel을 통해 현재 상태를 표시한다.

### 7단계: 기본 시작 세팅과 튜토리얼 의뢰

- 새 게임 시작 흐름을 `NewGameStartFlowState`와 `NewGameStartFlowController`로 추가했다.
- 협회 계약 최소 UI에서 `Yes`를 누르면 협회 로고 행성 시작 상태로 전환된다.
- 시작 상태는 기본 화물선, 기본 방호복, 막대기 1개, 돈 0이다.
- 첫 의뢰는 60초짜리 협회 튜토리얼 의뢰 1개만 노출한다.
- 튜토리얼 의뢰 수락 시 `Cargo Hold Center Cargo`가 세션 운송 대상으로 등록되고 세션은 `Transporting`이 된다.
- UI는 실제 마우스 클릭 경로로 검증한다. 계약/의뢰 UI가 떠 있는 동안 커서는 보이고 잠금 해제된다.
- 튜토리얼 의뢰 수락 후 검은 계약 UI 박스는 닫히고 1인칭 플레이 커서 잠금으로 복귀한다.
