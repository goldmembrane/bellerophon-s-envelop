- `SettlementDebtStatus`를 추가해 정산 후 잔액 상태를 정상, 첫 마이너스 유예, 최종 게임오버로 분리했다.
- 정산 후 첫 마이너스 잔액은 `WalletState.HasUnpaidDebtGrace`로 남기고 세션을 `Completed`로 유지해 다음 운행 시작을 허용한다.
- 다음 운행 정산 후에도 잔액이 마이너스이면 세션을 `GameOver`로 전환한다.
- 정산 입력에 협회 기본급, 거리 산정 비용, 수리비 지원금, 근속 보너스, 화물선 보험 지급, 화물 손실 패널티, 청소 비용, 사망자 생명 보험 비용, 협회 알선비/유지비를 반영할 수 있게 했다.
- 튜토리얼 의뢰 정산은 거리비 산식이 아니라 고정 보상 $1000과 협회 소속 추가 보너스 $100을 적용해 총 $1100을 지급한다.
- 화물선 평균 내구도에 따른 보험 지급 구간과 견인 비용은 정산 지급/차감에 연결했다.
- 구역별 수리비와 총파손 비용은 정산에서 차감하지 않고 정비 단계에서 청구될 예정 수리비로 산출·표시하도록 분리했다.
- 운행 완료 시 `TransportSettlementController`가 정산 UI를 자동으로 열고, 결과 금액과 항목별 계산 근거를 표시한다.
- 마이너스 확정 게임오버 시 플레이어 조작을 억제하고, 전체 화면 컷씬에서 화물선과 버려지는 포드를 보여준 뒤 게임오버 화면으로 전환한다.

- 포탑 화면에서는 마우스 조준, 좌클릭 단발/누르고 있기 연속 발사, R 재장전, ESC 종료를 처리하고 1인칭 이동/상호작용 입력을 억제한다.
- 원본 기획서 기준 수동 포탑 연사 딜레이는 0.25초다.
- 기본 포탑은 탄창 50발, 재장전 2초, 발당 50 피해 규칙을 사용한다.
- 소행성 지대 발생 시 seed 기반 외부 소행성 목표를 생성하고, 포탑으로 목표를 파괴하면 위험 결과가 `Neutralized`가 되어 선박 손상과 정비비가 발생하지 않는다.
- 목표를 파괴하지 않고 위험 시간이 끝나면 기존 11단계 규칙대로 선박 구역 손상이 발생해 정산의 예정 수리비와 정비 화면 수리비로 이어진다.
- 포탑 모드 중 침입자 피격 가능 상태는 `IntruderHitPossible` 상태값으로만 남겼고, 실제 침입자 전투 연결은 이후 단계로 남겨 두었다.

- 구체 침입자 최종 외형, 공격 모션, 실제 전투 연결, 씨앗체 하위 개체 선택은 아직 구현하지 않았고 이후 단계에서 사용자 확인 후 진행한다.

### 14단계: 첫 침입자 씨앗체 구현

- 14단계 MVP 첫 씨앗체를 파르붐 1종으로 구현했다.
- `SeedIntruderState`, `SeedIntruderTickResult`, `SeedIntruderRules`를 추가해 씨앗체 발생 판정, 파르붐 정의, 이동/공격/처치 상태를 순수 로직으로 관리한다.
- 씨앗체는 튜토리얼 첫 운행에서는 발생하지 않고, 후속 운행 중 2초마다 15% 확률로 발생 판정을 수행한다.
- 파르붐은 외부 목표를 만들지 않는 내부 침입자로 생성되며, 외부 포탑 요격 대상이 되지 않는다.
- 파르붐 원본 수치 중 체력 55, 이동속도 2.5, 사거리 1, 공격 딜레이 0.5초를 반영했다.
- 파르붐의 선박 설비 공격은 원본의 비생체 대상 피해값을 적용해 0.5초마다 목표 구역 내구도 3을 감소시키며, 이 손상은 도착 정산 후 정비 수리비로 남는다.
- 현재 화물 모델에는 재질 필드가 없으므로 파르붐의 금속 화물 섭취 행동은 임의 구현하지 않고, 화물 재질 모델이 생길 때 다시 연결한다.
- 활성/해결된 파르붐 상태는 운행 HUD에 표시되며, 검증 경로에서는 처치 후 추가 피해가 멈추는지 확인한다.
- 활성 파르붐은 `SeedIntruderVisualView`가 방별 graybox 앵커에 월드 placeholder로 표시하고, 처치되면 즉시 숨긴다. 최종 생물 외형과 공격 모션은 이후 전투/아트 단계에서 교체한다.

### 15단계: 무기류와 비품실 기본 루프

- 장비 상태 모델 `PlayerEquipmentState`와 무기/장비 정의 `EquipmentRules`를 추가해 세션 저장 대상에 기본 방호복, 손 슬롯 기본 3칸, 비품창고 3칸, 활성 손 슬롯, 사용 쿨다운을 포함했다.
- 협회 시작 장비는 기본 방호복 착용과 막대기 1개 지급으로 연결했다.
- 막대기는 원본 기획서 수치대로 피해 30, 사거리 2~3, 사용 딜레이 2.5초, 우클릭 투척 모드 골격을 반영했다.
- 머스킷은 원본 기획서 수치대로 피해 50, 사거리 5~7, 사용 딜레이 3.5초, 정밀 조준 모드, 가격 $450을 반영했다.
- 머스킷 탄창 크기와 장전 시간은 아직 확정하지 않았다. R 재장전 입력과 HUD 표시는 골격만 두고, 실제 수치는 사용자 확인 후 확정한다.
- 비품실 보관함 HUD는 기본 방호복, 손 슬롯, 비품창고 3칸, 마지막 장비 행동을 표시한다.
- 정비 화면 상점에서 Buy/Sell 탭 골격을 열 수 있고, 막대기/머스킷 구매와 치료/강화/기타 데이터 전용 항목, 개인 화물 판매 데이터 전용 항목을 표시한다.
- 14단계 파르붐과 연결해 막대기 및 머스킷 명중 시 침입자 체력을 차감하고, 체력이 0 이하가 되면 파르붐을 처치 상태로 전환한다.
- 치료, 강화, 기타 물품의 실제 기능과 개인 화물 판매 로직은 데이터 구조만 두고 이후 단계로 남겼다.
