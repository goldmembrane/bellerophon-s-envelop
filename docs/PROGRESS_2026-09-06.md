## `Baton_Discharge_Exit` Mode 전체 동작 정확한 역재생 반복 연결

- 사용자 확인에 따라 `Baton_Discharge_Mode.controller`가 실제 참조하는 원본 Mixamo Take와 기존 `0.5초` 전환 클립을 `Baton_Discharge_Exit`에 동일 자산으로 직접 연결했다. 새 애니메이션 클립이나 커브를 생성하지 않고 `Mixamo Take 역재생 → 0.5초 전환 역재생` 순서로 배치해 마지막 방출 자세에서 `Baton_Idle` 자세로 돌아온 뒤 처음부터 반복한다.
- 두 상태는 각각 기존 클립의 끝에서 시작해 `-1` 배속으로 재생한다. 첫 설정에서 역재생 종료 경계를 `exitTime=-1`로 요청했지만 Unity가 지원 범위인 `0`으로 직렬화해 보조 게이트가 중단됐고, Unity의 실제 역재생 종료 경계인 `0`을 명시해 동일 구성을 정상 저장했다. 이 과정에서 원본 모션과 씬의 메시·리그·VFX는 변경하지 않았다.
- 첫 실제 Play Mode 검토에서 동작 자체는 정확히 역순으로 보였지만 보조 비교식이 `speed=-1` 상태의 `normalizedTime`도 음수로 감소한다고 잘못 해석해 위치 `0.091753m`, 회전 `63.229515°`의 가짜 오차를 기록했다. Unity는 상태 진행률을 `0→1`로 증가시키고 모션 샘플만 역방향으로 진행하므로 비교식만 바로잡았으며 적용 애니메이션은 변경하지 않았다.
- 1순위 직접 확인으로 실제 Play Mode `2.021955회`, `13개` 시점을 정면·측면·후면 사선·상체 확대 구도에서 확인했다. 마지막 방출 자세에서 Mixamo 동작이 역순으로 풀리고, 마지막 `0.5초`에 `Baton_Idle` 자세로 복귀한 뒤 방출 자세부터 다시 반복된다. 팔·몸통·전류봉의 튐, 중간 끊김, 메시 변형은 보이지 않았고 전류봉은 오른손을 계속 추종했다. 최종 확인본은 `docs/validation/baton_discharge_exit_reverse_2026-09-06/final.png`, Mode 정방향과 Exit 역방향 나란한 비교본은 같은 폴더의 `mode_reverse_comparison.png`다.
- 2순위 보조 확인에서 실제 런타임 포즈와 두 원본 클립의 대응 역재생 포즈 차이는 위치·회전 모두 전 구간 `0`이다. 두 클립의 연결 경계 차이도 `0`이고, 기존 `Baton_Discharge_Mode` 컨트롤러·0.5초 전환 클립·원본 Mixamo FBX·전류봉 FBX 해시는 적용 전후 동일하며 전류봉 아래 `55개 LineRenderer` 구성도 유지됐다.

## Baton 전류 모드 활성화 VFX 적용 범위 교정

- 대상은 `Baton_Idle`, `Baton_Swing_Right`, `Baton_Discharge_Mode`, `Baton_Discharge_Fire`, `Baton_Discharge_Exit`의 기존 `BatonChargeReadyVfx`다.
