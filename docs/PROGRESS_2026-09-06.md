# Bellerophon 진행 기록 — 2026-09-06

## Baton 전류 모드 활성화 VFX 적용 범위 교정

- 대상은 `Baton_Idle`, `Baton_Swing_Right`, `Baton_Discharge_Mode`, `Baton_Discharge_Fire`, `Baton_Discharge_Exit`의 기존 `BatonChargeReadyVfx`다.
- 사용자 확인으로 전류봉과 오른손 배치는 정상임을 확정하고, 승인된 활성화 VFX의 적용 범위만 교정했다. 시작점은 검은 손잡이 상단 경계에 유지하고 VFX의 전류봉 장축 방향 스케일만 실제 최상단 집전부까지 닿도록 맞췄다. 장축과 직교하는 두 축의 실제 크기는 유지했다.
- 승인된 `BatonChargeReadyVfx.prefab`의 전류 형태·색·불규칙 점멸 동작은 수정하지 않았다. 전류봉 모델, 메시, UV, 리그, 텍스처, 머티리얼, 오른손 상대 Transform, 수송자 자세와 애니메이션도 변경하지 않았다.
- 1순위 직접 확인으로 승인 샘플 `artSample/baton_electric_vfx/unity_charge_ready.png`과 실제 다섯 상태의 동일 시점 캡처 `docs/validation/baton_charge_vfx_range_correction_2026-09-06/final.png`을 비교했다. 모든 상태에서 전류가 검은 손잡이 상단부터 금속 봉 전체와 최상단 집전부까지 이어지고, 전류봉·오른손·수송자 메시의 분리·늘어짐·꼬임·변형이 없음을 확인했다.
- 2순위 보조 확인에서 다섯 상태의 VFX 시작점 오차는 `0m`, 최상단 오차는 최대 `0.000000238m`였다. 각 상태의 전류봉 상단 적용 길이는 약 `0.68m`이며 예상 길이와 일치했다. 전류봉 로컬 Transform, 대상 루트, 모든 Animator 할당, 승인 프리팹 SHA-256은 전후 동일하고 각 VFX의 `LineRenderer`는 기존 `55개`로 유지됐다.
- 적용 명령은 `ApplyBatonChargeVfxFullUpperRange`, 직접 검토 명령은 `CaptureBatonChargeVfxFullUpperRangeReview`를 사용했다.
- 사용자가 직접 명령명과 대상 범위를 지정하지 않은 Harness, EditMode, PlayMode 테스트 스크립트 및 Windows Build는 실행하거나 결과를 확인하지 않았다. Git 작업도 수행하지 않았다.
