# 진행 기록 2026-06-16

## 오늘 작업 범위

- 화물선 전체 모델링 기준 작업을 중단하고, 조종실을 작은 단위로 나누어 샘플 승인 후 Unity에 조립하는 방식으로 전환했다.
- 기존 화물선 전체 비주얼 모델링은 모델링 확인 작업에서 보이지 않도록 비활성화하는 흐름을 유지했다.
- 튜토리얼 흐름은 모델 확인을 방해하지 않도록 꺼두고, 플레이 중 자유 시점으로 확인할 수 있는 모델링 검사 카메라를 추가했다.
- 조종실 구조, 전면 파노라마 화면, 조종대, 경고등, 방향 라벨을 `artSample/` 승인 흐름에 맞춰 제작한 뒤 승인된 항목만 Unity에 반영했다.

## 적용된 조종실 항목

- CK-01 전면 유리창 / 전방 파노라마 화면: 5분할 창문을 제거하고 큰 전면 화면으로 Unity에 배치했다.
- CK-02 / CK-03 메인 조종대와 조작부: 낮은 조종대 본체, 타륜형 핸들, 오른쪽 전진 레버 형태로 제작해 Unity에 적용했다.
- CK-04 경고등: 좌우 보조 경고등은 제외하고, 스크린 위 경고등 바와 조종실 천장 중앙 비상 경고등 본체만 적용했다.
- CK-11 방향 표시 / 방 라벨: 왼쪽 동력실, 오른쪽 통제실, 뒤쪽 운송창고 방향을 표시하는 라벨을 Unity에 적용했다.
- `docs/COCKPIT_OBJECTS.md`에 조종실 오브젝트 목록과 제외/이관 항목을 따로 저장했다.

## 제외 및 이관 결정

- CK-05 화물선 전개도 / 내구도 표시 패널은 수동 조종 모드에서만 보이는 UI/HUD로 처리하기로 하고 조종실 모델링 오브젝트에서 제외했다.
- CK-06 자동 조종 상태 / 복구 패널, CK-07 긴급 수리 장치, CK-08 일반 수리 장치는 장치 쪽 작업으로 이관했다.
- CK-10 침입 감지 경고는 시각 경고 없이 사운드 경고로만 처리하기로 하고 모델링 오브젝트에서 제외했다.

## 중요 이슈

- CK-11 방향 라벨 위치를 사용자가 Unity 에디터에서 직접 편집한 뒤 스크립트에 반영하는 과정에서, 현재값 캡처 후 `Run-ApprovedCockpitDirection.ps1`를 실행해 라벨 루트가 재생성되었다.
- 그 결과 사용자가 직접 맞춘 라벨 위치가 덮어써졌고, 이 문제는 복구 완료로 기록하지 않는다.
- 이후 같은 상황에서는 재생성 스크립트를 실행하기 전에 각 오브젝트의 계층 경로, `localPosition`, `localRotation`, `localScale`을 먼저 별도 파일로 저장해야 한다.
- 사용자 편집값 반영 요청이 있을 때는 `Ensure` 계열 재생성 명령을 실행하지 말고, 현재 씬 값을 읽어 스크립트 상수만 갱신하는 절차를 먼저 사용해야 한다.
