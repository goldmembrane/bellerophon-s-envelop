이 문서는 원본 기획서 `docs/GAME_DESIGN_SOURCE.txt`와 구현 순서 문서 `docs/MVP_IMPLEMENTATION_ORDER.md`를 기준으로 무기실 모델링에 필요한 구조와 오브젝트를 정리한 작업 목록입니다. 실제 Unity 씬, 프리팹, 런타임 자산에 반영하기 전에는 필요한 항목별로 `artSample/`에서 검사 가능한 샘플을 만들고 사용자 승인을 받아야 합니다.

## 범위

- 포함: 무기실 내부 룸 셸, 중앙 기둥, 기둥 후면 계단, 포탑 핸들, 전면 가로 커브형 대형 스크린, 비품실/통제실/운송창고 방향 출입구와 복도 연결부, 무기실 손상 상태를 보여줄 수 있는 시각 요소.
- 제외: 실제 포탑 조준/발사 로직, 포탑 수동 모드 UI, 외부 선체 포탑 모델, 소행성/침입선/외계 생명체 외부 목표 모델, 조종실/동력실/통제실/비품실/운송창고 자체 오브젝트 수정, Unity 배치, 테스트/검증 실행.
- 기준: 원본에 명시된 항목은 확정으로 기록하고, 원본 기능에는 필요하지만 구체 외형이 없는 항목은 확인 필요로 분리합니다.

## 공간 구조 요약

- 무기실은 개인 무기 보관실이 아니라 화물선 포탑을 운용하는 방으로 해석합니다.
- 방의 중심 기준 오브젝트는 중앙 기둥입니다.
- 기둥 뒤편에는 기둥 위로 올라가는 계단이 있습니다.
- 계단을 통해 기둥 상부로 올라가면 포탑 핸들이 있습니다.
- 기둥 앞쪽, 즉 포탑 운용자가 바라보는 정면 벽에는 가로 커브형 대형 스크린이 있습니다.
- 대형 스크린은 화물선 정면 시야를 보여주는 장치입니다.
- 스크린 벽을 정면으로 보는 기준에서 뒤쪽은 통제실 복도입니다.
- 스크린 벽을 정면으로 보는 기준에서 오른쪽은 비품실 복도입니다.
- 비품실 복도 바로 옆에는 운송창고 복도가 있습니다.
- 운송창고로 이어지는 복도는 아래로 경사가 있습니다.

## MVP 구현 순서 대조

- 4단계 Graybox에서는 무기실의 중앙 기둥, 포탑 핸들, 전면 스크린 자리, 비품실/통제실/운송창고 연결 방향이 우선입니다.
- 6단계 방별 상호작용 1차에서는 무기실 포탑 핸들에 F 상호작용 프롬프트와 포탑 수동 모드 진입 틀이 필요합니다.
- 12단계 수동 포탑과 외부 목표에서는 조준, 발사, 탄창, 재장전, 외부 목표 피격 판정을 구현합니다.
- 15단계 무기류와 비품실 기본 루프의 휴대 무기들은 무기실 고정 오브젝트가 아니라 아이템/비품실 작업으로 분리합니다.

## 모델링 우선순위

1. AR-01~AR-09: 무기실 룸 셸, 중앙 기둥, 계단, 포탑 핸들 위치, 전면 커브형 스크린, 3방향 출입구와 운송창고 경사 복도까지 한 번에 구조 샘플을 제작합니다.
2. AR-10: CR-17과 같은 방향 표시 레이블 스타일로 무기실 출입구 방향 표기를 정리합니다.
3. AR-12: 정상 룸 셸 승인 후 포탑 조종대 파손/폭파 상태 샘플을 별도로 제작합니다.
4. AR-13~AR-16: 포탑 기능 상태 표시는 물리 모델보다 UI/상태 표시 성격이 강하므로 후속 작업으로 분리합니다.

## 샘플 제작 전 확인 필요 항목

- 무기실 첫 샘플에서 천장을 포함할지, 통제실 샘플처럼 천장을 제외하고 내부 구조를 먼저 보여줄지 확인이 필요합니다.
- 중앙 기둥 후면 계단을 직선 계단, 나선 계단, 사다리형 계단 중 어떤 형태로 만들지 확인이 필요합니다.
- 기둥 상부 조작 발판과 난간을 둘지 확인이 필요합니다. 원본에는 발판/난간 외형이 없지만 플레이어 이동과 안전한 시각 구조에는 필요할 수 있습니다.
- 포탑 핸들의 외형을 선박 조타륜, 양손 조작 그립, 회전 핸들, 레버 콘솔 중 어느 쪽으로 잡을지 확인이 필요합니다.
- 가로 커브형 대형 스크린의 곡률, 폭, 높이, 화면 재질, 기본 화면 내용을 확인해야 합니다.
- 운송창고 방향 경사 복도의 길이와 높이 차는 전체 선박 복도 스케일과 맞춰야 합니다.
- 무기실에 개인 무기 진열 랙이나 탄약 보관함을 넣을지 확인이 필요합니다. 원본 기준으로는 개인 무기 보관은 비품실 기능이므로 기본 무기실 샘플에는 넣지 않습니다.

## Unity 반영 전 주의사항

- 이 문서는 목록 정리 문서입니다. 아직 무기실 샘플 제작, Unity 배치, 런타임 연결은 하지 않았습니다.
- 무기실 모델링은 먼저 `artSample/`에 검사 가능한 샘플로 만들어야 합니다.
- 샘플 승인 전에는 `CargoRunMvp` 씬, 런타임 프리팹, UI 흐름, 상호작용 로직에 연결하지 않습니다.
- 승인된 샘플을 Unity에 반영할 때는 오브젝트 존재 여부가 아니라 승인 샘플과의 시각적 일치도를 기준으로 확인합니다.
- 무기실 작업은 기존 조종실, 동력실, 통제실 오브젝트와 현재 통제실 복구 스냅샷을 임의로 수정하지 않는 별도 범위로 진행합니다.
