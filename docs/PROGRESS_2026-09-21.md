- 현재 공간을 기준으로 Unity 적용형 천장 아트 샘플을 `Assets/_Project/ArtSamples/ShipSpaceCeilings/`와 `artSample/ShipSpaceCeilings/`에 제작했습니다. 방 6개와 복도 10개를 대상으로 본체·입구·복도 천장을 구성하고 기존 프로젝트 머티리얼을 재사용했습니다.
- 입구 천장은 각 입구 벽 상단 높이에 맞췄고, 경사 복도 천장은 원본 복도와 같은 `5.344374도` 기울기를 유지했습니다. 무기실·비품실·통제실 입구 천장 위의 열린 면은 수직 마감 벽으로 막았습니다. 동력실은 지름 `8.800001m` 원형 천장과 세 입구 전체를 덮는 천장을 적용했습니다.
- 사용자 승인 후 샘플에서 지시된 천장·마감 조각 53개만 실제 `CargoRunMvp` 대응 공간 아래에 적용했습니다. 기존 공간 오브젝트 790개의 상태와 지시하지 않은 샘플 요소는 변경하지 않았습니다.
- 직접 확인에서는 방 6개, 복도 10개, 입구 보강 13개를 상부·실내 하부·측면에서 비교했습니다. 입구 높이 오차와 경사 복도 회전 오차는 `0`, Unity 콘솔 오류는 `0`이었습니다.

## 수평 복도 길이와 세 공간실 연결 배치

- 현재 플레이어 설정의 보행 속도 `4m/s`와 평균 이동 시간 5초를 기준으로 기울기 없는 `SC-H01~05`의 가시 길이를 각각 `20m`로 맞췄습니다. 바닥·양측 벽·외부 천장은 길이축만 연장했고, 기존 끝단을 양끝으로 이동한 뒤 원본 리브 간격을 따라 복도별 연장 리브 12개를 추가했습니다. 단면과 경사 복도 `SC-S01~05`는 변경하지 않았습니다.
- 동력실·조종실·통제실과 `SC-H01`, `SC-H02`, `SC-H05`의 첫 정렬 결과는 각 복도 양끝 간격이 `4.30872m`, `0.56889m`, `19.62456m`로 달라 사용자의 직접 확인에서 기각했습니다. 이 결과를 완료 상태로 남기지 않고 세 공간실 루트의 수평 위치와 대상 복도의 위치·회전만 다시 계산했습니다.
- 최종 공간실 루트는 동력실 `(-26.31523, 3.17, 15.98706)`, 조종실 `(-1.155731, 2.649, 63.11723)`, 통제실 `(32.64646, 2.66, 25.71863)`입니다. 동력실 왼쪽·조종실 위쪽·통제실 오른쪽이라는 배치도 관계를 유지합니다.
- 실제 Pegasus 씬의 전체 조감도와 세 연결부 확대를 먼저 직접 확인해 복도 양끝 간격의 균일성, 공간실·복도·중앙 창고·비대상 공간과의 비관통을 판정했습니다. 보조 수치는 여섯 간격 `1.000000~1.000007m`, 전체 편차 `0.000007m`, 중심선 각도 오차 `0도`, 최대 횡방향 오차 `0.000004m`, Unity 콘솔 오류 `0`입니다.
- 공간실 회전·높이·내부 상대 Transform, 복도 길이·단면·끝단·내부 리브, 비대상 공간실과 `SC-H03`, `SC-H04`, `SC-S01~05`는 변경하지 않았습니다. 공간실과 복도 사이를 메우는 별도 연결 조각도 아직 제작하지 않았습니다.
