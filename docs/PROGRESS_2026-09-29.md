## 롱가 아르마의 플레이어 공격 접촉 처리 지연 개선

- 실제 키보드·마우스 입력으로 막대기 1회 명중 후 롱가의 연속 반격을 유도했다. 실행 화면에서 기존 왼팔 칼날 동작을 직접 확인했으며, 반복 공격 피해와 플레이어 사망 후 금속 섭취 복귀를 확인했다. 원본 모델·클립·공격력·주기는 변경하지 않았다.
- 매 공격 프레임 전체 정점마다 뼈 계층과 이름을 재탐색하던 처리를 렌더러/메시별 캐시로 변경했다. 기존 가중치 조건을 만족하는 모든 칼날 정점을 그대로 사용하며, 현재 접촉과 이전 프레임부터의 이동 접촉 검사를 유지한다. 재사용 정점 버퍼와 칼날 정점만의 좌표 변환으로 반복 배열 생성 및 불필요한 변환도 줄였다.
- 이번 측정은 이전의 플레이어 막대기 처리 측정과 다르게 롱가 자신의 LateUpdate 공격 접촉 처리다. 수정 전 최대 76.125ms, 수정 후 첫 실행 최대 4.354ms, 재실행 최대 1.457ms였다. 각각 Logs/LongaAttackBaseline.log, LongaAttackFixed2.log, LongaAttackRepeat.log에 기록했다. 수정 후 두 실행에서 실제 피해가 적용됐다.
- 전체 프레임 최대값은 수정 후 24.523ms 및 83.319ms로, 에디터 관찰/캡처를 포함한 다른 비용까지 섞여 있다. 따라서 전체 게임의 모든 끊김 제거 또는 일정 FPS 보장을 주장하지 않는다. GC 계측값은 신뢰성을 추가 확인하지 않아 무할당의 증거로 사용하지 않는다.
- 최종 캡처를 한 번 실행했다. 종료 확인 Logs/LongaAttackFinalState.log: Pegasus, Play=False, Pause=False, dirty=False, compiling=False, 콘솔 오류·경고 0. 에디터 재시작, 자동 테스트 스크립트, 빌드, Git 커밋·푸시는 하지 않았다.

## Pegasus 롱가 아르마 AI 적용

- `CargoRunMvp`의 `Approved Longa Arma Enemy Placement`에서 기존 상세 리그 모델과 Idle, Move Crawl, Attack Slam Drag, Hit Recoil, Consume Peck, Death Melt Puddle 동작을 확인했다. 원본 모델·씬·클립은 수정하지 않았다.
- Pegasus에서 `Fuga Gameplay 01`을 삭제하지 않고 비활성화하고, 같은 시험 위치의 바닥에 `Longa Arma Gameplay 01`을 배치했다. 수송자 시작 위치와 겹치지 않는다. 별도 게임플레이 프리팹을 저장했다.
- 체력 110, 이동속도 3, 모든 대상 타격 피해 30, 왼팔 칼날 애니메이션 메시 접촉 판정, 타격 주기 2.5초, 금속 감지 5m, 공간실 내구도 500/23초 및 금속 화물 초기 내구도/48초의 직접 섭취, 피격 때마다 공격자 재지정, 12m·시야 추적 포기, 스피커 반응, 실제 공간실 문 경계부터 2m 전진을 구현했다. 수송자 막대기 근접·투척 피격 대상으로도 연결했다.
- 기존 샘플의 공격·피격·섭취·사망 컨트롤러가 현재 상세 리그와 다른 구형 클립을 참조해 동작 시간이 흘러도 뼈가 움직이지 않는 문제를 발견했다. 동일 FBX에 들어 있는 상세 리그용 원본 동작을 Pegasus 전용 `.anim` 복사본과 override controller로 연결했다. 원본 클립과 `CargoRunMvp`는 그대로 두었다.
- 처음에는 칼날 상승 여부로 접촉을 제한했으나 원본 동작이 측면 휘두르기여서 타격이 누락됐다. 실제 애니메이션 칼날 메시의 현재·이전 프레임 접촉으로 판정하게 고쳤고, 접근 간격을 조정했다. 실행모드에서 휘두르는 동작을 직접 본 후 플레이어 보호막이 50→20으로 감소하고 왼팔 칼날 메시가 플레이어 표면에 닿은 상태를 확인했다. 거리에만 의존한 피해는 적용하지 않았다.
- 실행 화면에서 원본 모델의 이동·벽 섭취·왼팔 공격·사망 동작을 전면과 측면에서 직접 확인했다. 창고 벽 내구도는 현재 동작으로 474→174까지 감소했다. 창고 및 조종실 출입문의 실제 경계를 지난 뒤 각각 약 2.004m, 2.008m 전진하고 금속 탐색·섭취로 이어지는 것을 확인했다. 창고 내구도가 소진된 뒤 조종실로 이동해 벽을 섭취하는 모습도 직접 확인했다.
- 사망 직후 충돌체가 꺼졌고, 사망 동작 후 5.279초 시점에 개체가 제거된 것을 확인했다. 원본 사망 클립 길이는 2.750초이며 제거 대기는 그 뒤 1.5초다.
- 최종 캡처 `Logs/PegasusLongaArmaFinal.png`는 기둥이 모델을 가려 증거로 쓰기 어렵다. 규칙상 최종 캡처를 반복하지 않았다. 이전 실행 직접 관찰 이미지와 실시간 화면 판정이 모델링·애니메이션 검증 근거다.
- 실제 수송자 조작으로 막대기 명중, 스피커 파괴, 화물 직접 섭취, 모든 출입문 조합은 이번에 직접 재현하지 않았다. 연결 코드와 규칙은 구현했지만 이 항목들을 시각 검증 통과로 보고하지 않는다.
- 열린 Unity 에디터의 브리지와 `./scripts/Refresh-UnityProject.ps1`를 사용했다. 에디터 재시작은 하지 않았다. 종료 직전 `Pegasus` 실행모드 `False`, 일시정지 `False`, 씬 dirty `False`, 컴파일 중 `False`, 콘솔 오류·경고 0건을 확인했다.
- 사용자 지시가 없는 Harness·EditMode·PlayMode·Build 검증 및 Git 커밋·푸시는 실행하지 않았다. 기존 사용자 수정으로 보이는 조종실 머티리얼과 `artSample/` 변경은 건드리지 않았다.

## 롱가 아르마 섭취 재이동·옆걸음·막대기 타격 지연 수정

- **이전 리그 분석 정정:** 위 기록의 “상세 리그에 맞지 않는 구형 클립”이라는 판단은 잘못됐다. `CargoRunMvp` 슬롯에는 비활성 구형 리그와 실제 표시되는 `LongaArmaWalkingFbx_Model/char1`이 함께 있다. 이전 구현은 첫 Animator/Renderer 검색으로 숨겨진 구형 리그를 선택했다. 따라서 그 리그를 기준으로 한 방향·입·칼날 검증 결과를 실제 표시 모델의 검증 근거로 취급하지 않는다.
- 실제 표시 모델의 기존 Animator·원본 걷기/섭취/피격/공격 클립을 선택하도록 수정했다. 숨겨진 상위 Animator는 비활성화하고 잘못 연결했던 gameplay override 참조를 끊었다. `CargoRunMvp`, 원본 모델·애니메이션 에셋은 수정하지 않았다.
- Pegasus와 gameplay prefab의 표시 모델을 원본 +Z 정면으로 맞췄다. 이동 방향으로 회전하기 전에 횡이동하지 않도록 했으며, 섭취 중 애니메이션 입 위치에 따라 목표/경로를 계속 재선정하던 동작을 제거했다. 입의 정면 거리뿐 아니라 좌우 치우침도 접근 위치에 반영하고, 도착 후 벽 법선 방향으로 정렬한다.
- 입은 표시 리그의 `headend`, 왼팔 칼날은 원본 공격 제작 코드에서 사용한 `R_frontleg` 계열로 연결했다. 공격 접근 거리는 원본 공격을 일회성 복사본에서 샘플링한 칼날 메시 도달거리 약 1.019m를 사용한다. 피해는 여전히 실제 애니메이션 칼날 메시 접촉이 있어야 발생하며, 접근 거리만으로 피해를 주지 않는다.
- 막대기 판정은 표시 메시를 대상으로 한다. 상태 슬롯 변경 시 서로 다른 렌더러 사이의 가짜 이동 보간을 없앴다. 상태별 메시 공간 분할을 준비·재사용하고 현재/이전 프레임으로 경계를 갱신하며, 실제 막대기 근처의 삼각형만 시간 보간 접촉 검사한다. 정점 버퍼를 재사용하고 좌표 변환 및 경계 갱신 비용을 줄였다. 몸체 접촉 가능성이 있는 모든 샘플에서는 기존 벽 가림/물리 차단을 유지한다.
- 직접 화면에서 창고 벽 앞 연속 섭취와 다른 공간실로 이동하는 모습을 확인했다. 창고에서는 같은 위치에서 19초 이상 섭취가 이어졌고, 한 번 섭취한 뒤 옆으로 재접근하는 반복은 나타나지 않았다. 이후 동력실 벽 끝에서 입의 측면 오프셋 때문에 접근 후 대기하는 사례를 발견해 추가 보정했다.
- 임시 입력 장치로 실제 수송자 이동·시점·좌클릭을 전달했다. 대상 순간이동이나 직접 피해 주입 없이 막대기 3회 명중, 체력 110→80→50→20, 피격 후 수송자 공격 전환을 확인했다. 타격 처리 보조 계측에서 메시 갱신 최고 약 14ms→2ms, 해당 실행 전체 타격 처리 최고 약 16ms를 기록했다. 이는 해당 에디터 실행의 구간 측정이며 게임 전체 FPS 보장이 아니다.
- 작업 중 추가한 검사용 입력 장치는 종료 시 제거하고 원래 입력 설정/장치를 복원한다. 에디터 재시작, 원본 씬 변경, 무관한 에셋 변경, Git 커밋·푸시는 하지 않는다.
- 최종 섭취 재검증에서는 창고→조종실→동력실을 개체가 자연스럽게 이동했다. 조종실에서 섭취 시작 후 4.796초 동안 상태가 유지되며 내구도 396, 동력실에서 7.362초 동안 유지되며 내구도 340을 확인했다. 두 방 모두 실제 입 접촉이 이어졌으며, 해당 위치의 전후 실행 화면을 직접 확인했다. 문 경계 후 전진은 각각 2.0105m/2.0135m였다. 근접 도착 오차를 줄이고, 입이 벽 내부에 잠깐 들어가는 원본 섭취 포즈에서는 몸체 쪽에서 같은 벽의 가시성을 확인하도록 해 섭취 중단을 방지했다.
- 코드 공백 점검에서 수정한 플레이어 코드의 오류는 없었다. Unity가 저장한 씬 YAML의 빈 문자열 항목에 후행 공백 경고가 있었으나, 이 자동 직렬화 표현을 손으로 일괄 변경하지 않았다.
- 마지막 실제 입력 재검증: 막대기 3회 명중(롱가 체력 20), 피격 후 공격, 수송자 사망 뒤 금속 섭취 복귀를 확인했다. 해당 실행 타격 처리 최고 11.509ms, 메시 갱신 2.045ms, 피격 처리 0.592ms였다. 근거는 `Logs/LongaActualStickInput.txt`, `Logs/LongaLastInputReview.log`와 직접 본 실행 화면이다.
- 검증 통과 후 최종 캡처 `Logs/PegasusLongaArmaFinal.png`를 한 번 실행하고 직접 확인했다. 이번 최종 화면에는 조종실 벽 앞의 실제 표시 모델이 보인다. 종료 상태는 `Logs/LongaFinalEditorState.log`: Pegasus, Play=False, Pause=False, dirty=False, compiling=False, 콘솔 오류/경고 0. 실행모드를 끈 상태로 인계한다. 자동 테스트 스크립트와 빌드는 요청되지 않아 실행하지 않았다.
