## Accelerando IdleDetect 최신 적용 상태 요약

- 최신 상태:
  - `Accelerando_01_Idle_Detect`는 더 이상 본체/더듬이 분리 Mesh + Transform 스케일 호흡 방식을 쓰지 않음.
  - 현재 방식은 단일 `SkinnedMeshRenderer` + `blendShape.Accelerando_IdleBreathMorph` 커브임.
  - 적용 시 기존 `Accelerando_IdleBreath_Body` / `Accelerando_IdleBreath_StaticMaceAntennae` 분리 자식을 제거하고, `Mesh1.0` 렌더러 하나로 원본 형태를 유지함.
  - Transform 스케일/위치 호흡 값은 모두 `0`으로 고정함.
  - 더듬이/철퇴/뿌리 정점은 BlendShape 델타를 `0`으로 처리함.
  - 몸통 호흡 수치는 `IdleBreathRadialScale=0.030`, `IdleBreathVerticalScale=0.016`, `IdleBreathBodyFadeStartVertical=0.34`, `IdleBreathStaticShellVerticalThreshold=0.40` 기준임.

- 최신 확인:
  - `Logs/Accelerando_IdleBreath_Apply.log` 기준 `AnimatedVertices=3023`, `StaticVertices=9967`, `MaxDelta=0.02`.
  - 최신 캡처는 `docs/validation/accelerando/Accelerando_IdleBreath_000.png`, `Accelerando_IdleBreath_050.png`, `Accelerando_IdleBreath_100.png` 및 Oblique 3장임.
  - 캡처는 현재 BlendShape 포즈를 임시 Mesh로 Bake해서 촬영함. 실제 씬 적용은 임시 Mesh가 아니라 `SkinnedMeshRenderer`의 BlendShape 애니메이션임.
  - 육안 확인 기준 전면/사선 모두 몸통 하단과 중앙부만 작게 호흡하고, 철퇴/더듬이/뿌리 쪽은 화면상 고정됨.
  - 사용자가 지적한 영상의 등껍질/뿌리 경계 벌어짐은 최신 캡처에서 보이지 않음.
