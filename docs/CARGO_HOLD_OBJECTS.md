# 운송창고 오브젝트 목록

이 문서는 `docs/GAME_DESIGN_SOURCE.txt`와 `docs/MVP_IMPLEMENTATION_ORDER.md`를 기준으로 운송창고 관련 오브젝트를 정리한 문서다.
원본 기획서에 없거나 애매한 요소는 확정 오브젝트로 넣지 않고 확인 필요 항목으로 분리한다.

## 기준 근거

- 원본 기획서: 화물선은 조종실, 운송창고, 무기실, 비품실, 동력실, 통제실 6개 방과 복도로 구성된다.
- 원본 기획서: 모든 구역은 운송창고와 연결된 형태다.
- 원본 기획서: 운송할 화물은 우주선 내 운송창고에 위치하고, 별도 내구도를 가진다.
- 원본 기획서: 운송창고 내구도는 화물 적재 수량, 개인 화물 운송 가능 여부, 화물 손실률, 출발 가능 여부, 창고 점수에 영향을 준다.
- MVP 구현 순서 4단계: 운송창고는 중앙 화물과 가장자리 이동 영역, 5개 복도 연결 지점을 만든다.
- MVP 구현 순서 5단계: 운송창고 내 화물 상태와 화물 손실률을 만든다.
- MVP 구현 순서 6단계: 운송창고 화물은 화물 내구도와 손실률을 표시한다.
- MVP 구현 순서 기본 원칙: 화물 직접 집기, 운반, 납품 상호작용은 구현하지 않는다.
- 사용자 확정: 중앙 화물은 여러 개 의뢰를 받아도 단일 컨테이너로 보이게 한다.

## 손상도 기준 요약

원본 기획서 기준 운송창고 손상도는 아래 규칙에 연결된다. 이 문서는 오브젝트 목록 정리이므로 수치 구현은 별도 상태 모델에서 다룬다.

- 75% 이하: 화물 적재 수량 감소.
- 50% 이하: 개인 화물 운송 불가, 화물 적재 수량 추가 감소.
- 25% 이하: 화물 손실률 발생, 출발 제한 알림 조건.
- 0%: 화물 손실률이 주기적으로 감소하는 위험 상태.
- 운송창고 내구도는 화물 운송 점수에 반영된다.
- 협회 의뢰는 화물 운송 점수 미만이면 수락할 수 없다.

## 제외 항목

- 플레이어가 화물을 직접 집거나 운반하거나 납품하는 상호작용은 구현하지 않는다.
- 납품 구역이나 수동 납품 장치는 만들지 않는다.
- 화물 적재용 크레인, 지게차, 컨베이어, 선반, 팔레트 랙은 원본 기획서에 명시되지 않았으므로 확정 오브젝트로 두지 않는다.
- 운송창고 자동 포탑은 원본 업그레이드 설명에서 제외 대상으로 언급되므로 기본 오브젝트로 두지 않는다.
- 개별 화물 종류별 모델, 정확한 화물 크기, 방 크기, 복도 폭, 경사 길이는 이 문서에서 확정하지 않는다.

## 확인 필요 항목

- 운송창고와 각 구역을 잇는 5개 연결 지점의 정확한 배치 방향은 실제 6구역 배치와 맞춰 확인해야 한다.
- 화물 상태 표시 지점이 벽면 패널인지, 중앙 화물 근처 표시판인지, UI 전용인지 확인이 필요하다.
- 개인 화물과 의뢰 화물의 시각 구분을 만들지 여부는 이후 화물 상태 모델/정산 구현 전에 확인해야 한다.
