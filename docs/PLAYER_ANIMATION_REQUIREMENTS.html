수송자(플레이어) 애니메이션 개별 명세

☑ 완료 표시는 Unity 구현과 직접 시각 검증까지 통과한 제작 키다.

1. 명세 기준

  • 원본 근거는 `docs/GAME_DESIGN_SOURCE.txt`다.
  • 이 문서는 Unity 적용 전 제작 요구사항만 정의한다.
  • 표 한 행은 애니메이션 클립 또는 Animator에서 독립적으로 관리할 단일 상태 하나다.
  • 같은 클립을 여러 장비가 재사용하더라도 장비별 동작 요구사항은 별도 행으로 기록한다.
  • `명시`는 원문에 동작이 직접 적힌 상태, `필수 파생`은 명시 동작을 시작하거나 끝내는 데 필요한 상태, `기획 미확정`은 아이템은 있으나 동작이 정해지지 않은 상태다.
  • `기획 미확정` 행은 제작 대상 식별용이며 구체 동작을 임의로 만들지 않는다.
  • 취소 조건의 `없음`은 해당 클립 재생 중 정상 취소를 허용하지 않는다는 뜻이다.

시점별 플레이어 표시 기준

  • 본인 플레이어 화면에는 1인칭용 양팔과 손만 표시한다.
  • 다른 플레이어가 직접 볼 때와 CCTV 화면으로 볼 때는 해당 플레이어의 전신 모델과 전신 애니메이션을 표시한다.
  • 같은 게임플레이 상태를 기준으로 본인 화면의 1인칭 팔·손 표현과 외부 시점의 전신 표현을 동기화한다.

Shift 달리기 기준

  • 원본 15행의 Shift 달리기와 170행·291행의 Shift 대시는 같은 기능을 뜻하며, 별도 대시 기능은 두지 않는다.
  • 탈진 상태에서는 Shift 달리기를 사용할 수 없다.

점프 통합 기준

  • Player_Jump 한 클립에 도약, 상승, 하강, 일반 착지를 모두 포함한다.
  • 맵은 큰 높이 차가 없는 평면 구성이므로 별도 낙하 루프와 강한 착지 애니메이션은 제작하지 않는다.

걷기 방향별 분류와 재사용

  • 걷기 제작 원본은 `Player_Walk_Forward`, `Player_Walk_Backward`, `Player_Sidestep` 3개다. `Player_Walk_Diagonal`은 별도 원본 클립을 만들지 않고 기존 모션을 혼합한다.
  • `Player_Sidestep`은 오른쪽 옆걸음을 기준 원본으로 제작하고, 왼쪽 옆걸음은 같은 클립의 Animator Mirror를 켜서 재생한다.
  • `Player_Walk_Diagonal`은 우선 오른쪽 전방 W+D만 구현한다. 현재 연결된 `Player_Walk_Forward`와 오른쪽 `Player_Sidestep`을 속도·위상 수정 없이 50:50으로 혼합하는 1D Blend Tree를 사용한다.
  • 왼쪽 전방 미러와 양쪽 후방 대각선은 이번 범위에 포함하지 않고 후속 작업으로 둔다.
  • 실제 이동 방향은 Rigidbody 입력 벡터가 담당하며 Blend Tree의 두 자식 모션은 인플레이스 상태를 유지한다.

7. 미니 화염방사기

미니 화염방사기 리깅 작업 목표

  • 대상은 Flamethrower_Idle, Flamethrower_Fire, Flamethrower_Remote_Mode, Flamethrower_Tank_Place, Flamethrower_Tank_Recover 다섯 개다.
  • item model/mini flamethrower.fbx의 원본 정점, 삼각형, 노멀, 탄젠트, UV, 머티리얼과 텍스처를 그대로 유지한 단일 파생 SkinnedMesh에 가중치와 바인드 포즈만 추가한다.
  • 리그는 탱크 본 1개, 호스 본 8개, 분사 손잡이 그립 본 1개의 총 10개 본으로 구성한다.
  • 탱크·프레임·스트랩·두 연료통은 탱크 본에 고정하고, 수송자의 등 대부분을 덮는 현재 배치와 연료통이 바깥을 향해 양옆으로 나란한 방향을 유지한다.
  • 원본의 굵은 주 호스와 얇은 보조 호스는 탱크 연결부에서 고정한 뒤 8개 호스 본에 연속 가중치를 적용하며, 분사기 연결부가 오른손을 따라가도록 한다.
  • 분사기 몸체·트리거 가드와 사용자가 빨간 박스로 지정한 방아쇠울 내부의 검은 권총형 손잡이는 분사 손잡이 그립 본에 고정한다. 손 정렬은 호스나 분사기 원통부가 아니라 이 손잡이의 중앙 쥠면을 수송자 오른손 손바닥 중심과 겹치는 것을 기준으로 한다. 이 겹침 위치를 유지한 채 분사기와 연결 호스 끝을 함께 회전해 방아쇠울과 방아쇠가 수송자 기준 아래쪽을 향하고 오른손 안쪽 손가락과 겹치게 한다.
  • 수송자 메시, 기존 본, Animator, 대상 루트 Transform은 변경하지 않는다. 원본에 없는 대체 형상이나 생성 호스는 만들지 않는다.
