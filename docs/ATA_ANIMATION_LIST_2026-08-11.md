# 아타 애니메이션 목록

## 확정 기준

- 원본 근거는 `docs/GAME_DESIGN_SOURCE.txt`의 해적 공통 설명과 아타 직접
  명세 및 지휘 명세(`240~249행`)입니다.
- 아래 목록과 순서는 2026-08-11 사용자가 직접 확정했습니다.
- 확정 작업 목록은 정적 비교 상태 1개와 애니메이션 8개를 합친 총
  9개입니다.
- 권총 조준과 발사는 하나의 모션으로 구성합니다.
- 수호태세와 돌파태세 하달은 하나의 명령 모션을 공용합니다.
- 동력실·통제실·조종실·무기실의 특수 상호작용은 하나의 사보타주
  모션을 공용합니다.
- 비품실·운송 창고의 폭탄 설치는 사보타주 모션에 합치지 않고 별도
  폭탄 설치 모션으로 구성합니다.
- 원본과 사용자 확정에 없는 자세·각도·재생 시간·반복 방식은 이
  문서에서 임의로 정하지 않습니다.

## 항목별 원본 경계

### 정적

- 사용자가 아타 작업 목록의 첫 번째 항목으로 확정했습니다.
- 아타의 외형과 권총을 확인하는 비교 상태이며 애니메이션이 아닙니다.

### 대기 모션

- 사용자가 별도 모션으로 확정했습니다.
- 원본에는 아타의 대기 자세, 세부 움직임과 반복 시간이 없습니다.

### 이동 모션

- 아타는 화물선 내부에 도착한 뒤 가까운 구역으로 이동합니다.
- 다음 구역으로 갈 때는 먼저 돌파태세를 명령합니다.
- 보행 형태, 출발·정지 전환과 루프 길이는 원본에 없습니다.

### 권총 조준 및 발사 모션

- 아타의 주무기는 권총입니다.
- 사용자가 조준과 발사를 분리하지 않고 하나의 모션으로 확정했습니다.
- 권총 사거리·피해량·연사 딜레이는 게임플레이 수치이며 모션 수를
  늘리는 근거로 사용하지 않습니다.
- 조준 자세, 발사 손, 반동, 권총 장착 위치와 재장전은 아직 정하지
  않았습니다.

### 명령 모션

- 원본의 명령은 수호태세와 돌파태세 두 종류입니다.
- 아타가 다음 구역으로 이동하기 전에는 돌파태세, 구역 특수
  상호작용 전에는 수호태세를 명령합니다.
- 사용자가 두 명령에 하나의 명령 모션을 공용하도록 확정했습니다.
- 명령 제스처, 권총 처리, 재생 시간과 반복 여부는 아직 정하지
  않았습니다.

### 사보타주 모션

- 사용자가 다음 네 구역에 하나의 사보타주 모션을 공용하도록
  확정했습니다.
  - 동력실: 동력 출력 감소
  - 통제실: 통제실 해킹
  - 조종실: 자동 조종 무력화
  - 무기실: 자동·수동 포탑 비활성화
- 원본에는 동력실·통제실·조종실의 시전 시간이 각각 `1분`으로
  명시되어 있습니다. 무기실의 시전 시간은 명시되어 있지 않습니다.
- 위 시전 시간은 시스템 시간이며, 모션을 같은 길이의 단일 클립으로
  만들지 반복 루프로 구성할지는 아직 정하지 않았습니다.
- 구역별 상호작용 위치, 손동작, 완료 자세와 중단 동작도 아직 정하지
  않았습니다.

### 폭탄 설치 모션

- 비품실과 운송 창고에 내부 폭탄을 설치할 때 공용합니다.
- 원본 설치 시간은 `45초`입니다.
- 사용자가 네 구역 공용 사보타주 모션과 분리한 별도 모션으로
  확정했습니다.
- 폭탄을 꺼내는 동작, 설치 위치와 자세, 설치 완료 후 동작은 아직
  정하지 않았습니다.

### 피격 모션

- 사용자가 별도 모션으로 확정했습니다.
- 원본에는 피격 방향, 반동 크기, 재생 시간과 기본 자세 복귀 방식이
  없습니다.

### 사망 모션

- 원본에는 아타가 사망하면 다음 아타가 올 때까지 남은 해적 개체가
  정지하는 규칙이 있습니다.
- 사용자가 아타 자신의 사망 모션을 별도 항목으로 확정했습니다.
- 쓰러지는 방향, 재생 시간, 최종 자세와 유지·반복 방식은 아직 정하지
  않았습니다.

- 권총 재장전 모션

- 아타 정지 모션

후의 정지는 아타 자신이 아니라 남은 파후르·쿠르사·이슈판트에 적용되는
시스템 상태입니다.

- 이동 경로, 루트 이동속도와 방향 결정
- 권총 피해량·사거리·연사 딜레이
- 사보타주 시전 시간과 구역별 기능 비활성화
- 폭탄 폭발과 구역 내구도 `0%` 처리
- 아타 사망 감지와 남은 해적 정지·재활성화
- 아타 전용 침입선과 외부 포격
