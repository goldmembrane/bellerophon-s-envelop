# Cockpit Object List

작성일: 2026-06-15

이 문서는 조종실 내부에 구현해야 할 오브젝트 목록을 따로 고정해 두기 위한 작업 메모입니다. 실제 모델링, 머티리얼, UI 시각 요소는 `artSample/` 승인 후 Unity에 반영합니다.

## 범위

- 포함: 조종실 내부 구조 안에 배치될 시각 오브젝트, 상호작용 앵커, 상태 표시물.
- 제외: 복도 본체 모델링, 다른 방 오브젝트, 수동 운행 UI의 실제 런타임 로직.
- 기존 유지: 화물선 전체 기존 모델은 비활성화 상태를 유지하고, 튜토리얼 로직은 모델 확인용으로 꺼둔다.

## 원본 근거

- `docs/GAME_DESIGN_SOURCE.txt:115`: 조종실은 앞이 유리이고, 왼쪽은 동력실, 오른쪽은 통제실, 뒤쪽은 운송창고 방향이며 긴급 수리 장치와 수리 장치로 내구도 회복 가능.
- `docs/GAME_DESIGN_SOURCE.txt:116`: 유리창 앞에 조종대가 있고, 조종대 앞에서 F 상호작용 시 수동 운행 모드로 전환.
- `docs/GAME_DESIGN_SOURCE.txt:117`: 수동 운행 모드 화면은 1945식 구성, 왼쪽 하단에 화물선 전개도와 구역 내구도 색상 표시.
- `docs/GAME_DESIGN_SOURCE.txt:119`: 조종실 내구도 50% 이하에서는 자동 운행 모드 이용 불가.
- `docs/GAME_DESIGN_SOURCE.txt:120`: 수동 운행 중에도 조종실 침입을 소리로 감지 가능.
- `docs/GAME_DESIGN_SOURCE.txt:121`: 조종실 내구도 0% 시 조종대 폭파 및 주변 유저 피해.
- `docs/GAME_DESIGN_SOURCE.txt:247`: 우주 해적 아타가 조종실에서 자동 조종 모드를 무력화할 수 있고, 유저가 F 상호작용으로 복구 가능.
- `docs/MVP_IMPLEMENTATION_ORDER.md:98`: 조종실은 전면 유리, 조종대, 동력실/통제실/운송창고 연결 방향을 알아볼 수 있게 만든다.
- `docs/MVP_IMPLEMENTATION_ORDER.md:138`: 조종실 조종대는 F 상호작용으로 수동 운행 모드 UI에 진입하는 틀을 가진다.

## 오브젝트 목록

| ID | 오브젝트 | 용도 | 상태 |
| --- | --- | --- | --- |
| CK-01 | 전면 유리창 / 전방 파노라마 화면 | 조종실 전면의 핵심 시야면. 5분할 창문은 사용하지 않는다. | 승인 및 Unity 배치 완료. 사용자 편집 위치를 스크립트에 반영함. |
| CK-02 | 메인 조종대 | 유리창 앞에 배치되는 핵심 상호작용 오브젝트. F 상호작용 앵커의 기준. 중앙/전면 화면은 CK-01이 담당하므로 포함하지 않는다. | 낮은 본체 버전 승인 및 Unity 교체 적용 완료. |
| CK-03 | 조종 핸들 / 스틱 / 그립 | 조종대에서 실제 조작감을 주는 시각 부품. 타륜형 핸들과 오른쪽 전진 레버를 포함한다. | CK-02 하위 부품으로 제작. |
| CK-04 | 경고등 / 작은 물리 표시등 | 조종실 내부의 위험 상태를 분위기로 알려주는 경고등. 자동/수동 운행 상태, 진행도, 내구도 같은 정보는 CK-01 메인 스크린에 표시하고 별도 모델링하지 않는다. | 승인 및 Unity 배치 완료. 좌우 경고등은 제외했고, 스크린 위 경고등 바와 중앙 천장 비상 경고등 본체만 적용했다. 천장 경고등은 조종실 천장 한가운데에 배치했다. |
| CK-05 | 화물선 전개도 / 내구도 표시 패널 | 수동 운행 화면의 구역명과 내구도 색상 표시. | 조종실 모델링 오브젝트에서 제외. 수동 조종 모드일 때만 표시되는 UI/HUD 작업으로 이관. |
| CK-06 | 자동 조종 상태 / 복구 패널 | 자동 조종 불가, 아타 사보타주, F 복구 상호작용을 표시할 패널. | 기능은 기존 로직 유지, 모델은 별도 제작. |
| CK-07 | 긴급 수리 장치 | 조종실 내구도 회복용 장치. 원본에 명시됨. | 조종대 이후 제작. |
| CK-08 | 일반 수리 장치 | 긴급 수리 장치와 구분되는 기본 수리 장치. 원본에 명시됨. | CK-07과 세트로 제작. |
| CK-09 | 조종대 파손 / 폭파 상태 부품 | 조종실 내구도 0% 시 조종대 폭파 상태를 표현할 파손 버전. | 기본 조종대 승인 후 파생 제작. |
| CK-10 | 침입 감지 오디오 경고 | 수동 운행 중 침입자 소리 감지. | 조종실 모델링 오브젝트에서 제외. 시각 경고 없이 사운드 경고로만 구현. |
| CK-11 | 방향 표시 / 방 라벨 | 왼쪽 동력실, 오른쪽 통제실, 뒤쪽 운송창고 방향을 알아보기 위한 내부 표시. | 승인 및 Unity 적용 완료. `Approved Cockpit 11 Direction` 루트로 조종실 구조에 맞춰 배치했고, 비교 캡처는 `artSample/ck_dir11/unity_applied_comparison/index.html`에 저장. |
| CK-12 | 조종실 내부 조명 / 점검등 | 구조와 오브젝트를 확인하기 위한 조명, 경고등, 라이트 스트립. | 기능 필수는 아니지만 시각 완성용. |

## 우선순위

1. CK-02 메인 조종대
2. CK-03 조종 핸들 / 스틱 / 그립
3. CK-04 경고등 / 작은 물리 표시등
4. CK-11, CK-12 보조 표시물
5. CK-09 조종대 파손 / 폭파 상태

제외/이관:

- CK-05는 수동 조종 모드 UI/HUD에서 구현한다.
- CK-06, CK-07, CK-08은 장치 쪽 작업으로 구현한다.
- CK-10은 시각물 없이 사운드 경고로 구현한다.
