### 현재 Unity 반영 상태

- `Vacuum_Idle`에서 사용자가 조정한 청소기 로컬 위치·회전·스케일을 스크립트 기준값으로 보존하고 `Vacuum_Use`에 동일하게 반영했다. `Vacuum_Use` 청소기는 오른손 위치·회전을 실시간 추종하며 전진·후진·옆걸음·달리기·대각선 2D 이동 순환을 출력한다.
- `Speaker_Idle`에는 원본 휴대용 스피커 모델·텍스처·머티리얼, 사용자가 최종 조정한 Transform, 왼쪽 어깨 추종을 반영했다. 왼손은 손바닥이 수송자 오른쪽을 향하는 자연스러운 손잡이 근처 자세를 유지하고, 6모션 이동 중 상체 흔들림을 남겼다.
- `HoloSpray_Idle`에는 원본 홀로그램 스프레이 모델·텍스처·머티리얼을 적용했다. 캔은 세로, 분사구는 정면이며 오른손을 추종한다. 오른팔 파지를 유지하면서 6모션 이동 흔들림이 출력되고 팔꿈치·전완 뒤틀림 교정을 마쳤다.
- Flashbang 4상태에는 원본 섬광탄 모델·텍스처·머티리얼과 지정된 Hands 원본 애니메이션을 연결했다. `Flashbang_Idle`은 자연스러운 오른팔 파지와 6모션 이동 순환을 사용한다. `Flashbang_Throw_Release`는 오른손 최고점에서 분리돼 전방 포물선 비행, 속도 방향 기울기, 중력과 자연 회전을 적용한 뒤 다음 반복에서 복귀한다.
- Flashlight 3상태에는 원본 손전등 모델·텍스처·머티리얼을 적용하고 렌즈 정면, 자연스럽게 내린 오른팔, 주먹 파지와 오른손 추종을 연결했다. `Flashlight_Idle`은 지정된 Player 원본 6모션을 2D Freeform Cartesian Blend Tree에서 각각 1초씩 순환하며 기존 파지와 자연스러운 상체 흔들림을 함께 유지한다.

## Flashbang_Idle 오른팔 고정 및 Throw Release 손 위치 해제 — 사용자 영상 기준 직접 확인 통과

### 적용 상태

- 사용자 영상 `Bellerophon - CargoRunMvp - Windows, Mac, Linux - Unity 6.3 LTS (6000.3.16f1) _DX12_ 2026-09-11 21-27-35.mp4`를 4fps 전체 프레임과 8fps 투척 구간으로 나누어 직접 확인했다. 중앙 `Flashbang_Idle`의 오른팔이 아래에서 머리 위까지 반복 회전하고, `Flashbang_Throw_Release`의 섬광탄 비행 시작점이 손보다 아래에 표시되는 두 결함을 재현했다.
- `Flashbang_Idle`의 기존 런타임 코드는 작성 포즈에 원본 대기 애니메이션의 현재 회전 차이를 다시 더해 오른팔이 계속 회전했다. 이 가산을 제거하고 `RightShoulder`부터 `RightHand` 및 모든 오른손 손가락까지 19개 본의 작성 로컬 회전을 Animator 적용 뒤 그대로 복원한다.

- 해제 순간 Rigidbody 보간이 이전 kinematic 위치를 한 프레임 표시하지 않도록 보간을 끄고 `Physics.SyncTransforms`로 인계 위치를 동기화했다. 위치·회전 인계 뒤 첫 `FixedUpdate`부터 기존 속도 방향 정렬, 자연 회전과 중력을 적용한다.
- 두 번째 반복에서도 오른손으로 복귀해 최고점 파지를 다시 기록하고 동일한 위치에서 재투척한다. 일회성 자동 적용 등록은 최종 반영 뒤 제거했다.

## Flashbang_Idle 손바닥 정면 교정 및 Throw Release 물리 비행 — 직접 확인 통과

### 적용 상태

- `Flashbang_Idle`의 오른손바닥이 수송자 정면을 향하도록 오른팔 회전을 교정했다. 손목 하나에 회전을 몰지 않고 각 관절의 길이축을 기준으로 `RightShoulder 10%`, `RightArm 35%`, `RightForeArm 55%`를 분산했으며 남은 오차만 `RightHand`에서 제거했다.
- 원본 `Hands_Empty_Idle` 애니메이션과 현재 섬광탄 파지는 유지하고, Animator 적용 뒤 오른팔 길이축 회전만 보정한다. 렌더러·메시·머티리얼·텍스처·FBX와 다른 신체 부위는 변경하지 않았다.
- `Flashbang_Throw_Release`는 240Hz로 원본 `Hands_Throw_Release`를 분석해 오른손 높이가 최대가 되는 `0.775000036초`에 오른손 추종을 해제한다.
- 섬광탄의 초기 전방 속도와 회전량은 임의 수치로 만들지 않고 원본 오른손 애니메이션에서 얻었다. 수송자 로컬 발사 속도는 `(0, -0.0475788079, 6.63574171)m/s`, 자연 회전량은 `21.25249rad/s`이며 `Rigidbody` 중력을 적용한다.
- 비행 중 섬광탄의 로컬 전방축을 현재 속도 방향으로 기울이면서 원본 손 회전량을 함께 적용한다. 애니메이션이 새 반복으로 넘어가면 Rigidbody 비행을 끝내고 섬광탄을 오른손에 다시 연결해 같은 절차로 재투척한다.
- 일회성 자동 적용은 최종 반영 뒤 해제했다. `Flashbang_Throw_Aim`, `Flashbang_Throw_Cancel`, 원본 애니메이션·컨트롤러와 승인 범위 밖 씬 개체는 변경하지 않았다.
