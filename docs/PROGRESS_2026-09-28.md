## 파르붐 공간실 입구 통과 후 2m 전진 — 이전 판정 정정

아래 최초 검증은 연결부와 방 바닥 소속 시작점을 실제 공간실 문으로 오인했다. 사용자 지적에 따라 해당 완료 판정을 철회하고, 실제 문틀 안쪽 면 기준으로 다시 수정·검증한다. 아래 기록은 이전 구현의 이력이지 현재 요구사항 충족 근거가 아니다.

- 사용자 지시로 기존 1m 전진 조건을 2m로 대체했다. `ParvumGameplayRules.RoomEntryAdvanceDistance = 2f`. 기존 캡슐 뒤쪽의 방 진입 확인, 실제 진행 방향 변위 기반 판정, 물리 이동, 피격/스피커 우선순위와 중단 후 재개를 유지했다.
- Pegasus 실행 화면에서 창고→조종실, 조종실→통제실, 통제실→무기실의 입구 진입·전진·이후 벽 섭취를 연속 관찰했다. 피격/스피커 입력 후에도 남은 전진이 재개되며 보조 기록은 각 2.0003m 완료 뒤 금속 탐색으로 전환했다. 일부 임시 자극은 기둥/몸체에 가려졌으므로 해당 접촉 장면을 선명하게 직접 확인했다고 주장하지 않는다. 전체 입구 전수 검증과 구분한다.
- 게임 로직 변경은 거리 상수뿐이며 원본 모델·애니메이션·공격/감지/속도 수치·방/복도/연결부·충돌체·NavMesh·씬 배치 변경 없음. 에디터 도구에는 이번 최종 캡처의 별도 파일명 처리만 추가했다.
- 열린 에디터 리프레시와 ReviewParvumGameplay로 반영/관찰했다. 상세 근거: `docs/validation/PegasusParvumAI/EntryAdvanceTwoMetresReport.md`. 검증 후 최종 캡처 `EntryAdvanceTwoMetresFinal.png` 1회.
- 실행 종료 후 원래 파르붐 시작 위치/체력 복귀, Pegasus Dirty=False, Compiling=False, 콘솔 0건. 임시 조건은 저장하지 않았다. Unity 재시작, 자동 테스트/빌드, Git 커밋·푸시 미실행.

## 실제 공간실 문 기준으로 재수정 — 후속 보완 및 검증 완료

- `ParvumRoomEntrance.cs` 및 `ParvumBrain.cs`에 실제 문틀의 방 안쪽 면 기준을 적용했다. 연결부 바닥 시작점을 거리 원점으로 쓰지 않는다. 몸체 캡슐 후단이 실제 문 면을 통과한 뒤 2m 전진 후 금속 탐색으로 전환한다. 문 안쪽 목표까지 경로를 유지하고 피격/스피커 중단 후 전진 재개를 보존했다.
- 직접 실행 화면에서 조종실, 동력실, 통제실(서쪽 두 입구 및 남쪽 무기실 입구), 무기실(통제실·비품실 입구), 비품실 진입 후 전진을 확인했다. 상세 연속 캡처와 판정은 `docs/validation/PegasusParvumAI/DoorEntryReport.md`에 기록했다.
