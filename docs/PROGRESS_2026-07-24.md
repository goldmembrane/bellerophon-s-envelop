## Git 기록 준비 - 니게티프 작업

- 사용자의 요청에 따라 위 니게티프 샘플·Unity 에셋·배치 도구·브리지 명령·진행 문서를 `main` 브랜치에서 커밋하고 `origin/main`으로 푸시하는 범위로 정리했습니다.
- `CargoRunMvp.unity`는 Git LFS 파일이라 니게티프 씬 변경만 부분 스테이징할 수 없습니다. 사용자에게 이 제약을 알렸고, 기존 미커밋 씬 상태를 포함한 현재 씬 파일 전체를 이번 커밋에 포함하도록 명시 승인받았습니다.
- 공유 파일 `UnityEditorValidationBridge.cs`는 니게티프 관련 브리지 명령만 부분 스테이징하며, 작업 트리에 함께 존재하는 돌로레·오스티나토·그라베 관련 일반 파일 변경은 이번 커밋에서 제외합니다.
- 커밋 대상에는 기존 FBX 기반 니게티프 샘플 제작 이력, 최종 GLB 승인 샘플, Unity 니게티프 에셋, 전용 배치·검사 도구, 원본 모델의 FBX→GLB 교체, 관련 샘플 생성 스크립트가 포함됩니다.
