# 모델링 규칙

이 문서는 모델, 텍스처, 머티리얼, 적대 개체 샘플 및 모델 교체의 Unity 적용에 적용한다. 작업 시작 전 루트 `AGENTS.md`와 `docs/DESIGN_RULES.md`를 먼저 따른다.

## 모델·텍스처·머티리얼

- 신규 모델링, 텍스처링, 머티리얼 작업은 먼저 `artSample/`에 검사 가능한 샘플을 저장하고 명시 승인을 받은 뒤 Unity 런타임 씬, 프리팹, 에셋, UI 흐름에 구현한다.
- 기존 모델의 형상 수정, 결함 복구, 불필요한 지오메트리 제거에는 `artSample/` 제작과 샘플 선승인이 필요하지 않다. 사용자가 지정한 모델·부위·변경 범위 안에서 일반 작업 승인을 받은 뒤 직접 수정할 수 있다.
- 기존 모델에 새로운 시각 디자인을 추가하거나 텍스처·머티리얼을 새로 제작·변경하는 작업은 수정이라는 이유로 예외 처리하지 않고 `artSample/` 승인 절차를 따른다.
- 기존 `artSample/` 이미지가 모델링·텍스처링 목표이면 창작 프롬프트가 아니라 재현 대상으로 다룬다. 이미지를 실루엣, 비율, 주요 형태, 개별 부품, 표면 재질, 마모 패턴, 조명, 카메라 각도로 분해한 뒤 Blender 또는 적절한 DCC 도구에서 작업한다.
- 텍스처링은 레퍼런스가 요구하는 재질감을 포함해야 한다. 알베도 변화, 벗겨진 도장, 오염, 러프니스·메탈니스 반응, 노멀·범프 디테일을 반영한다. 거칠고 마모된 레퍼런스에 피상적인 선 스크래치나 단색만 적용한 상태는 부족하다.
- 단순 단색 머티리얼, 기본 셰이더, 임시 재질만 적용한 상태는 완료가 아니다.

## 모델 교체와 Unity 적용 범위

- 모델 교체는 승인된 모델 파일, 내보내기 파일, 텍스처, 머티리얼, 프리팹, 사용자가 명시한 Unity 루트 오브젝트에만 한정한다.
- 사용자가 씬 전체 작업을 명시적으로 승인하지 않았으면 모델 교체를 이유로 Unity 씬 전체를 열거나 저장하거나 덮어쓰지 않는다.
- 씬 반영이 필요하면 승인 요청에 대상 씬 경로, 대상 루트 오브젝트 이름, 교체할 하위 오브젝트, 유지할 기존 오브젝트, 삭제 또는 비활성화할 오브젝트를 구체적으로 적는다.
- `Player`, `Hud`, `EventSystem`, 조명, 카메라, Phase 루트, graybox, 방 상호작용 루트처럼 교체 대상이 아닌 기존 씬 루트는 사용자가 이름으로 명시하지 않는 한 읽기·복사·삭제·비활성화·저장 대상에 포함하지 않는다.
- 승인된 `artSample/` 모델의 Unity 적용은 샘플 승인과 별도 작업이다. 샘플 승인만으로 씬, 프리팹, 런타임 에셋을 변경하지 않는다.
- 모델 교체 스크립트나 Unity 브리지 명령은 씬 전체를 여는 패턴을 기본값으로 삼지 않는다. 모델 임포트, 프리팹 교체, 지정 루트 하위 교체처럼 더 좁은 방법을 먼저 검토한다.
- 기존 씬을 열어야만 하면 `OpenSceneMode.Single` 사용 여부와 저장 여부를 승인 요청에 명시한다. 승인받은 루트 외의 씬 오브젝트는 생성·삭제·복원·이동·이름 변경·활성 상태 변경이 없어야 한다.

## 적대 개체 샘플

- 적대 개체 샘플은 먼저 `artSample/enemies/{enemy_id}/` 아래에 생성한다. 명시 승인 전에는 Unity 런타임 씬, 프리팹, 에셋, AI, 피격 판정, UI 흐름에 연결하지 않는다.
- 샘플은 `docs/GAME_DESIGN_SOURCE.txt`, 사용자 확인 사항, `image/` 폴더의 기준 이미지를 참고해 제작한다.
- 기준 이미지의 외형, 실루엣, 비율, 주요 부위, 색 분포, 재질, 질감, 표면 특성을 최대한 맞춘다.
- 텍스처와 머티리얼을 반드시 적용한다. 없으면 직접 만든 절차적·생성 텍스처와 머티리얼이라도 제작해 적용한다.
- 텍스처·머티리얼 제작이 어렵거나 불완전하면 기준 이미지를 분석해 색 분포, 표면 패턴, 거칠기, 광택, 투명도, 금속성·비금속성, 오염·손상, 요철감, 젖음·점액·분말·섬유·피부 같은 표면 성질을 정리하고 제작에 반영한다.
- 샘플은 사용자가 검사할 수 있는 정적 렌더와 검토에 필요한 원본·내보내기 파일을 포함한다. 예: Blender, FBX, GLB, README, 승인 상태, 에셋 매니페스트, HTML 미리보기.
- 애니메이션 GIF나 애니메이션 샘플은 적대 개체 샘플의 필수 조건이 아니다. 애니메이션은 Unity 적용 단계에서 별도 승인 범위 안의 기능형 애니메이션 작업으로 다룬다.
- 승인된 적대 개체를 Unity에 구현할 때는 사용자가 범위를 명시적으로 제한하지 않는 한 승인된 `artSample/enemies/{enemy_id}/`의 시각 모델·텍스처·머티리얼 의도를 가능한 한 가깝게 재현한다.
