## Feasibility Answer

- Hitting 95% structural similarity is realistic for 01 cockpit if the work stops chasing pixel-level detail and prioritizes layout, silhouette, proportions, depth, and major part placement.
- Hitting 95% pixel/detail reproduction is not realistic with the current procedural Blender loop and is no longer the target.
- The current loop is repeating the same failure mode:
  - v003 can get near 95 numerically, but some close-up views crop too tightly and lose the whole object silhouette.
  - v004 restores silhouettes but loses the reference board's composition and material response.
  - v005 proves that global brightening does not solve the mismatch.
- A legitimate structural 95 needs a workflow change:
  - rebuild the main cockpit background/window/cargo-bay depth as actual Blender geometry,
  - lock each slot camera to the reference silhouette before material tuning,
  - model monitor frames, side cheeks, bottom latches, helm grips, bolts, and worn edge masks at the same visible scale as the reference,
  - texture paint enough edge wear, dirt, chipped metal, CRT glass, roughness, and bump maps to support the structure without trying to copy every small mark,
  - use pixel similarity only as a supporting diagnostic, not as the approval gate.
