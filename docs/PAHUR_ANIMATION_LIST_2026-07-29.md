# 파후르 애니메이션 목록

## 기준

- 원본 근거는 `docs/GAME_DESIGN_SOURCE.txt`의 해적 공통 설명과 파후르,
  아타 지휘 설명(`240~249행`)입니다.
- 원본 기획서의 행동과 2026-07-29 사용자 확정 사항을 함께 적용합니다.
- 원문에 세부 동작이 없더라도 사용자가 직접 확정한 항목은 확정 목록에
  포함합니다.
- 공격 피해량·사거리·지속시간·재사용 대기시간은 게임플레이 수치이며,
  별도 애니메이션 수를 늘리는 근거로 사용하지 않았습니다.
- 정적 비교 개체는 향후 Unity 배치 시 필요할 수 있지만 애니메이션이
  아니므로 확정 애니메이션 개수에 포함하지 않았습니다.

## 사용자 확정 애니메이션 목록

파후르에 넣을 애니메이션은 다음 9개로 확정합니다. 이후 파후르 모델
배치와 애니메이션 작업은 이 목록과 순서를 기준으로 합니다.

| 순번 | 확정 애니메이션 | 확정 근거와 역할 |
| --- | --- | --- |
| 1 | 대기 모션 | 사용자 확정. 비전투 또는 행동 대기 상태 |
| 2 | 이동 모션 | 원본의 일반 이동과 대형 이동 |
| 3 | 미니 화염방사기 발사 모션 | 원본의 일반 구역·유저 공격 |
| 4 | 돌파태세 화염방사 모션 | 원본의 화염방사기 발사와 전진이 동시에 일어나는 돌파태세 |
| 5 | 수호태세 전용 발사 모션 | 원본의 쿠르사 방패 틈 발사를 별도 모션으로 사용자 확정 |
| 6 | 정지 모션 | 원본의 아타 사망 후 활동 정지 상태를 별도 모션으로 사용자 확정 |
| 7 | 대형 전환 모션 | 수호태세와 돌파태세 대형 전환을 별도 모션으로 사용자 확정 |
| 8 | 피격 모션 | 사용자 확정 |
| 9 | 사망 모션 | 사용자 확정 |

## 확정 애니메이션별 원본 경계

### 대기 모션

- 사용자가 확정 목록에 직접 포함했습니다.
- 원본에는 대기 자세나 반복 움직임이 명시되어 있지 않으므로 구체적인
  자세와 움직임은 구현 단계에서 임의로 정하지 않습니다.

### 이동 모션

- 파후르는 쿠르사와 함께 화물선 내부 구역으로 이동합니다.
- 일반 이동속도는 `2`입니다.
- 아타의 명령을 받은 대형 이동에서는 다음 구역까지 이동속도 `1.5`가
  적용됩니다.

### 미니 화염방사기 발사 모션

- 아타의 명령이 없을 때 화물선 내부 구역을 공격하고, 유저를 만나면
  같은 미니 화염방사기로 유저를 공격합니다.
- 기본 공격 수치는 피해량 `0.5초당 5`, 사거리 `1~2`, 최대 방출
  `10초`, 재방출 대기 `2.5초`입니다.

### 돌파태세 화염방사 모션

- 돌파태세에서는 파후르가 최전방에 배치됩니다.
- 화염방사기를 전방으로 방출하면서 이동속도 `1.5`로 전진합니다.
- 최대 방출 시간은 `8초`, 재방출 대기시간은 `3초`, 피해량은
  `0.5초당 8`입니다.

### 수호태세 전용 발사 모션

- 쿠르사가 방어태세를 유지하는 동안 파후르는 방패 틈으로
  화염방사기를 발사합니다.
- 최대 방출 시간은 `5초`, 재사용 대기시간은 `5초`, 피해량은
  `0.5초당 10`입니다.
- 사용자가 일반 발사와 분리된 전용 모션으로 확정했습니다.

### 정지 모션

- 아타가 사망하면 나머지 해적 개체는 다음 아타가 올 때까지 정지합니다.
- 사용자가 이 상태를 별도 정지 모션으로 확정했습니다.

### 대형 전환 모션

- 아타는 파후르를 포함한 해적 개체에게 수호태세 또는 돌파태세를
  명령합니다.
- 사용자가 두 태세의 배치 변경을 대형 전환 모션으로 확정했습니다.

### 피격 모션

- 사용자가 확정 목록에 직접 포함했습니다.
- 원본에는 피격 방향이나 반동 형태가 없으므로 구체 동작은 구현 단계에서
  임의로 정하지 않습니다.

### 사망 모션

- 사용자가 확정 목록에 직접 포함했습니다.
- 원본에는 쓰러지는 방향이나 최종 자세가 없으므로 구체 동작은 구현
  단계에서 임의로 정하지 않습니다.

## 확정됐지만 세부 동작이 정해지지 않은 항목

- 대기 모션의 자세와 반복 움직임
- 수호태세 전용 발사 모션의 조준 자세와 쿠르사 방패와의 상대 위치
- 정지 모션이 현재 자세를 고정하는 방식인지 별도 정지 자세로
  전환하는 방식인지
- 대형 전환 모션의 이동 순서, 시작·종료 대형과 전환 시간
- 피격 모션의 방향, 반동 크기와 복귀 방식
- 사망 모션의 쓰러지는 방향, 종료 자세와 반복 여부

위 세부 사항은 애니메이션 목록의 확정 여부와 별개입니다. 실제 구현
단계에서는 사용자 제공 자료나 별도 사용자 확인 없이 추측해 정하지
않습니다.

## 목록에 포함하지 않은 항목

- 정적 외형 비교: 애니메이션이 아닌 배치 상태입니다.
- 화염 VFX: 애니메이션과 별도의 시각 효과입니다.
- 기본·수호·돌파태세별 피해량과 공격 주기: 게임플레이 로직입니다.
- 쿠르사 방패 태세: 쿠르사의 애니메이션입니다.
- 파후르 침입선: 파후르 개체가 아닌 외부 수송 수단입니다.
- 방향 전환: 원본에 파후르 전용 방향 전환 시간이나 동작이 없습니다.
- 별도 공격 준비·종료 모션: 사용자 확정 9개 목록에 포함되지 않았습니다.

## 기존 구현 기록과의 구분

- 과거 진행문서에는 파후르 공격이 `로켓 공격`으로 기록된 부분이
  있습니다.
- 원본 기획서의 파후르 주무장과 공격 방식은 `미니 화염방사기`입니다.
- 이번 애니메이션 목록은 원본 기획서를 우선해 화염방사기 동작만
  기준으로 삼았으며, 과거 로켓 표현을 애니메이션 근거로 사용하지
  않았습니다.
