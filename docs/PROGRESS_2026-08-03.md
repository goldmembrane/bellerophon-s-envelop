## 쿠르사 기존 UV 눈 형태 재수정

- 상태: `EXISTING_UV_METHOD_RETAINED_DIRECT_VISUAL_REVIEW_COMPLETED`
- 사용자가 제공한 실제 화면에서 이전 결과의 왼쪽 눈이 과도하게 크고 오른쪽 눈이
  가늘게 찢어진 것을 확인해 앞선 눈 완료 판정을 취소했다.
- 별도 눈 표면을 추가하는 시도를 했으나 기존 방식 유지 지시와 맞지 않아 즉시
  파기했다. CargoRunMvp에 추가됐던 눈 표면 `24개`와 전용 메시·머티리얼·셰이더·도구를
  모두 제거했으며 최종 씬에는 별도 눈 오브젝트가 `0개`다.
- 최종 수정은 기존 스킨 얼굴 메시의 `uv2/uv3/uv4` 눈 투영 채널과 승인 눈 텍스처만
  사용한다. 얼굴·리그·몸통과 승인 텍스처는 변경하지 않았다.
- 텍스처 알파와 공통 깊이 절단이 눈 외곽을 결정하지 않게 하고, 셰이더의 좌우 타원
  마스크가 작은 눈 형태를 직접 제한하도록 변경했다.
- 왼쪽 UV 중심에는 다섯 얼굴 표면이 겹쳐 있었다. 실제 눈구멍의 absolute signed-depth
  `0~0.307` 연속 표면만 포함하고 `1.08` 이상인 원거리 중복 표면은 제외하기 위해
  왼쪽에만 `|depth| < 0.8` 조건을 적용했다. 오른쪽 중심은 단일 표면이므로 별도 깊이
