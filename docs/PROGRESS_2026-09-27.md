- 저장된 시작점으로 Play Mode 진입 후 전후좌우 이동 및 마우스 시점 회전 화면을 직접 확인. 가상 키보드/마우스를 기존 입력 시스템에 공급했으며 Transform으로 이동을 강제하지 않음. 주변 보행 후 접지 유지, 겹침·끼임·추락 없음. 단차를 내려가는 순간 비접지 후 정상 착지함.
- Play Mode 종료·재진입으로 같은 시작 위치/방향과 일반 보행 설정을 재확인. PlayerCount=1, Grounded=True, FreeMove=False. 임시 입력 장치는 제거했으며 최종 실행모드 종료.
- 처음 후보가 0곳으로 나왔던 것은 우주선 외피의 큰 AABB가 내부까지 포함한 조사 도구의 과잉 제외 때문이었음. 내부 렌더러 기준과 실제 화면으로 보완. 관찰 카메라 복원 시 생긴 `1.6200001` 미세 오차도 원본 카메라 값으로 복원 후 저장함. 사용자 변경을 버리지 않음.
- 최종 콘솔 Compiling=False, Entries=0. 씬 변경은 Player 위치·회전 및 설정 참조만이며, 종료 후 에디터 씬 복사본은 저장된 Pegasus와 텍스트 일치.
- 근거/복구본: `docs/validation/PegasusPlayerSpawn/`. 최종 캡처 `Final.png`는 확인 통과 후 1회. Unity 재시작, 자동 테스트·빌드, Git 커밋·푸시는 실행하지 않음.

## Pegasus 서 있는 수송자 통과 장애 수정 — 완료

- 실행모드에서 기존 수송자를 움직여 동력실의 조종실 방향 H01, 통제실 방향 H05 입구에서 전진이 막히는 현상을 직접 확인. 해당 입구 천장과 연결부 상단을 보정해 수정 후 선 채로 통과하는 화면을 확인했다.
- 두 입구의 천장, 측벽 상단, 문 위 벽 부분 및 연결부 실링을 맞춰 머리 공간을 확보했다. 기존 공유 메시 18개를 Pegasus 전용 에셋으로 분리해 수정했으며, 원본 샘플과 다른 씬은 변경하지 않았다. 바닥과 모든 Transform, Player 높이·반지름·속도·중력 유지.
- 활성 복도 10개와 입구 20곳의 중앙·좌우 경로를 양방향으로 보행했다. 실제 입력 시스템/Motor/CharacterController를 사용하고 숙이기·점프·자유 비행 없이 도착. 방 내부로 이어지는 꺾인 경로도 보정해 확인했다. 채택한 보행 기록 60조건 모두 도착했으며 수치만으로 판정하지 않고 이동 화면을 직접 확인했다.
- 수정 입구에서 위쪽을 바라보며 시점을 회전해 천장·벽 이음새를 확인. 확인 화면에서 외부 노출 틈 없음. H01 닫힌 문은 이동을 막고 재개방 후 통과하는 것을 확인했다.
- 포커스 변화로 입력이 중단된 최초 결과는 통과 근거에서 제외하고 재시도했다. 검증 중에만 임시 입력 BackgroundBehavior를 보완하고 종료 시 원상복원했다. 게임의 영구 입력 설정 변경 없음.
- 최종 콘솔 Compiling=False, Entries=0. 실행모드 종료와 임시 입력 장치 정리 완료. 에디터 씬 복사본과 디스크 Pegasus 전체 텍스트 일치. 씬 변경은 MeshFilter 18개, MeshCollider 10개, BoxCollider 6개와 전용 메시 에셋 참조 전환뿐이다.
- 근거/복구본 및 상세 기록: `docs/validation/PegasusStandingClearance/Report.md`. 최종 `Final.png`는 관련 확인 통과 후 1회만 생성. Unity 재시작, 자동 테스트·빌드, Git 커밋·푸시 없음.

## Pegasus 벽 통과 방지 — 완료

- 조종실 벽을 실제 입력으로 통과해 외부로 추락하는 수정 전 화면을 확인했다. 구조 벽 충돌체가 없거나 꺼져 있었으며 플레이어의 자유 비행은 이미 꺼져 있었다.
- 구조 벽·출입구 측벽·통제실 내부 칸막이·수평 복도 측벽에 실제 메시 기반 MeshCollider 93개 추가. 외형, 배치, 플레이어 크기/속도/시작 위치, 공유 에셋 및 전역 물리 설정은 유지했다.
- 수정 후 여섯 방의 벽과 활성 복도 10곳 측벽에서 실제 입력으로 전진해도 벽 앞에 머무르는 화면을 확인했다. 중앙/좌우 양방향 통행은 60개 직선 경로 중 59개 도착. 창고→동력실 한쪽 가장자리의 마지막 목표점은 곡면 벽에 막혔으며, 같은 가장자리 접근 후 안쪽으로 방향을 틀어 정상 진입하는 전체 경로를 추가 확인했다. 이 실패를 숨기거나 벽 충돌을 제거하지 않았다.
- H01 닫힌 문 차단과 재개방 후 통행 확인. 가상 입력을 기존 Input System/Motor/CharacterController에 공급했으며 이동 중 위치 강제 변경 없음.
- 씬 차이는 MeshCollider 93개와 GameObject 컴포넌트 참조 93개뿐. 실행모드 종료 후 저장된 Pegasus와 에디터 복사본 일치, Dirty=False.
- 마지막 에디터 전환에서 내부 LayerSettings 캐시 공유 위반 4건 발생. 원문 보존 후 Refresh와 Play 보행/종료 재확인에서 재발하지 않았으며 최종 콘솔 Entries=0, Compiling=False. 캐시 파일 직접 편집이나 Unity 재시작 없음.
- 상세 근거: `docs/validation/PegasusWallCollision/Report.md`. 자동 테스트·빌드 및 Git 작업은 실행하지 않았다.
