## 조종실 보호 조건

- 조종실 관련 파일은 수정하지 않았다.
- 조종실 `Ensure` 또는 재생성 계열 명령은 실행하지 않았다.
- 조종실 루트와 오브젝트는 동력실 적용 중 삭제, 재생성, 이동하지 않았다.
- 동력실 적용 스크립트는 조종실 루트와의 Bounds 겹침만 확인하고, 조종실 자체는 수정하지 않는다.

## 사용자 편집값 스크립트 반영

- 사용자가 Unity 에디터에서 `Approved Engine Room 01 Shell`을 직접 편집했다.
- 요청에 따라 현재 열린 씬의 ER-01 Transform 값을 캡처했다.
- 캡처 명령:
  - `CaptureApprovedEngineRoomShellCurrentObjects`
- 캡처 기록:
  - `artSample/engine_room_shell/editor_current/er01_current_objects.md`
- 반영 파일:
  - `Assets/_Project/Editor/Validation/ApprovedEngineRoomShellBootstrap.cs`
- 반영 방식:
  - `UserEditedTransformOverrides` 배열에 현재 `localPosition`, `localRotation`, `localScale` 값을 저장했다.
  - 현재 씬에서 삭제되어 캡처되지 않은 ER-01 하위 오브젝트는 다음 생성 때 다시 살아나지 않도록 snapshot 밖 오브젝트 제거 로직을 추가했다.
- 실행하지 않은 것:
  - `Run-ApprovedEngineRoomShell.ps1`
  - `EnsureApprovedEngineRoomShell`
  - 동력실 재생성

  - 스크린 모델링은 보여주기 용도이고, 세부 내구도 표시는 UI로 구현한다고 확인했다.

  - `Assets/Sci-Fi Styled Modular Pack/Prefabs/Decorative elements/big_screen.prefab`를 벽면 스크린 하우징 기준 에셋 후보로 기록했다.

  - 디스플레이 면에 `Assets/Sci-Fi Styled Modular Pack/Textures/computer_wall_texture.png`를 넣어 컴퓨터 화면처럼 보이도록 한 버전을 만들었다.

- 유지한 조건:
  - 스크린 하우징, 프레임, 볼트, 케이블, ER-10 하단 예비 커버 모델링 구조는 마지막 텍스처 교체 때 변경하지 않았다.
  - ER-09 샘플은 아직 사용자 최종 승인 전이므로 Unity 씬, 프리팹, 런타임 자산에 연결하지 않았다.
