# 진행 기록 2026-08-31

## Stick_Carry 막대기 RightHand 상대 위치 고정

- 사용자 지시에 따라 저장된 씬 값이나 손바닥 추정값을 사용하지 않고, 열린 Unity 에디터의 `Stick_Carry/Armature/Hips/Spine02/Spine01/Spine/RightShoulder/RightArm/RightForeArm/RightHand/Stick_Carry_Item` Transform을 변경 없이 먼저 읽었다.
- 열린 Unity에서 직접 캡처한 `RightHand` 기준 `localPosition`은 `(0.026, -0.012, -0.374)`였다. 캡처 당시 부모가 `RightHand`임을 확인했고, 회전은 `(-0.95831877, -0.16028203, 0.000000067055204, -0.23650531)`, 스케일은 `(100, 100, 100)`이었다.
- 저장돼 있던 이전 씬 좌표 `(-0.0042916946, -0.0834606, -0.34019476)`는 현재 열린 Unity의 사용자 편집값과 달랐으므로 고정값으로 사용하지 않았다.
- `PlayerHandsObjectAnimationTools`에 실측 `localPosition`을 그대로 상수화하고, 손바닥 중심·애니메이션 평균·화면 오프셋으로 막대 위치를 생성하던 적용 호출을 제거했다. 막대 재생성 시 `RightHand.localPosition`에 실측값을 직접 대입한다.
- 전용 `CaptureStickCarryCurrentRightHandLocalTransform` 명령으로 수정 전 열린 Unity 값을 `docs/validation/player_stick_carry_grip_material_fix_2026-08-30/current_right_hand_local_transform.json`에 기록했다.
- 스크립트 재적용 후 캡처값, 스크립트 고정값, 씬의 `Stick_Carry_Item.localPosition`이 세 축 모두 정확히 일치했다. 적용 전후 회전 변화는 `0°`였고 원본 애니메이션 자세 차이는 위치·회전 모두 `0`이었다.
- 1순위 직접 확인에서 정면과 오른손 정면·측면 확대의 최종 8개 애니메이션 위상을 확인했다. 사용자가 맞춘 현재 막대 위치가 스크립트 재적용 뒤에도 동일하게 유지됐고, 크기·애니메이션·머티리얼 1개와 텍스처 5개도 변경되지 않았다.
- 직접 시각 검증까지 완료한 상태를 반영해 `docs/PLAYER_ANIMATION_REQUIREMENTS.html`의 `PLR-STK-001 / Stick_Carry` 행을 `animation-complete`, `data-completion="완료"` 상태로 갱신했다.
- Unity 반영에는 `./scripts/Refresh-UnityProject.ps1`, `CaptureStickCarryCurrentRightHandLocalTransform`, `ApplyStickCarryOneHandAnimationAndStickGrip`, `CaptureStickCarryGripDiagnostic`, `CaptureStickCarryOneHandAnimationAndStickGrip`을 사용했다. `artSample/` 신규 제작과 Harness·EditMode·PlayMode·Windows Build는 실행하지 않았다. 관련 변경은 본 진행 기록과 HTML 완료 체크를 포함해 선별 커밋·푸시 대상으로 정리했다.
