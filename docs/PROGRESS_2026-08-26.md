# 진행 기록 - 2026-08-26

## 수송자(플레이어) 애니메이션 요구사항 문서화

- 원본 기획서 `docs/GAME_DESIGN_SOURCE.txt`를 기준으로 플레이어에게 필요한 애니메이션을 동작 단위로 명세했다.
- Markdown 원본 `docs/PLAYER_ANIMATION_REQUIREMENTS.md`와 브라우저 확인용 `docs/PLAYER_ANIMATION_REQUIREMENTS.html`을 함께 작성했다.
- 기본 이동, 손과 물체, 무기, 방호 장비, 치료·강화·기타 물품, 특수 물품, 화물선 조종, 포탑 조작, 화면·단말기, 수리·복구, 피격·사망, 상태 이상·물리 반응과 애니메이션 외 연계를 각각 독립 요구사항으로 정리했다.
- 각 항목에는 제작 키, 동작 범위, 반복 여부, 시작 조건, 종료 상태, 취소 조건, 원본 근거와 우선순위를 기록했다.
- 아직 기획이 확정되지 않은 동작은 임의로 결정하지 않고 `기획 미확정` 또는 제작 전 확정 항목으로 분리했다.

## 기본 이동과 자세 확정

### 걷기

- 걷기 원본은 `Player_Walk_Forward`, `Player_Walk_Backward`, `Player_Sidestep`, `Player_Walk_Diagonal` 4개로 확정했다.
- 좌우 옆걸음은 오른쪽 옆걸음 원본 하나를 기준으로 왼쪽에서 Animator Mirror를 사용한다.
- 대각선 걷기는 오른쪽 전방 인플레이스 원본 하나를 사용하고, 왼쪽은 Mirror, 실제 네 방향 이동은 Rigidbody 입력 벡터로 처리한다.
- 대각선 후진에서도 클립을 역재생하지 않으며, 걷기 방향 전환에는 Blend Tree를 사용하지 않는다.

### 달리기

- 달리기는 `Player_Run_Forward` 전진 달리기 원본 1개만 제작하는 것으로 확정했다.
- 후진, 좌우, 왼쪽·오른쪽 전진 대각선과 왼쪽·오른쪽 후진 대각선의 별도 달리기 제작 요구사항은 제거했다.

### 점프

- 점프는 `Player_Jump` 원본 1개에 도약, 상승, 하강, 일반 착지를 모두 포함하는 것으로 확정했다.
- 맵이 큰 높이 차가 없는 평면 구성이므로 별도 낙하 루프와 강한 착지 애니메이션은 제작하지 않는다.
- 폭발·사출·강제 추락에 사용하는 공중 물리 반응과 물리 착지는 일반 점프와 용도가 달라 별도 상태로 유지했다.

### 앉기

- 앉기 동작은 아래 7개로 확정했다.
  - `Player_Crouch_Enter`: 앉기 시작
  - `Player_Crouch_Idle`: 앉은 대기
  - `Player_Crouch_Forward`: 앉은 전진 이동
  - `Player_Crouch_Backward`: 앉은 후진 이동
  - `Player_Crouch_Sidestep`: 앉은 옆걸음 이동
  - `Player_Crouch_Diagonal`: 앉은 대각선 이동
  - `Player_Crouch_Exit`: 일어서기
- 좌우 옆걸음과 네 방향 대각선의 개별 제작 키는 각각 공용 옆걸음과 공용 대각선 항목으로 통합했다.

## 현재 적용 상태와 검증

- 이번 작업은 Unity 적용 전 제작 요구사항 문서화만 수행했다.
- Unity 씬, 프리팹, 모델, 실제 `AnimationClip`, Animator Controller와 런타임 로직은 변경하지 않았다.
- Markdown과 HTML의 기본 이동 표, 제작 전 확정 항목과 Base 구현 기준을 직접 대조해 동일한 내용을 확인했다.
- 검색을 통해 제거한 방향별 달리기·점프 분리·앉기 방향별 제작 키가 두 문서에 남아 있지 않은 것을 확인했다.
- 실제 모델링·애니메이션 에셋을 수정하지 않았으므로 Unity 직접 시각 검증은 수행 대상이 아니다.
- 사용자가 명령명과 대상 범위를 직접 지정하지 않은 Harness, EditMode, PlayMode, Windows Build 검증은 실행하지 않았다.
