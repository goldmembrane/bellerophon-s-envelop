# Progress 2026-06-04

이 문서는 2026-06-02 진행 문서 이후 이어서 작업한 MVP 구현 상태와 사용자 확인으로 확정된 변경사항을 따로 정리한다.

## 사용자 확인 사항

- 화물 직접 집기, 직접 운반, 직접 납품 상호작용은 "아직 구현하지 않음"이 아니라 게임 컨셉에 맞지 않으므로 구현 금지 항목이다.
- 게임 오버는 돈이 부족한 즉시 발생하지 않는다. 첫 마이너스 정산은 부채 유예로 처리하고 다음 운행 정산 후에도 마이너스이면 조작 불가능한 전체 컷씬 게임 오버로 전환한다.
- 정산에서는 수리비를 차감하지 않는다. 수리비는 행성 정비 화면에서 실제 수리할 때 청구한다.
- 수동 운행 화면과 포탑 수동 화면은 모달이 아니라 전체 화면 전환이며, 배경은 불투명해야 한다.
- 무기를 든 상태의 우클릭 보조 모드 전환은 홀드가 아니라 우클릭 1회 토글 방식이다.
- 14단계 첫 적대개체는 파르붐 1종으로 테스트한다.
- 침입 확률은 기획서의 씨앗체 규칙을 확인해 적용한다.

## 완료된 구현

### Phase 8: 자동/수동 운행 루프

- `TransportRunState` 기반 운행 진행도, 남은 시간, 자동/수동 운행 상태를 추가했다.
- 조종실 내구도 조건에 따른 자동 조종 가능 여부를 반영했다.
- 수동 운행은 전체 화면 불투명 화면으로 전환되며, WASD 회피 입력을 처리한다.

### Phase 9: 정산과 게임 오버

- 튜토리얼 보상은 협회 소속 기준 총 `$1100`으로 확인 및 반영했다.
- 마이너스 잔액 1회차는 부채 유예 상태로 두고 다음 운행을 허용한다.
- 다음 정산 후에도 마이너스이면 플레이어 조작을 막고 화물선에서 포드가 버려지는 전체 컷씬 게임 오버 화면을 표시한다.
- 수리비는 정산 차감에서 제거하고 정비 단계 청구로 분리했다.

### Phase 10: 행성 정비와 다음 운송 준비

- 정산 화면의 `Maintenance` 버튼에서 행성 정비 화면으로 전환되도록 구현했다.
- 정비 화면에서 전체 함선 내구도, 구역별 손상도, 예상 수리비, 다음 의뢰 목록을 표시한다.
- 수리 버튼은 실제 지갑에서 수리비를 차감하고 6구역 내구도를 정상화한다.
- 상점, 개인 화물, 업그레이드는 진입 버튼/안내 중심의 골격으로 남겼다.

### Phase 11: 소행성 지대 위험

- `TransportHazardState`, `TransportHazardRules`를 추가했다.
- 튜토리얼 이후 운행에서 소행성 지대 발생/지속/결과 판정을 연결했다.
- 자동 조종 방치 시 함선 구역 손상, 수동 회피 입력 시 피해 회피가 가능하도록 만들었다.

### Phase 12: 수동 포탑과 외부 목표

- 수동 포탑 화면을 전체 화면 불투명 화면으로 전환했다.
- 마우스 조준, 좌클릭 단발/홀드 연속 발사, 0.25초 발사 딜레이, 탄창 50발, 재장전 2초, 발당 50 피해를 반영했다.
- 외부 목표 파괴 시 소행성 위험을 중화한다.

### Phase 13: 침입자/적대 개체 프레임워크

- `IntruderDefinition`, `IntrusionAttemptState`, `IntruderEntityState`, `IntruderRules`를 추가했다.
- 침입 시도, 침입 성공, 목표 구역, 목표 유형, 피해 결과를 순수 로직으로 테스트 가능하게 구성했다.
- 구체 개체 구현 전 공통 데이터 구조만 마련했다.

### Phase 14: 첫 침입자 파르붐

- 첫 침입자를 파르붐 1종으로 구현했다.
- 튜토리얼 첫 운행에는 발생하지 않고, 이후 운행 중 2초마다 15% 확률로 침입 판정을 수행한다.
- 파르붐의 체력 55, 이동속도 2.5, 공격 거리 1, 공격 딜레이 0.5초, 구역 내구도 피해를 반영했다.
- 파르붐 월드 placeholder 외형을 배치하고, 처치 시 제거되도록 연결했다.

### Phase 15: 무기와 비품실 기본 루프

- `PlayerEquipmentState`, `EquipmentRules`, 상점 구매/판매 골격을 추가했다.
- 시작 장비로 기본 방호복과 막대기 1개를 지급한다.
- 막대기는 피해 30, 사거리 2~3, 사용 딜레이 2.5초, 투척 모드 골격을 반영했다.
- 머스켓은 피해 50, 사거리 5~7, 사용 딜레이 3.5초, 정밀 조준 모드, 가격 `$450`을 반영했다.
- 상점에서 머스켓 구매 후 닫기 버튼이 다른 정비 버튼과 겹쳐 재오픈되는 문제를 수정했다.

### Phase 16: HUD, 맵, 분위기 1차

- 기본 중앙 조준선을 숨기고, 머스켓 정밀 조준 모드에서만 전용 레티클을 표시한다.
- 좌하단 체력/보호막 퍼센트 바를 추가했다.
- 체력/보호막 퍼센트 텍스트와 바의 세로 정렬을 맞추고 검증 조건을 추가했다.
- 우하단 화물선 내부 맵을 80% 스케일로 표시하고, 플레이어 위치 기준 현재 구역을 하이라이트한다.
- 저채도 재질, 어두운 ambient, fog, 제한된 camera far clip으로 화물선 내부 분위기 1차를 적용했다.
- 선박 내부, 선박 피해, 외부 위험, 침입자 신호용 사운드 훅을 추가했다.
- 무기 보조 모드는 우클릭 홀드가 아니라 우클릭 토글 방식으로 변경했다.
