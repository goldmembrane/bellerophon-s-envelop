# 방패 표면 샘플

- 범위: 방패의 모든 문자 표식 제거, 전면 창 반투명화
- 권장안: 창 불투명도 50%
- 비교 순서: 현재 / 35% / 50% / 65%
- 창 미리보기 픽셀 영역: (x:218, y:594, width:204, height:137)
- 전면 글자 패널 미리보기 픽셀 영역: (x:160, y:765, width:320, height:65)
- 생성형 이미지 사용: 없음
- Unity 실제 에셋 적용: 미적용, 샘플 승인 대기
- 승인 후 구현: base color의 모든 글자 UV 영역을 주변 표면으로 복원하고 전면 창을 별도 반투명 머티리얼로 분리
- 원본 FBX·메시·리그·스킨 웨이트·애니메이션 변경: 없음
