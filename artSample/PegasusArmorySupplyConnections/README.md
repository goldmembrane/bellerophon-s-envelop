## 승인 결과의 Pegasus 적용

다섯 방, H01~H05와 대응 천장, 상단·하단 연결부를 승인 샘플과 같은 배치·크기·형상으로 적용했습니다. 실제 실행모드에서 입구와 경계를 확인하고 샘플의 동일 시점과 비교했습니다. 직접 확인 기록은 [DirectReview.md](../../docs/validation/PegasusArmorySupplyConnections/TransferReview/DirectReview.md)입니다. 비대상 개체와 공유 원본 자산은 보존했습니다. 이전 연결부·불필요한 확장 리브는 교체했으며 작업 전 씬 백업으로 복구 가능합니다.

대상 씬: `Assets/_Project/Scenes/Pegasus.unity`. 기존 셔터·문턱·Collider도 승인 상태 그대로이며 실제 보행 검증 완료를 뜻하지 않습니다. 아래의 “Pegasus 미적용” 기록은 적용 전 샘플 제작 당시 이력입니다.

## 범위

최초 제작에서는 상단 세 방과 H01/H02/H05를 보존하고 무기실·비품실을 배치했습니다. 이후 사용자 지시로 같은 별도 씬의 상단 세 복도를 아래와 같이 75% 단축했습니다. 하단 무기실·비품실 연결은 그대로입니다.

## 2026-09-23 상단 세 복도 75% 단축

통제실의 위치·각도, 조종실·동력실의 각도를 유지하고 조종실·동력실 루트 위치만 옮겼습니다. 복도 본체는 기존 길이의 25%이며 폭·높이는 유지했습니다.

| 연결 | 본체 길이 | 4m/s 보행 기준 |
|---|---:|---:|
| 조종실–통제실 H02 | 14.54215m | 3.63554초 |
| 통제실–동력실 H05 | 26.89366m | 6.72341초 |
| 조종실–동력실 H01 | 9.69476m | 2.42369초 |

위 시간은 연결부·방 내부를 제외한 길이 환산값입니다. 직접 보행 실측이 아닙니다.

여섯 접점은 새 배치의 실제 입구 가장자리와 복도 끝 사이에 독립된 바닥·양벽·천장 메시를 맞췄습니다. 실행모드의 실제 Game 화면에서 안쪽 양방향, 좌우 바닥 모서리, 천장, 외부 측면·상부를 직접 확인했습니다. 확인한 경계에서 외부 배경 노출이나 통로를 가로막는 새 판은 보이지 않았습니다. 조명·대상 가시성은 바꾸지 않았습니다.

직접 확인 자료: `View_100~147.png`, `View_181~185.png`. 벽에 가려진 113·122 및 셔터 중심 근접 화면은 해당 가려진 부위의 근거로 쓰지 않았고, 조종실 외부는 181·182에서 다시 확인했습니다. 중간 실패 화면·수치 보고서는 최종 통과 근거가 아닙니다.

시각 확인 후 보존 데이터를 대조해 통제실·무기실·비품실, H03/H04와 대응 천장·하단 연결부의 기존 직렬화 내용을 유지한 것을 확인했습니다. 세 방의 회전도 동일합니다. Pegasus 파일은 이번 작업에서 저장하지 않았습니다. 콘솔 오류 0, 경고 58건은 이번에 수정하지 않은 다른 파일의 기존 API 사용/미사용 변수 등의 컴파일 경고입니다.

기존 상단 연결부 조각과 단축 구간 밖의 확장 리브는 샘플에서 교체·제거했습니다. 작업 전 씬은 `docs/validation/PegasusArmorySupplyConnections/BeforeTriangleResize.unity.txt`에 보관되어 있습니다. 공유 원본 모델은 편집하지 않았습니다.

- 통제실 아래 오른쪽 무기실용 입구 → H03 → 무기실 통제실용 입구
- 무기실 비품실용 입구 → H04 → 비품실 아래 무기실용 입구
- 수송자 보행 설정 4m/s에 맞춰 복도 본체만 H03 16m(4초), H04 12m(3초)입니다. 양끝 연결부 각 1m와 방 내부 입구 길이는 별도입니다. 이는 길이 설계 기준이며 실측 보행 성공 기록이 아닙니다.
- 새 메시: `Armory Supply Intermediate Connectors/Contact_0~3`의 바닥·양벽·천장, `Boundary Seals`의 경계 마감입니다. 기존 방·입구 메시나 원본 머티리얼은 변형하지 않았습니다.

## 직접 확인

Unity 실제 실행모드에서 관찰 카메라 위치와 방향을 바꾸며 네 입구의 방 방향, 양쪽 벽–바닥 모서리, 양쪽 벽–천장 모서리, 외부 측면 및 두 복도 내부를 확인했습니다. 발견한 무기실 입구 천장 옆 틈, 복도 벽 아래 틈, 통제실 천장 끝단 틈을 별도 메시로 보완하고 다시 보았습니다. 확인한 연결 경계에서 큰 외부 노출이나 통로를 가로막는 새 판은 보이지 않았습니다.

이미지는 `docs/validation/PegasusArmorySupplyConnections/`의 실제 Game 화면입니다. 검증 중 지오메트리 숨김이나 조명 변경은 하지 않았습니다. 가려진 초기 셔터 근접 화면은 완료 근거에서 제외했습니다. 단일 전경만으로 모든 접점의 품질을 판정하지 않았습니다.

## 제한 및 보존 사항

기존 복도 모델의 닫힌 셔터와 바닥 가로 리브, 기존 Collider 상태는 그대로입니다. 새 연결부가 입구를 막은 것은 아니지만, 현재 샘플이 플레이어로 끝에서 끝까지 통과 가능한 상태임을 검증한 것은 아닙니다. 물리 이동·끼임 검증 완료로 간주하지 않습니다. 표지판의 뒷면 글자 투과도 기존 표시 상태를 유지합니다.

이 샘플에는 운송창고와 경사 복도 연결을 추가하지 않았습니다. Pegasus, 원본 방 자산, 기존 승인 샘플에 반영하지 않았습니다. 추후 적용은 사용자 샘플 승인 및 적용 지시 범위에 따릅니다.

자동 테스트·빌드는 실행하지 않았습니다. 직접 확인 후 보조 확인한 Unity 콘솔 오류·경고는 0입니다.
