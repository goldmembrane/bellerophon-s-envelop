머스켓 총구 발사 VFX

단일 효과 평면 대신 겹친 소프트 파티클의 황백색 연소체와 난류형 체적 연기가 총구 전방·상방으로 팽창하는 3D VFX 재승인 샘플입니다.

승인됨 · Unity 적용 완료

사용자가 이 3D 방향을 승인했습니다. 화염·내부 가스·연기는 3D 공간에 분포한 소프트 파티클 군집으로, 작은 불티만 메시로 Musket_HipFire와 Musket_Aim_Fire에 적용하고 실제 Play Mode 자연 발사 루프로 직접 확인했습니다.

검토 이미지

승인 샘플과 실제 Unity 적용 비교

시간 구성

0–20ms · 점화총구 중심에 작은 백색 핵과 황색 불꽃이 시작됩니다.
20–60ms · 최대 섬광황백색 핵과 황금색 외곽을 가진 짧은 3D 연소체가 총구에서 약 0.45m까지 뻗습니다.
60–220ms · 연기 팽창섬광은 사라지고 깊이·자체 음영이 있는 짙은 회백색 난류 덩어리가 전방·상방으로 퍼집니다.
220–650ms · 잔류카메라를 향한 단일 판이 아니라 3D 공간의 연기 입자군이 월드 공간에 남았다가 사라집니다.

Unity 적용 결과

적용 상태Musket_HipFireLoop, Musket_Aim_FireLoop 정규화 시간 0.08에 한 번씩 표시
앵커현재 머스켓 총구 구멍의 실제 끝점. 임의 전방 오프셋 없이 방향은 머스켓의 stock→muzzle 로컬 전방축을 사용
3D 구성네 가지 소프트 불꽃 마스크의 밝은 화염 핵 3개와 금빛 내부 가스 최대 6개, 네 가지 다엽형 마스크를 서로 다른 위치·크기·회전으로 겹친 소프트 연기 최대 14개, 메시 불티 최대 12개의 네 계층으로 구성. 고정 화염 메시와 단일 평면 효과는 사용하지 않음
파티클 예산대상별 설정 상한 35개, 두 자연 발사 루프에서 실제 최대 34개. 연기 효과 동시 6개, 짧은 무그림자 라이트 동시 4개로 제한
공간·축척모든 계통은 총구 로컬 시뮬레이션과 로컬 스케일을 사용해 FBX 부모의 큰 상속 스케일로 확대되지 않음. 실제 검토에서 위치·회전 앵커 오차와 총구 표면 간격 모두 0
카메라HipFire에는 조준선을 추가하지 않음. AimFire의 기존 조준 UI는 유지하고 VFX만 같은 총구 앵커에서 표시
최적화128×128 공유 불꽃·연기 아틀라스 각 하나와 공유 머티리얼 3개, 프리팹의 비루프 파티클 4계통을 계속 재사용하며 발사별 생성·삭제 없음. 레이마칭·파티클 그림자·모션 벡터·노이즈·동적 라이트 그림자 없음
오류 수정연기 Velocity over Lifetime의 X/Y/Z를 같은 두 상수 모드로 통일해 반복 발사 시 곡선 모드 오류가 더 생성되지 않음

원본·추론·생성 여부

원본 기획서에서 가져온 기준은 1인칭 3D 게임, 양손 머스켓, 화면 중앙 발사, HipFire 조준선 없음과 정밀 조준 모드의 조준 UI입니다. 황백색 체적 섬광, 난류형 짙은 회백색 연기, 지속 시간과 구체적인 효과 크기는 사용자 피드백과 현재 Unity 머스켓 모델을 바탕으로 만든 신규 제안입니다. 두 승인 이미지는 OpenAI 내장 이미지 생성 도구로 제작한 3D 콘셉트 렌더이며 실제 게임 렌더가 아닙니다. 오른쪽 Unity 결과는 승인 후 실제 대상 두 상태를 자연 재생해 캡처한 직접 확인 자료입니다.
