미니 화염방사기 공격 VFX 아트 샘플

사용자 참고 이미지의 실제 화염방사기 실루엣을 기준으로, 별도 공격 메시나 투사체 모델 없이 제작한 Unity 파티클 전용 시안입니다. 보이는 화염은 분사구 끝에서 바로 시작하며, 속도와 수명 구간이 겹치는 황색·주황·적갈색 입자가 같은 거리에서 교차해 단절 없는 연소 흐름을 만듭니다. 각 레이어는 두 색 곡선을 무작위로 사용하고 짧은 꼬리가 서로 겹쳐 색 띠가 분리되지 않게 했습니다. 이 샘플은 사용자 승인을 받았으며 Flamethrower_Fire의 실제 분사구에 Unity VFX 프리팹으로 적용했습니다.

승인본 Unity 적용 결과

실제 Play Mode 반복 재생 검토

시각 구성

중심 화염
  • 분사구 끝에서 바로 시작하는 좁은 백색·황색 고온 제트
  • 앞으로 이동하면서 빠르게 부풀어 오르는 황색 점화층
  • 샘플의 4.5m 전개 비율을 유지하며 실제 적용본은 기획 사거리 최대 3m로 조정
외곽과 잔류층
  • 황색·주황·적갈색이 같은 거리에서 교차하는 전방 연소 갈래
  • 검은 원형 구체 대신 작고 길쭉한 저불투명 갈색·회색 연기 조각
  • 2×2 고대비 난류 텍스처로 밝은 가장자리와 어두운 내부 연소 무늬 표현
  • 일반 알파 혼합과 강화된 재질 알파로 밀도 높은 불투명 화염 유지
  • 화염 수명의 약 80%까지 높은 불투명도를 유지한 뒤 끝에서 빠르게 소멸
  • 7개 레이어가 겹쳐 배경에서도 윤곽이 분명한 입체적 화염

Unity 적용 내용

  • Flamethrower_Fire의 단일 발사 상태 진입 시 방출을 시작하며, 상태가 유지되면 10초 분사와 2.5초 대기 뒤 다음 분사를 계속 반복합니다.
  • 상태 종료 시 반복 요청과 새 방출을 멈추고 남은 입자만 자연 소멸합니다.
  • 현재 승인된 분사 손잡이의 실제 노즐 끝점을 앵커로 사용해 오른손과 분사기 회전을 그대로 따라갑니다.
  • 기획 유효 사거리는 1~3m이며 VFX 최대 길이는 3m에 맞췄습니다. 피격·피해 판정은 이번 작업 범위에 포함하지 않았습니다.
  • 미니 화염방사기와 수송자 메시·리깅은 수정하지 않았습니다.

추론·생성 여부

형태와 색 분포는 사용자가 제공한 참고 이미지에서 보이는 분사구 직후의 좁은 뿌리, 전방 확대, 백황색 고온부, 주황색 난류, 내부의 어두운 연소 주머니만 기준으로 옮겼습니다. 모델 형상은 추론하거나 생성하지 않았습니다. 승인 프리뷰와 같은 설정의 전용 머티리얼 5개와 2×2 난류 텍스처 2개를 VFX 자산으로 저장했으며, 기존 모델 텍스처·머티리얼은 수정하지 않았습니다.
