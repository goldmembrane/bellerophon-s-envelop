Shotgun Muzzle Flash V2

기존 효과보다 강한 순간 압력감과 불규칙한 화염 실루엣을 목표로 한 실사형 산탄총 총구 이펙트입니다.

사용자 승인 완료 · 머스켓 방식 Unity 적용

핵심 변경

  • 중심: 더 크고 강한 백색 고온 섬광
  • 형태: 위·아래로 갈라지는 불규칙한 화염
  • 입자: 전방으로 퍼지는 불티와 화약 파편
  • 마무리: 짧고 조밀한 회백색 연기 충격파

Unity 적용 결과

  • CargoRunMvp/PlayerAnimationLayout/Shotgun_Fire
  • 샷건 총구 중심을 왼쪽 원점에 연결
  • 3초 동작 시작 후 0.15초에 표시
  • 머스켓과 같은 4계층 소프트 파티클을 샷건용 넓은 원뿔로 분산
  • 단일 지배 카드 없이 최대 59개 입자와 짧은 제한형 무그림자 광원 사용

범위와 상태

AI 편집 원본은 변경하지 않고 보존했습니다. 사용자가 지적한 평면 메시 느낌을 제거하기 위해 Unity 런타임은 승인 이미지를 큰 카드로 표시하지 않고, 실제 머스켓 효과의 FlashCore·HotGas·Smoke·Embers 레이어 방식으로 재구성했습니다. 기존 애니메이션 동작과 3초 길이는 변경하지 않았습니다.
