ElectricMine_Armed_Idle 앞·뒷면 중앙부 점멸

Unity의 ElectricMine_Armed_Idle에 실제 적용된 모델 앞면과 뒷면을 기준으로, 양면 중앙부가 동시에 점멸하는 1초 주기 샘플입니다.

Unity 적용 모델 앞면 / 뒷면

앞면 · 점멸 효과 기준면

중앙 적색 버튼, 적색 외곽 링과 네 개의 기계 결합부가 보이는 면입니다. OFF / ON 비교는 이 앞면을 사용합니다.

뒷면 · 수송자 파지 시 노출면

어두운 원판과 방사형 날개 구조가 보이는 면입니다. 중앙의 갈색 원형 캡을 뒷면 점멸 부위로 사용합니다.

앞면 OFF / ON 직접 비교

뒷면 OFF / ON 직접 비교

대상ElectricMine_Armed_Idle

고정 조건

  • 앞면·뒷면 각 비교에서 좌우 모델의 형상, 배치, 카메라, 재질, 배경은 동일합니다.
  • 앞면 중앙 버튼과 뒷면 중앙 원형 캡 이외의 본체, 기계 홈, 방사형 핀과 배경에는 적색 빛이 번지지 않습니다.
  • 앞면과 뒷면의 점등·소등 시점은 서로 정확히 일치합니다.
  • 전기 아크, 스파크, 연기, 입자, 빔, 경고 아이콘과 추가 조명은 포함하지 않습니다.
  • 기존 전류 지뢰 모델 디자인은 변경하지 않습니다.

제작 정보

제작 방식: ElectricMine_Armed_Idle의 실제 적용 모델과 현재 할당된 머티리얼을 저장하지 않는 Unity Preview Scene에 복제해 앞면과 뒷면을 직접 렌더링했습니다. 각 면의 실제 Unity 렌더를 편집 원본으로 지정해 내장 이미지 생성 도구의 정밀 오브젝트 편집 방식으로 점멸 비교를 제작했습니다.

편집 범위: 각 비교의 좌우에 같은 Unity 기준 이미지를 배치했습니다. 앞면은 오른쪽 패널의 기존 중앙 적색 버튼에만, 뒷면은 오른쪽 패널의 기존 중앙 원형 캡에만 적색 발광과 국소 블룸을 추가했습니다. 두 부위는 같은 ON 0.5초 / OFF 0.5초 타이밍으로 동시에 점멸합니다.

이 문서는 시각 승인용 샘플이며, Unity 에셋·머티리얼·씬에는 아직 반영하지 않았습니다.
