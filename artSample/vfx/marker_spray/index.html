1m 끝점의 반높이는 약 12.28cm, 전체 높이는 약 24.56cm입니다. 가까운 곳은 좁고 진하며 전방으로 갈수록 밀도와 불투명도가 감소합니다.

LOOP

지속 입력 연속 분사

입력 유지 중 생성이 끊기지 않습니다. 오래된 입자는 전방에서 자연스럽게 사라지고 새 입자가 원점에서 이어집니다.

ASSETS

독립 입자 3종

부드러운 미스트, 건조 미세 입자, 속도 방향 흐름 텍스처를 분리해 반복 무늬를 줄입니다.

URP

투명 파티클 머티리얼

프로젝트의 기존 VFX 관례와 같은 URP Particles/Unlit, Transparent Surface, ZWrite Off를 사용합니다.

RELEASE

입력 해제 후 자연 감쇠

새 방출만 중단하고 이미 발생한 입자는 World 공간에서 수명 끝까지 이동한 뒤 투명하게 사라집니다.
