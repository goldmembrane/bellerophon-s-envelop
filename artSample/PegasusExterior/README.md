# Pegasus 외형 + 기존 내부 아트 샘플

최신 작업: 외형 부유 부품 조사·삭제를 완료했습니다. 동일 구도의 Unity 실행모드 전후 비교는 [FloatingReview.html](FloatingReview.html), 삭제한 원본 제작 단위 641개 목록은 FloatingRemoval.json입니다. 기존 부착 부품은 이동·재설계하지 않았습니다. 원본 Pegasus와 내부는 유지했습니다. 삭제 전 모델은 BeforeFloatingRemoval/에 백업했습니다. 아래 내용은 이전 제작 이력입니다.

상태: 샘플 제작 및 Unity 직접 검토 완료. 사용자 외형 승인 대기이며 Pegasus 생산 씬에는 적용하지 않았습니다.

최신 수정: 사용자 요청으로 외부 태양광 패널/전용 지지대, 사다리, 외형 글자를 모두 제거했습니다. 내부 표지판과 선체·안테나·추진기·탱크는 보존했습니다. Unity 실행모드에서 양측·후방·하부 및 내부 표지판을 직접 확인했습니다. 최신 최종 화면은 `docs/validation/PegasusExterior/Exterior_Removal_Final.png`이며 아래 최초 제작 기록의 패널 포함 화면은 과거 이력입니다. 제거 전 모델·스크립트·화면은 `BeforeRemoval/`에 보관했습니다.

## 보존 범위

현재 Pegasus의 여섯 공간실, 복도, 천장, 연결부와 하위 구조를 위치·회전·크기·활성 상태 그대로 별도 샘플에 복사합니다. 원본 Pegasus 및 기존 공유 메시·재질은 변경하거나 저장하지 않습니다. 미사용 경사 복도의 비활성 상태도 유지합니다.

## 기준 이미지와 설계

- 사용자 제공 `Reference.png`의 산업용 화물선 실루엣, 전방 다각형 함교/도킹부, 중앙 적층 컨테이너와 노출 트러스, 후방 원통형 탱크/추진기, 안테나·보조 패널을 기준으로 합니다.
- 반대편·바닥·후면은 사용자의 허용에 따라 같은 디자인 언어로 설계하는 창작 영역입니다. 이미지에 보이지 않는 구조를 원본과 동일하다고 주장하지 않습니다.
- 내부 배치가 약 72m × 66m로 넓으므로 원본 이미지보다 중앙 선체를 넓히고 앞뒤 외장 구간을 연장합니다. 실측 내부 전체를 감싸는 선체 외피는 중공 형태이며 중앙에 막힌 덩어리를 넣지 않습니다.
- 새 외부 함교형 구조는 외형상의 상부 구조물입니다. 기존 내부 조종실을 이동시키거나 새 창문·통로를 뚫지 않습니다. 외부 추진기·도킹부·안테나는 기능 없는 아트입니다.
- 도장 얼룩·금속 흠집·마모·거칠기·노멀은 절차적 텍스처입니다. 참고 이미지를 텍스처로 투사한 평면 그림이 아닙니다.

## 완료 기준

Unity 실행모드의 실제 외형을 참고 이미지와 비교하고 전후좌우·위아래를 확인합니다. 내부 각 방과 복도에서도 외피 관통·통로 침범이 없는지 직접 확인합니다. 관찰한 화면 근거를 기록한 뒤에만 원본 보존·치수·콘솔을 보조 대조합니다. 현재 닫힌 셔터의 개폐/통과 기능은 이번 작업에 포함하지 않습니다.

## 직접 확인 결과와 열기

Unity에서 위 샘플 씬을 열면 `ShipExterior`가 신규 외형이고 `PreservedInterior` 아래에 기존 여섯 공간실과 복도·연결부가 있습니다. 현재 에디터는 이 샘플 씬을 열어 둔 상태입니다. Play Mode 기본 카메라는 외형 전체를 보여줍니다.

실행모드에서 외부 전후·양측·하부와 내부 여섯 방, H01–H05, 창고 연결 복도 다섯 곳을 직접 관찰했습니다. 확인한 내부 화면에서 신규 외피 침범은 없었습니다. 패널 격자와 상부 보강대 정렬은 시각 검토 후 수정하고 다시 확인했습니다. 최종 화면은 `docs/validation/PegasusExterior/Exterior_Final.png`, 상세 근거와 제한은 같은 폴더 `VisualReview.md`입니다.

원본 Pegasus 파일은 작업 전후 동일하고, 복사한 내부 계층의 위치·회전·크기·활성 상태도 원본 스냅샷과 일치합니다. 기존 메모리 누수 진단(Persistent 16 / TransformAccessArray 8) 및 내부 조명 shadow atlas 축소 경고는 남아 있습니다. 콘솔이 완전히 깨끗하다고 주장하지 않습니다. 자동 테스트·빌드·Git 작업은 실행하지 않았습니다.
