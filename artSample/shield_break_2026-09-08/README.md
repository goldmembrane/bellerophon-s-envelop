# 방패 파손 아트 샘플

- 승인 상태: 사용자 승인 완료
- Unity 적용 상태: 파편 형태·재질·방향과 `10.0배` 선형 이동 유지, 파손 시작 1초 뒤 숨김 적용 및 직접 확인 완료
- 대상: 승인된 글자 제거 방패 몸체와 불투명도 65% 창 전체
- 파편 수: 17개 (사용자 지정 상한 20개 이하)
- 파편 형태: 난수 중심점으로 나눈 크기·면적·윤곽이 서로 다른 불규칙 다각형
- 재생시간: `2.866667초` (`Shield_Break_Reaction_Mixamo`와 동일)
- 분산: 조각별 방향·거리·회전은 시드 `20260908`로 서로 다르며, 합성 방향은 수송자 기준 오른쪽 뒤편입니다. 파쇄 윤곽은 별도 시드 `20260913`으로 재현합니다.

`Shield_TextFree_Window.asset`, `Shield_TextFree.mat`, `Shield_Window_Transparent.mat`을 Unity에서 직접 읽어 조각을 만들었습니다. 기존의 2열×4행 균등 분할을 제거하고, 방패 평면에 흩어진 난수 중심점 17개의 Voronoi 경계로 모든 삼각형을 빠짐없이 나눴습니다. 생성형 이미지나 별도 외형을 사용하지 않았고 원본 메시·UV·리그·스킨 웨이트·텍스처·머티리얼은 수정하지 않았습니다.

승인 근거는 [index.html](index.html)의 영상과 네 단계 비교 이미지입니다. 파편 형태·재질·개별 방향은 유지하고, `Shield_Break_Reaction` 런타임은 최종 `10.0배` 선형 이동을 사용합니다. 후속 사용자 지시에 따라 파손 시작 `0.05초`부터 1초 뒤인 `1.05초`에 파편을 숨기고 다음 반복 시작까지 숨김 상태를 유지합니다. 전면 카메라에서는 수송자의 오른쪽이 화면 왼쪽으로 보입니다.
