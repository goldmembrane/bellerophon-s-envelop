## 2026-09-24 셔터 외형 추가

사용자의 ‘외형만 배치’ 지시에 따라 기존 SC-S01의 하우징·닫힌 셔터·장갑판·빨간 경고 띠를 다섯 신규 복도 양 끝에 복제했습니다. 개폐 기능이나 애니메이션은 추가하지 않았습니다. 닫힌 고정 외형이므로 현재 상태의 통과 가능성을 보증하지 않습니다.

실행모드에서 10곳 모두 정면, 뒷면, 바닥 접합과 외측 상부를 직접 확인했습니다. 원본 외형과 비교했으며 기존 방·바닥·복도 형상은 수정하지 않았습니다. 확인 이미지와 한계는 `../../docs/validation/PegasusCargoConnections/ShutterDirectReview.md`에 기록했습니다.

최종 콘솔에 Persistent 16 allocations / TransformAccessArray 8 allocations 누수 메시지가 남았습니다. 이전 기록에도 같은 메시지가 있지만 원인을 특정하지 않았습니다. 전체 완료 판정과 최종 캡처는 보류했습니다. 실행모드는 종료했고 저장된 샘플 씬을 열어 두었습니다.

- Unity 별도 씬: `Assets/_Project/ArtSamples/PegasusCargoConnections/PegasusCargoConnections.unity`
- 기존 다섯 방과 기존 연결은 기준 위치·각도·크기를 유지합니다.
- 창고만 배치하고 창고 쪽 입구 위치·방향을 조정합니다. 지정된 다섯 방의 창고용 입구와 각각 연결합니다.
- 창고 천장 상단은 비품실 보행 바닥보다 0.3m 아래입니다.
- 복도 본체는 경사를 따른 중심선 18m, 수송자 보행속도 4m/s 환산 4.5초입니다. 양 끝 접속부는 이 길이에서 제외합니다.
- 입구의 출구 방향에 맞춘 완만한 곡선으로 연결하며, 기존 방을 이동하거나 복도끼리 교차시키는 배치는 제외합니다.
- 제작 당시에는 Pegasus 미적용이었으며, 사용자 승인 후 2026-09-24 적용했습니다.

조사 자료는 `docs/validation/PegasusCargoConnections/`에 있습니다. 조사 이미지와 수정 결과·최종 검증 이미지를 혼동하지 않습니다.

## 셔터 배치 전 연결부 직접 확인 이력

Unity 실행모드에서 다섯 경로를 임시 CharacterController로 양방향·양측 이동했습니다. 다섯 순방향 이동 기록 각 1회의 전체 연속 화면, 역방향 입구 접근 화면과 별도 저시점·외측 상하 시점을 직접 검토했습니다. 관찰한 새 연결 경계에는 외부로 열린 틈이나 통로를 막는 면이 보이지 않았습니다. 모든 저장 프레임을 검토했다는 뜻은 아닙니다.

기존 방 바닥·충돌체는 수정하지 않았습니다. 빠짐 방지는 새 연결부 소속 입구 받침으로 처리했고, 측면·상부 접합 마감도 연결부에 넣었습니다. 실제 게임 플레이어 전체 동작 검증과 임시 CharacterController 보행 확인은 구분합니다.

직접 확인 뒤 길이를 대조했습니다. 다섯 본체는 각각 약 18m(경사 중심선), 4m/s 환산 약 4.5초입니다. 기록된 이동 소요 시간 자체가 4.5초라는 뜻은 아닙니다.

콘솔에서 오류는 확인되지 않았으나 추가 조명 그림자 해상도 축소 경고는 남아 있습니다. 기존 방 표지의 깊이 표시 문제와 무관한 기존 구조는 변경하지 않았습니다. 자동 테스트·빌드·Git 작업은 실행하지 않았습니다.
