## 적용한 외형

- 교체 FBX에 이미 있는 묶은 두건 표면은 짙은 적갈색 비금속 천으로,
  얼굴은 매끄러운 중암도 건메탈로 분리했습니다. 머리 높이값으로
  나누지 않고 정면·3/4·측면 토폴로지에서 확정한 기존 머리
  폴리곤 `126`개를 두건 표면으로 고정했습니다.
- 두건의 기존 주황 화염 문양은 유지했습니다. 얼굴에는 두건 바로
  아래에서 서로 떨어진 따뜻한 암적색 광학부와 기존 금속면 위의
  어두운 적갈색 소켓만 표시했습니다.
- 눈은 얼굴 전체의 공통 X/Y 평면 투영에서 분리했습니다. 렌더
  프레임에서 평가된 기존 좌우 상단 안면판에 각각 접선축을 맞춘
  독립 투영을 사용하므로, 정면과 3/4에서 가까운 눈과 먼 눈이
  각 표면의 경사와 원근을 따릅니다.
- 두 눈은 하나의 렌즈 원본을 좌우 표면에 독립 배치하며 중앙 금속,
  관자놀이, 두건, 얼굴 하단을 가로지르지 않습니다. 이마 문양은
  기존 머리 로컬 표면 범위에 그대로 고정했습니다.
- 기준 이미지처럼 두 눈의 바깥쪽 눈꼬리는 높고 중앙 쪽 끝은 낮게
  보이도록, 기존 접선 평면 안에서 화면 왼쪽 눈을 `-16°`, 오른쪽
  눈을 `-14°` 회전했습니다. 정면 발광 영역 주축은 각각 `+8.9°`,
  `-11.6°`로 서로 중앙을 향해 내려갑니다.
- 기준 이미지의 더 큰 세로 눈 비율에 맞춰 두 눈의 접선 평면 투영
  너비 `5.0`과 중심·각도는 유지하고 높이만 `3.0`에서 `4.5`로
  확대했습니다. 정면과 3/4에서 두건·중앙 금속·관자놀이·얼굴
  하단을 침범하지 않습니다.
- 이번 색상 수정은 원본 이미지를 열거나 색상을 추출하지 않고,
  현재 샘플의 푸른 계열만 산화철·마호가니 계열 적갈색으로
  교체했습니다. 눈과 흉부 표시도 같은 계열의 따뜻한 암적색
  발광으로 변경했습니다.
- 얼굴 알베도에 남아 있던 반복 가로선을 제거하고, 러프니스·
  메탈릭 변화도 평탄화했습니다. 얼굴 노멀과 높이 맵은 평탄하며
  입·환기구·코·턱·추가 패널 문양은 없습니다.
- 몸통의 색상 경계를 만든 2D 투영 오버레이와 발광·금속성·거칠기
  투영 맵 연결을 모두 제거했습니다.
- 원본 몸통 `442`면에서 실제로 분리된 `7`개 연결 표면을 확인했고,
  검토 샘플에서는 중앙 상단의 독립 연결 표면 `97`만 삭제했습니다.
  남은 몸통 `424`면과 `6`개 연결 표면에는 적갈색 외장과
  중앙·골반 갑주, 짙은 내부 기계부를 배정했습니다.
- 법선 각도로 세분하면 `32°` 기준 `122`개 조각으로 쪼개져 다시
  삼각 얼룩이 되므로 해당 방식은 사용하지 않았습니다.
- 상단 중앙의 작은 연결 표면 `97`은 실제 중심 갑주보다 위에 따로
  끼어 있는 독립 판이므로 검토 샘플에서 정점 `11`, 에지 `27`,
  면 `18`, 루프 `54`를 실제 삭제했습니다. 재질로 숨기거나 위치를
  옮긴 결과가 아닙니다.
- 허벅지와 정강이는 어두운 적갈색 강철을 기본으로 하고 국소적인
  밝은 판만 남겼습니다.
- 화염방사기는 짙은 건메탈, 후방 탱크는 매끄러운 마모 강철, 호스는
  거친 검은 고무로 분리했습니다. 황동·열변색은 작은 탱크 피팅에만
  제한했습니다.
- 새 모델의 기존 판금 형상을 우선하며 알베도에는 저주파 명도 변화,
  짧고 제한된 긁힘과 미세 수평 금속결만 넣었습니다. UV마다 늘어나던
  굵은 격자·대각선·볼트 무늬와 강한 패널 노멀은 제거했습니다.
- 몸통의 각 연결 표면은 전용 알베도·금속성·거칠기·미세 노멀만
  사용하며, 임의 패널 선·상태 표시·복부 무늬를 그리지 않았습니다.
- 팔과 다리의 재질 배정 및 텍스처는 이번 작업에서 변경하지
  않았습니다.
- 몸통·가스통·무기 재질 배정과 텍스처도 이번 얼굴 수정 전 상태를
  유지했습니다.
- 중앙 하단 연결 표면 `63·84`의 재질 배정도 이번 수정 전 상태를
  유지했습니다.
- 기준 이미지에 없는 입·세로 환기구·얼굴 패널·후면 문양·추가
  부품·화염 VFX는 만들지 않았습니다.
