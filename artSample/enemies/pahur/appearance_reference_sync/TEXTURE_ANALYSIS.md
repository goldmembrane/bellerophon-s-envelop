# 교체 파후르 모델 기준 이미지 텍스처 분석

## 기준 이미지에서 확인한 외형

- 머리는 챙 있는 모자가 아니라 윗머리에 밀착해 감고 뒤쪽에 묶은
  짙은 남색 두건입니다. 이마 중앙에는 작은 주황 화염 문양과 어두운
  청색 코어가 있습니다.
- 얼굴은 입이나 세로 환기구가 없는 매끄러운 짙은 금속면이며,
  서로 떨어진 두 개의 선명한 청색 광학부가 보입니다.
- 흉부 중앙은 밝은 강철 쉘, 그 둘레는 짙은 청회색 장갑이며, 복부는
  장갑보다 어두운 수평 적층 기계 모듈로 분리되어 있습니다.
- 허벅지와 정강이는 어두운 청회색 강철이 주조색이고 밝은 판은
  국소적으로만 배치되어 다리 관절과 외장을 구분합니다.
- 목·허리·팔꿈치·무릎·손·발의 연결부는 장갑보다 어둡고 반사가
  제한된 기계 재질입니다.
- 화염방사기 본체와 총구는 짙은 건메탈이며 표면에 제한된 긁힘과
  열 사용 흔적이 있습니다.
- 후방 탱크는 반복 홈이 없는 매끄러운 마모 강철이고, 호스는 검은
  고무 또는 어두운 피복 재질입니다. 탱크 상부의 작은 피팅에는
  제한된 황동·열변색 계열이 보입니다.
- 흉부에는 청색 표시와 제한된 주황 상태 표시가 있습니다.

## 교체 FBX에 적용한 방식

- 기준 모델은 머티리얼 슬롯이 없는 단일 스킨 메시입니다.
- 기존 `114`개 연결 표면과 본 가중치로 장갑, 관절, 화염방사기,
  탱크, 피팅과 호스를 분류했습니다. 머리는 높이 임계값을 사용하지
  않고 토폴로지 렌더에서 확정한 기존 폴리곤 `126`개를 두건으로,
  나머지 기존 금속 안면 표면을 얼굴로 고정했습니다.
- 연결 표면 `97`의 `18`면을 삭제한 검토 샘플의 `4,330`면을
  `15`개 재질군에 배정했습니다. 프로젝트 원본 FBX는 수정하지
  않았습니다.
- 두건과 얼굴은 알베도·메탈릭·러프니스·노멀을 공유하지 않습니다.
  두건은 낮은 금속성과 높은 거칠기, 얼굴은 높은 금속성과 평탄한
  노멀을 사용합니다.
- 얼굴 알베도에 남아 있던 7픽셀 간격의 가로선을 제거했습니다.
  얼굴 러프니스와 메탈릭도 반복 파형이나 무작위 입자 없이
  균일하게 만들고 넓은 명도 변화만 남겼습니다.
- 청색 광학부는 두건 바로 아래의 좌우 두 구역으로 나누고 중앙
  금속 간격을 유지했습니다. 얼굴 중앙·하단에는 발광 픽셀이 없으며
  입처럼 이어지는 수평선도 없습니다.
- 기존 눈은 얼굴 전체의 X/Y 평면 한 장에 함께 그려져 3/4에서
  가까운 눈이 늘어나고 먼 눈이 눌렸습니다. 기존 얼굴 `208`면의
  정적 좌표와 렌더 프레임 평가 좌표·법선·UV·인접 관계를
  `EYE_SURFACE_ANALYSIS.json`에 기록하고, 좌우 상단 안면판에 각각
  맞춘 접선축으로 두 눈을 독립 배치했습니다.
- 광학 텍스처는 하나의 렌즈 원본만 담고 셰이더가 좌우 표면에
  별도로 배치합니다. 얼굴 전체의 공통 평면 사각 투영은 사용하지
  않으며 중앙 금속·관자놀이·두건·얼굴 하단을 침범하지 않습니다.
- 기준 이미지의 화난 인상은 양쪽 눈의 중앙 쪽 끝이 낮고 바깥쪽
  눈꼬리가 높은 각도에서 나옵니다. 기존 좌우 접선 평면 안에서
  화면 왼쪽 눈은 `-16°`, 오른쪽 눈은 `-14°` 회전해 표면 부착을
  유지하면서 안쪽 끝을 낮췄습니다. 렌즈 텍스처의 색·형상·발광
  값은 변경하지 않았습니다.
- 이마 문양의 전신 `Generated` 좌표 투영도 제거한 상태를 유지하고
  기존 머리 로컬 표면 범위에 고정했습니다. 화염 문양은 임의
  아이콘을 만들지 않고 기준 이미지의 실제 문양 크롭을 사용했습니다.
- 금속 장갑은 저주파 색 변화·짧은 긁힘·미세 수평 브러시드 결과
  낮은 강도의 표면 노멀을 사용합니다. UV 조각마다 늘어나 표면이
  아래로 흐르는 것처럼 보이던 굵은 격자·대각선·볼트 무늬는
  제거했습니다.
- 원본 몸통 범위 `442`면은 실제로 분리된 `7`개 연결 표면
  (`1`, `27`, `61`, `63`, `84`, `96`, `97`)으로 구성되어 있습니다.
  검토 샘플에서는 `97`만 삭제하고 남은 `424`면·`6`개 연결 표면을
  갑주 재질 경계로 사용했습니다.
- 가장 큰 외장 표면과 측면 외장은 청회색 강철, 상부 중앙의 작은
  표면은 주변 외장과 같은 청회색 강철, 큰 중앙 하부와 골반 표면은
  중간 명도의 강철, 좁은 측면 연결 표면은 짙은 내부 기계부로
  배정했습니다.
- 상단의 작은 연결 표면 `97`은 위치상 주 중심 갑주 `63`보다 위에
  따로 놓인 독립 판이므로 검토 샘플에서 정점 `11`, 에지 `27`,
  면 `18`, 루프 `54`를 실제 삭제했습니다. 위치 이동이나 재질
  통합으로 숨기지 않았습니다.
- 법선 인접 각도 `32°`로 같은 몸통을 나누면 `122`개 조각이 되어
  삼각 파편과 얼룩이 생기므로 법선 클러스터 방식은 사용하지
  않았습니다.
- 이전 몸통 색상·발광·금속성·거칠기 투영 오버레이는 셰이더에서
  완전히 분리했습니다. 몸통에는 연결 표면별 전용 알베도·금속성·
  거칠기·낮은 강도의 미세 노멀만 사용하며, 임의 패널 선·상태 표시·
  복부 모듈 그림은 추가하지 않았습니다.
- 이번 수정에서 팔과 다리의 재질 배정과 텍스처는 변경하지
  않았습니다.
- 중앙 하단 연결 표면 `63·84`의 재질 배정도 변경하지 않았습니다.
- 탱크는 넓은 반사대와 미세 요철만 사용하고 반복 세로 립이나 밴드
  무늬를 만들지 않았습니다.
- 화염방사기 총구는 짙은 건메탈로 유지하고, 황동·열변색은 작은
  탱크 피팅에만 배정했습니다.

## 색과 표면 기준

- 두건: 짙은 남색, 비금속, 높은 거칠기, 낮은 직조·주름 노멀.
- 얼굴: 중암도 회색 건메탈, 높은 금속성, 낮은 표면 무늬, 청색
  광학부만 제한적으로 발광. 노멀·높이·거칠기 반복 무늬 없음.
- 흉부: 밝은 중앙 강철 쉘, 청회색 외장, 짙은 적층 복부 모듈.
- 허벅지·정강이: 어두운 청회색 강철을 기본으로 한 국소 밝은 판,
  중간 이상의 거칠기와 제한된 마모.
- 어깨·팔: 저채도 청회색 금속, 흉부보다 어둡고 반사는 제한적.
- 정강이·관절·손·발: 어두운 강철과 검은 기계부, 높은 거칠기.
- 무기: 짙은 건메탈, 중간 금속성, 제한된 긁힘.
- 탱크: 중성 회색 마모 강철, 넓고 매끄러운 반사.
- 호스: 검은 비금속 고무, 높은 거칠기.
- 상태 표시: 제한된 청색과 주황색만 사용.

## 한계와 추론

- 기준 이미지는 정면 한 장뿐입니다. 후면은 정면에서 확인된 재질군을
  단순 연장했으며 새 문양·부품·기계 구조를 추측하지 않았습니다.
- 교체 FBX는 기준 이미지보다 판금과 손가락 세부가 단순합니다.
  승인된 연결 표면 `97` 삭제 외에는 이 차이를 새 메시나 가짜
  실루엣으로 보완하지 않았습니다.
- 기준 이미지의 화염 분사는 VFX이므로 이번 샘플에서 생성하지
  않았습니다.
