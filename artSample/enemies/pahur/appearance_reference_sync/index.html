현재 모델 적용 기준

원본 파후르 FBX는 머티리얼 슬롯이 없는 단일 스킨 메시입니다. 기존 UV, 연결 메시 섬, 폴리곤 중심, 본 가중치만 기준으로 재질 영역을 나눴으며 정점·면·UV·본·가중치·내장 이동 애니메이션은 수정하지 않았습니다.

  • 검토용 원본 파일: blender/Pahur_Appearance_ReferenceSync.blend
  • 구조 보존 검토용 FBX: exports/Pahur_Appearance_ReferenceSync.fbx
  • 범용 시각 검토용 GLB: exports/Pahur_Appearance_ReferenceSync.glb
  • 후드와 안면: 짙은 남색 천, 주황 화염 표식, 푸른 광학부.
  • 몸체와 다리: 청회색 마모 장갑, 짙은 관절·발·손, 제한된 금속 반사.
  • 총신과 장비: 짙은 건메탈, 총구 끝 열변색, 검은 호스, 후방 마모 연료통.
  • Unity 적용 승인 후에는 원본 FBX 임포트 설정과 리그를 유지한 채 Pahur 전용 머티리얼·텍스처를 만들고, Approved Pahur Enemy Placement 아래 10개 인스턴스의 동일 Renderer에 연결하는 방식이 기준입니다.

현재 모델 한계와 추론 범위

  • 기준 이미지는 정밀한 판금 장갑과 안드로이드형 손·발을 가지지만 현재 FBX는 근육형 저폴리 실루엣입니다. 메시를 건드리지 않는 이번 범위에서는 이 형태 차이를 해소하지 않았습니다.
  • 기준 이미지의 화염 분사는 VFX이며 이번 색·머티리얼·텍스처 샘플에 새로 생성하지 않았습니다.
  • 후면 기준 이미지가 없으므로 후면은 새 문양이나 기계 부품을 만들지 않고 정면에서 확인된 청회색 장갑·짙은 장비·마모 연료통 재질만 연장했습니다.
  • GLB는 휴대용 시각 검토본입니다. 구조 보존 기준은 Blend와 FBX이며 상세 결과는 GEOMETRY_PRESERVATION.json, EXPORT_INSPECTION.json에 기록했습니다.
