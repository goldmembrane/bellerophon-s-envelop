교체 모델 적용 기준

교체 파후르 원본 FBX는 머티리얼 슬롯이 없는 단일 스킨 메시 char1입니다. 검토 샘플은 원본의 114개 연결 표면 중 승인된 97만 삭제하고, 나머지 연결 표면의 정점 좌표·UV·본 가중치와 내장 이동 애니메이션을 유지했습니다.

  • 검토용 원본 파일: blender/Pahur_Appearance_ReferenceSync.blend
  • 승인된 판 삭제 범위 검토용 FBX: exports/Pahur_Appearance_ReferenceSync.fbx
  • 범용 시각 검토용 GLB: exports/Pahur_Appearance_ReferenceSync.glb
  • 두건과 안면: 높이 임계값 대신 토폴로지에서 확정한 기존 두건 폴리곤 126개를 짙은 남색 비금속 천으로 고정하고 얼굴은 별도의 매끄러운 중암도 건메탈로 분리했습니다.
  • 얼굴 광학부: 기존 얼굴 208면의 정적 좌표와 렌더 프레임 평가 좌표·법선·UV·인접 관계를 분석했습니다. 좌우 상단 안면판에 각각 맞춘 접선축으로 두 눈을 독립 배치하고, 접선 평면 안에서 화면 왼쪽 -16°·오른쪽 -14°를 적용해 두 눈의 중앙 쪽 끝을 낮췄습니다.
  • 이마 문양: 임의 아이콘을 그리지 않고 기준 이미지의 실제 화염 문양 크롭을 기존 두건 정면 표면에 적용했습니다.
  • 몸통: 원본 몸통 442면 중 독립 판 97의 18면을 실제 삭제했습니다. 남은 424면의 큰 중앙 표면 63과 골반 표면 84는 중간 명도 강철, 외장은 청회색 강철, 좁은 측면 연결부는 짙은 내부 기계 재질로 구성했습니다.
  • 중앙 상단 판: 재질로 숨기거나 다른 위치로 옮기지 않고 독립 연결 표면 97의 정점·에지·면을 검토 샘플에서 제거했습니다.
  • 팔과 다리: 이번 작업에서 머티리얼 배정과 텍스처를 변경하지 않았습니다.
  • 총신과 장비: 화염방사기는 짙은 건메탈, 후방 탱크는 넓고 매끄러운 마모 강철, 연결 호스는 거친 검은 고무, 작은 탱크 피팅만 제한된 황동·열변색 계열로 분리했습니다.
  • 표면 정보: 새 모델의 기존 판금 형상을 우선하고, 텍스처에는 저주파 색 변화·짧은 긁힘·미세 수평 금속결, 재질별 메탈릭·러프니스와 낮은 강도의 노멀만 사용했습니다. 굵은 격자·대각선·볼트 무늬와 전신 패널 범프는 제거했습니다.
  • 기계 구조 표면 분리: 몸통 2D 색상·발광·금속성·거칠기 오버레이를 셰이더에서 제거했습니다. 법선 각도 기준으로 나눈 122개 조각도 삼각 얼룩을 만들기 때문에 사용하지 않고, 실제 연결 표면별 알베도·금속성·거칠기·미세 노멀만 사용했습니다.
  • 얼굴 표면: 알베도의 반복 가로선과 러프니스 파형을 제거했습니다. 입·세로 환기구·추가 패널·코·턱 문양을 생성하지 않았으며 얼굴 노멀과 높이 맵은 평탄하게 유지했습니다.
  • 메시 변경 범위: 승인된 표면 97만 삭제해 검토 샘플은 정점 2,434개·면 4,330개입니다. 나머지 정점 좌표·가중치·에지·면·UV 해시는 삭제 전후 일치하며 새 메시 생성이나 다른 표면 이동·변형은 하지 않았습니다.
  • Unity 적용 승인 후에는 원본 FBX 임포트 설정과 리그를 유지한 채 Pahur 전용 머티리얼·텍스처를 만들고, Approved Pahur Enemy Placement 아래 10개 인스턴스의 동일 Renderer에 연결하는 방식이 기준입니다.

교체 모델 한계와 추론 범위

  • 교체 FBX는 기준 이미지의 주요 부품을 갖고 있지만 판금 세부와 손가락 구조는 더 단순합니다. 승인된 상단 판 삭제 외의 형태 차이를 텍스처로 가장하거나 새 부품으로 보완하지 않았습니다.
  • 두건·얼굴·탱크·화염방사기의 실제 외곽선과 부품 수는 교체 FBX 원형을 그대로 유지했습니다.
  • 기준 이미지의 화염 분사는 VFX이며 이번 색·머티리얼·텍스처 샘플에 새로 생성하지 않았습니다.
  • 후면 기준 이미지가 없으므로 후면은 새 문양이나 기계 부품을 만들지 않고 정면에서 확인된 청회색 장갑·짙은 장비·매끄러운 탱크 재질만 연장했습니다.
  • GLB는 휴대용 시각 검토본입니다. 승인된 삭제 범위와 나머지 구조 보존 기준은 Blend와 FBX이며 상세 결과는 GEOMETRY_PRESERVATION.json, EXPORT_INSPECTION.json에 기록했습니다.
