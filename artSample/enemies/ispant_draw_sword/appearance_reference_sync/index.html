이슈판트 장검 적용 기준

  • 검토용 Blender 원본: ../Ispant_DrawSword_ArtSample.blend
  • 범용 3D 검토 파일: ../Ispant_DrawSword_ArtSample.glb
  • FBX 검토 파일: ../Ispant_DrawSword_ArtSample.fbx
  • 전체 길이: 1.0715m
  • 칼날: 길이 0.82m, 뿌리 폭 0.068m, 두께 0.012m의 좁고 곧은 테이퍼형 칼날입니다.
  • 가드: 전체 폭 0.19m이며 중앙 칼라와 좌우 대칭의 짧은 곡선형 금속 가드로 구성했습니다.
  • 손잡이: 길이 0.17m, 지름 0.052m의 짙은 갈색 가죽 몸체에 반복 감기 표현을 적용했습니다.
  • 폼멜: 길이 0.055m의 마모된 은회색 금속으로 손잡이 끝을 닫았습니다.
  • 칼날·가드·폼멜은 절차형 마모 강철 PBR, 손잡이는 짙은 갈색 가죽 PBR, 가장자리 세부에는 어두운 금속 재질을 사용했습니다.
  • 장검은 Ispant_Reference_LongSword 단일 메시이며 손잡이와 칼날이 분리되지 않습니다.
  • 새 장검은 mixamorig:RightHand 본의 직접 자식이며 기존 발검 장검 손잡이 중심과의 정렬 오차는 0m입니다.
  • 오른손 본 원점에서 손잡이 중심까지의 거리는 0.0557747075m입니다.
  • 사용자 승인과 적용 지시에 따라 Unity의 이슈판트 12개 슬롯에 적용했습니다.

메시 변경과 구조 보존

  • 새 장검은 2,080정점·4,092삼각형의 단일 메시입니다.
  • 전체 메시 치수는 0.198372m × 0.076m × 1.0715m입니다.
  • 발검 몸체의 38개 머티리얼 슬롯은 승인된 정적 이슈판트 샘플의 동일 이름 머티리얼 객체와 동기화했습니다.
  • 본체 UV 이름은 승인 외형의 uv, IspantMechanicalUV, IspantHelmetFaceUV로 맞췄습니다.
  • 몸체·초승달·눈·머스켓과 Mixamo 액션 1~46프레임은 현재 발검 개체 기준을 유지했습니다.
  • Unity 적용본에서 기존 Ispant_DrawSword_RigidSword와 Ispant_DrawSword_RigidSheath를 제거하고 승인 장검으로 교체했습니다.
  • BLEND·FBX·GLB를 각각 재가져오기해 장검 메시 1개, 재질 3개, 4,092삼각형과 오른손 본 부모 연결을 확인했습니다.
  • 원본 Unity 발검 FBX의 SHA-256 B9DEB78C6BECA61C81EE5ECD86C4763E56186B8925EED29720B4B62ED482CE42는 변경되지 않았습니다.

장검 모델 한계와 추론 범위

  • 기준 이미지에서 직접 확인되는 정면 윤곽, 칼날 비례, 금속 마모와 짙은 갈색 손잡이 계열을 우선했습니다.
  • 기준 이미지에서 보이지 않는 후면 깊이는 정면 윤곽의 대칭 두께만 사용했고 별도 장식이나 기계 부품을 추가하지 않았습니다.
  • 정적 렌더는 Mixamo 액션 1프레임을 기준으로 하며, 3D 파일에는 1~46프레임 액션이 보존됩니다.
  • GLB는 범용 시각 검토용이며 구조 보존 판정은 Blender 원본과 FBX·GLB 재가져오기 기록을 함께 기준으로 합니다.
  • Unity 적용본은 10개 정적 슬롯과 이동 슬롯의 기존 장착 위치를 유지하며 발검 슬롯만 오른손을 직접 추종합니다.
