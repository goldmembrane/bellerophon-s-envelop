# 칸타빌레 텍스처 분석

## 기준 이미지 분석

- 날개 내부는 밝은 하늘색과 청록색이 넓게 퍼지고, 외곽으로 갈수록 진한 파랑과 검은색 테두리가 강해집니다.
- 날개 외곽에는 작은 흰 반점이 반복적으로 배치되어 있습니다.
- 날개에는 중심부에서 바깥쪽으로 뻗는 짙은 파랑 잎맥형 선이 보입니다.
- 몸체는 갈색 나방형 털 질감이며, 머리와 복부는 밝은 갈색과 어두운 갈색이 섞입니다.
- 눈은 검정에 가까운 어두운 반사 질감입니다.
- 다리와 끝단은 몸체보다 어둡고 일부 끝단은 푸른 회색으로 보입니다.

## 샘플 반영

- `cantabile_wing_blue_black_spots_albedo.png`: 날개 내부 청록색, 검은 외곽, 흰 반점, 짙은 잎맥을 절차적으로 제작했습니다.
- `cantabile_body_brown_fur_albedo.png`: 갈색 털 결을 줄무늬 밝기 변화로 제작했습니다.
- `cantabile_eye_limb_dark_gloss_albedo.png`: 눈과 다리 끝단용 어두운 반사 계열 색을 분리했습니다.
- `cantabile_current_model_material_atlas_albedo.png`: 현재 단일 메시 GLB에 적용하기 위한 검토용 알베도 아틀라스입니다.
- `cantabile_fur_wing_vein_bump.png`: Unity 적용 단계에서 노멀/범프 계열로 전환할 수 있는 질감 기준 이미지입니다.

## 남은 한계

- 현재 모델은 저폴리 메시라 기준 이미지의 부드러운 붓결과 작은 반점은 면 단위로 단순화되어 보입니다.
- 원본 모델에 UV가 없어서 샘플용 UV를 생성했습니다. Unity 적용 단계에서는 이 UV 생성 방식을 유지할지, 별도 UV 언랩을 만들지 별도 승인이 필요합니다.
