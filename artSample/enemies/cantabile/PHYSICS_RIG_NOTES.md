# 칸타빌레 Unity 적용 메모

- 이 샘플은 색상/텍스처 검토용이며 애니메이션 샘플이 아닙니다.
- Unity 적용 단계에서 기존 칸타빌레 5개 검토 개체 구조를 유지하려면 승인된 루트와 하위 모델 범위를 다시 지정해야 합니다.
- 현재 샘플은 `cantabille.glb` 메시 기준입니다. 적용 시 `Player`, `Hud`, `EventSystem`, 조명, 카메라, graybox, 다른 적대 개체는 대상에 포함하지 않아야 합니다.
- 칸타빌레는 날아다니는 중형 개체이므로 실제 런타임 이동은 별도 승인 범위에서 `Rigidbody + Collider` 기준으로 검토해야 합니다.
- 이 색상 샘플 승인만으로 Unity 씬, 프리팹, 런타임 에셋을 변경하지 않습니다.
