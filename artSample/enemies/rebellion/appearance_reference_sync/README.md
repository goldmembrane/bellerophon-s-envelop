# 리벨리온 외형 동기화 아트 샘플

## 목표

`image/rébellion(리벨리온).png`의 외형을 현재 Unity에 배치된
`Assets/_Project/Art/Enemies/Rebellion/Models/Rebellion.glb`에 맞춰 검토하기 위한
파생 아트 샘플입니다.

현재 Unity GLB 원본 파일과 29본 리그는 변경하지 않았습니다. 기준 이미지에서
검은 패널이 원반 표면에 붙은 부품이 아니라 원반 내부로 들어간 구조인 점을
반영하기 위해 파생 샘플의 정면 패널 영역만 절삭했습니다.

## 정면 패널 수납부

- 원반 전면에 폭 `0.96m`, 높이 `0.41m`, 깊이 `0.40m`의 절삭 공간을 만들었습니다.
- 검은 뒷판은 원반 전면 기준 약 `0.201m` 뒤에 배치했습니다.
- 검은 뒷판 높이는 최종 `0.16m`로 줄였고 중심을 `Z=1.50`으로
  조정했습니다. 최종 세로 범위는 `Z=1.42~1.58`이며 원반 옆면보다
  확실히 낮아 위·아래에 여유가 남습니다.
- 총구 허브 반지름은 `0.115m → 0.075m`, 개별 총열 구경은
  `0.032m → 0.020m`, 총열 배열 반지름은 `0.050m → 0.032m`로
  축소했습니다.
- 수납부의 위·아래·좌·우 벽은 별도 외부 프레임이 아니라 원반 메시를 절삭하며
  생긴 원반 자체의 내부 면입니다.
- 별도로 덧붙였던 금속 테두리 4개는 제거했습니다.
- 정확한 측면에서는 검은 판과 수납부가 원반 외곽선 밖으로 나오지 않으며,
  다연장 총구만 전방으로 돌출됩니다.

## 기준 이미지에서 반영한 요소

- 중간 명도의 낡은 회색 원판과 금속 표면
- 짙은 철재 다리 프레임과 관절
- 밝은 유압 실린더와 금속 연결부
- 원반 내부로 파고든 검은 정면 패널
- 패널에서 앞으로 나온 7구 다연장 총구
- 패널 왼쪽의 작은 붉은 스캔 센서
- 금속 얼룩, 긁힘, 산화와 미세 요철
