# 리벨리온 전방 연속 사격 VFX 승인 샘플

## 상태

- `PENDING_USER_REVIEW`
- Unity 런타임 적용 승인 전
- 기본 검토 페이지: `index.html`

`index.html`에서 기준 이미지와 VFX 적용 샘플 비교, 전체 요약 SVG, 발사 사양,
Unity 적용 범위와 제외 항목을 한 번에 확인할 수 있습니다.

## 사용자 확정 사항

- 공격 모드 전환 모션의 기립 정점 자세를 유지합니다.
- 총구 묶음은 발사 뒤 오른쪽으로 `360÷7도`, 즉 `51.428571도`씩 회전합니다.
- 발사 간격은 `0.2초`입니다.
- 전체 발사 시간은 `5초`이며 총 `25회` 발사합니다.
- 위쪽 총열 끝에서 짧은 주황·노란 총구 화염이 나옵니다.
- 전체 모션은 반복 재생합니다.

## VFX 샘플 제안값

- 발사 앵커: 현재 위쪽 위치에 도달한 총열의 끝
- 화염 표시 시간: 발사 시점부터 `0.08초`
- 회전 시간: 화염이 사라진 뒤 다음 발사 시점까지 `0.12초`
- 화염 길이: 약 `0.14m`
- 화염 최대 폭: 약 `0.07m`
- 색 구성: 중심부 백황색, 중간 노란색, 외곽 주황색
- 표현 방식: 짧은 발광 핵과 방향성 화염 실루엣
- 포함하지 않는 표현: 연기, 탄피, 투사체, 궤적, 반동

화염 크기는 총구 형상에 맞춘 승인 전 제안값입니다. 사용자가 이 샘플을 승인하면
Unity의 `Rebellion_04_Forward_Burst_Fire` 슬롯에서 동일한 앵커, 색상, 크기와
표시 시간을 재현합니다.

## 0.2초 단위 동작

1. `0.00~0.08초`: 현재 위쪽 총열에서 화염을 표시합니다.
2. `0.08~0.20초`: 총구 묶음을 정면 기준 시계 방향으로 `51.428571도`
   회전합니다.
3. 다음 `0.2초` 구간에서 같은 순서를 반복합니다.
4. `0.0~4.8초`에 총 25번 발사하고 `5.0초`에서 루프합니다.

## Unity 적용 예정 범위

- 대상 씬: `Assets/_Project/Scenes/CargoRunMvp.unity`
- 대상 슬롯: `Rebellion_04_Forward_Burst_Fire`
- 기립 자세 출처:
  `Rebellion_02_Attack_Mode_Transition.anim`의 `1.2초`
- 회전 대상 리그: 총구 허브와 7개 총열이 연결된 `Bone_007`
- VFX 대상: 위쪽 발사 위치를 추적하는 총열 끝의 전용 총구 화염 오브젝트
- 유지 대상: 리벨리온 배치 위치, 다리와 원반 자세, 기존 다른 애니메이션
- 이번 샘플에는 투사체·피해·AI·전투 로직을 포함하지 않습니다.
