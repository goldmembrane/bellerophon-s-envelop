# 참조 이미지 표면 분석

기준 이미지는 짙은 회색 건메탈 몸체, 더 밝은 강철 외장, 검은 기관총과 내부 기계부, 제한적인 구리색 연결부, 청색 광학부로 구분됩니다.

재질 입력은 `image/révolution-attack.png`에서 선택한 작은 표면 영역을 원본 픽셀 크기 그대로 직접 잘라 사용했습니다. 크롭은 리사이즈·재도색·필터링하지 않았고 별도의 노멀·러프니스·메탈릭·높이·발광 텍스처 파일을 추정 생성하지 않았습니다. 정확한 좌표와 파일 해시는 `CROP_PROVENANCE.json`에 있습니다.

몸통의 큰 외피는 `reference_body_panel_direct_crop.png` 65%와 같은 참조 이미지에서 직접 자른 `reference_body_wear_direct_crop.png` 35%를 셰이더에서 혼합해 참조 몸통의 중간 건메탈 명도와 마모 변화를 유지합니다. 이전의 곱셈 혼합은 몸통을 참조보다 과도하게 어둡게 만들었기 때문에 사용하지 않습니다. 마모 크롭의 실제 명도는 러프니스와 미세 범프 입력에도 연결되며 새로운 픽셀 파일을 만들지 않습니다. 삽입 패널 114면에도 흰색처럼 보이던 밝은 강철 크롭 대신 참조 몸통의 중간톤 `reference_body_wear_direct_crop.png`를 별도 머티리얼로 사용합니다.

몸통 재질 경계는 임의의 본 가중치 분할이 아니라 원본 FBX의 연결 메시 컴포넌트 경계를 사용합니다. 외피 컴포넌트 0의 553면과 삽입 컴포넌트 1의 114면에 각각 한 재질만 지정되며, 상세 내역은 `TORSO_MATERIAL_ASSIGNMENT.json`에 있습니다.

몸통과 팔의 이음부는 진단 마스크로 확인한 원본 연결 컴포넌트만 사용합니다. 큰 관절 외피 `14/16`과 상부 연결편 `25/27`의 136면에는 몸통과 연결되는 낡은 건메탈 크롭을, 내부 링 `40/55`와 바깥 회전축 `2/3`의 174면에는 참조 이미지의 어두운 기계 금속 크롭을 적용합니다. 추가 마스크에서 확인한 관절 바깥 연결봉 97면은 기존 밝은 강철 재질 경계만 그대로 사용해 어두운 기계 금속으로 바꿉니다. 좌우 관절 310면과 연결봉 97면, 총 407면 중 밝은 기본 강철 또는 미도색 재질은 0면이며, 상세 내역은 `SHOULDER_JOINT_MATERIAL_ASSIGNMENT.json`에 있습니다.

좌우 팔이 동일한 원본 픽셀 분포를 읽도록 텍스처 X 좌표는 모델 중앙 기준 `abs(2 * Generated.X - 1)`로 미러링합니다. 원본 UV 데이터는 수정하지 않습니다.

참조 이미지에 없는 후면에는 새 무늬나 부품을 추측해 만들지 않고, 참조 전면에서 직접 확인한 동일 건메탈 팔레트를 기존 몸통 표면 전체에 이어 적용했습니다. 몸통 전·측·후면 667면 중 미도색 또는 중립 재질은 0면입니다. 참조의 상세 부품을 재현하기 위한 메시 변형·추가 생성도 하지 않았습니다.
