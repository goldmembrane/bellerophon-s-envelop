- 기준 모델: `Assets/_Project/Art/Enemies/Revolution/Models/Revolution.fbx`
- 기준 이미지: `image/révolution-attack.png`

- 변경 범위: 기존 폴리곤의 재질 슬롯과 참조 이미지 직접 크롭 연결
- 몸통 외피: 연결 컴포넌트 0의 553면 전체에 건메탈 기본 크롭과 마모 크롭을 65:35로 혼합하고, 마모 크롭의 명도에서 러프니스와 미세 범프를 구동
- 몸통 삽입부: 연결 컴포넌트 1의 114면 전체에 참조 몸통의 중간톤 마모 건메탈 직접 크롭 적용
- 몸통 전체: 전·측·후면 667면 모두 참조 이미지 직접 크롭 재질 적용, 미도색 또는 중립 재질 0면
- 어깨 이음부: 큰 관절 외피와 상부 연결편 136면은 낡은 건메탈, 내부 링과 회전축 174면은 어두운 기계 금속으로 적용
- 어깨 연결 프레임: 관절에서 팔 본체로 이어지는 가느다란 연결봉 97면을 어두운 기계 금속으로 적용

- 팔 색 배열: 정면 화면 오른쪽 팔을 원본으로 삼아 확인된 대응 부품의 실제 폴리곤 재질을 화면 왼쪽 팔에 복사
- 미변경 범위: 메시 좌표, 토폴로지, UV 데이터, 본, 포즈, 부품 구성

오른쪽 팔 기준 복사 기록은 `SCREEN_RIGHT_ARM_COPY.json`, 최종 대칭 계약은 `ARM_COLOR_SYMMETRY.json`에 기록합니다.
