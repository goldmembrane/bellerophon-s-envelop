아첼레란도 더듬이 연결 및 채색 샘플

기준 이미지는 accelerando(아첼레란도).png, accelerando-beside.png입니다. 현재 샘플은 원본 enemies model/accelerando.glb를 직접 덮어쓰지 않고, 막대형 연결부를 사슬로 치환해 더듬이 끝과 철퇴가 이어지도록 만든 검토용 GLB/BLEND와 렌더입니다. 사용자 승인 전까지 Unity 씬과 런타임 에셋에는 연결하지 않습니다.

현재 모델 적용 기준

샘플은 원본 저폴리 메시의 형태를 유지하면서, 보이는 단절을 보강하는 별도 연결 메시와 머티리얼을 추가한 상태입니다. Unity 적용 단계에서는 이 샘플을 승인 기준으로 삼고, 원본 모델 교체 또는 런타임 에셋 반영은 별도 승인 후 진행해야 합니다.

  • 검토용 3D 파일: exports/accelerando_connected_colored_sample.glb
  • 검토용 Blender 파일: exports/accelerando_connected_colored_sample.blend
  • 막대 치환: 원본 메시의 막대형 연결부를 제거하고 사슬 링크로 대체했습니다.
  • 사슬 시작점: 기존 더듬이 끝 캡 위치에서 첫 링크가 시작되도록 배치했습니다.
  • 사슬 끝점: 철퇴 상단에 마지막 링크와 연결 링이 닿도록 배치했습니다.
  • 형태 기준: 기준 이미지처럼 금속 막대가 아니라 녹슨 체인이 철퇴를 매다는 구조로 정리했습니다.
  • 색상: 젖은 회갈색 몸통, 어두운 낡은 껍질, 녹슨 어두운 금속으로 구분했습니다.
  • 전시용 바닥판: 원본 GLB에 있던 판 형태 하단부는 샘플에서 제거했습니다.

적용하지 않은 항목

  • enemies model/accelerando.glb 원본은 덮어쓰지 않았습니다.
  • Unity Assets/, 씬, 프리팹, 런타임 배치에는 연결하지 않았습니다.
  • 애니메이션, 충돌, 리깅, 게임플레이 설정은 변경하지 않았습니다.
  • 표면 질감은 현재 절차적 머티리얼 수준이며, 기준 이미지의 고해상도 점액/마모 디테일과 완전히 동일하지는 않습니다.
