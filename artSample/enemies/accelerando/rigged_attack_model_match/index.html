Accelerando 리깅 공격 모델 일치 샘플

사용자 승인 대기 · Unity 런타임 미적용

원본 accelerando.glb의 18본 리그를 유지하면서 현재 Unity의 몸체·갑각·녹슨 금속 색과 좌우 12링 사슬·분리 철퇴 구성을 맞췄습니다. 철퇴 아래의 옛 막대 지지물과 보이는 하단 소켓 링은 제거했습니다. 리그 이미지에서 주황색은 공격 시 직접 제어할 더듬이 본, 파란색은 직접 제어에서 제외한 본입니다.

포즈 렌더는 기능 미리보기이며 AnimationClip과 가속 제어는 포함하지 않았습니다. 승인 후 별도 Unity 적용 승인을 받아 Accelerando_03_Antenna_Strike/Accelerando_Model만 교체할 예정입니다.
