# 돌로레 사망 초상 화면 효과 샘플

## 상태

- 사용자가 2026-07-23에 승인한 샘플입니다.
- Unity 씬의 `Approved Dolore Enemy Placement/Dolore_07_Death`에 Animator, 애니메이션 클립, 컨트롤러, 초상 신호 머티리얼과 셰이더를 적용했습니다.
- 원본 Dolore 렌더러와 FBX는 변경하지 않았습니다. 액자 내부 중앙 화면용 신호 면만 별도 자산으로 추가했습니다.
- 중앙 신호 면은 정적 비교 개체의 기준 자세에서 생성해 초상 지배 본인 `head`의 자식으로 배치했습니다. 액자 틀과 몸통까지 전환시키던 전체 스킨 복제 오버레이는 제거했으며, 신호 마스크의 크기와 중심을 낙하 후 초상 개구부에 맞췄습니다. 동일 자세·고정 카메라의 정면·사선 최종 캡처에서 액자 내부 경계 일치, 액자 틀·몸체 무침범, 백색 노이즈와 검정 화면을 확인했습니다.
- 이 샘플은 사망 모션 중 초상 부분에만 적용할 화면 효과와 시간을 승인받기 위한 HTML 미리보기입니다.

## 승인 요청 시퀀스

1. `0.0~0.9초`: 돌로레가 왼쪽으로 쓰러지는 동안 기존 흐릿한 남성 초상을 유지합니다.
2. `0.9~1.9초`: 완전히 쓰러진 직후 초상 부분만 지직거리는 TV 백색 노이즈로 바뀝니다.
3. `1.9~2.9초`: 초상 부분만 완전한 검은색으로 바뀝니다.
4. `2.9초`: 처음 자세와 기존 초상으로 즉시 복귀해 반복합니다.

## 적용 경계

- 변경 대상은 `Dolore_Faded_Portrait`에 대응하는 초상 화면뿐입니다.
- 바깥의 산화 황동 액자, 청록 생체 몸체, 리그와 원본 FBX는 화면 효과의 영향을 받지 않습니다.
- 왼쪽 쓰러짐 리그 애니메이션은 애니메이션 예외 규칙에 따라 이 시각 샘플 승인 후 Unity 적용 단계에서 별도로 구현합니다.
- Unity 런타임 적용은 승인된 별도 묶음 범위에서 진행했습니다.

## 미리보기

- `index.html`을 브라우저에서 엽니다.
- 기본 상태는 `2.9초` 자동 반복입니다.
- `일시정지`, `처음부터`, `정상 초상 고정`, `노이즈 고정`, `검정 고정`, `자동 반복` 버튼으로 각 상태를 확인할 수 있습니다.

## 시간 변수

- `FALL_DURATION_MS = 900`: 왼쪽 쓰러짐과 기존 초상 유지 시간
- `NOISE_DURATION_MS = 1000`: 백색 노이즈 유지 시간
- `BLACK_DURATION_MS = 1000`: 완전한 검은 화면 유지 시간
- `LOOP_DURATION_MS = 2900`: 즉시 복귀 전 전체 반복 시간
