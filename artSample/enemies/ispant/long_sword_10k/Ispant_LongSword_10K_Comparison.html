ISPANT // LONG SWORD EXTRACTION

이슈판트 장검 10K PBR 비교

분할 GLB의 장검 전체를 그대로 추출해 10K 이하로 감량하고, 사용자가 UV 원본으로 지정한 išpant-new.fbx와 제공된 네 PBR 텍스처를 이용해 표면 재질을 복원한 검토 샘플입니다.

형상과 UV 처리

  • 대상은 išpant-segment.glb의 mesh_10이며 검신·가드·손잡이·폼멜 전체를 포함합니다.
  • Decimate 비율 0.212로 감량했고 장검의 단일 연결 요소와 원본 실루엣을 유지했습니다.
  • GLB에는 UV와 이미지 텍스처가 없어서, 사용자 지정 FBX 장검의 29개 UV 섬·242면을 정규화된 표면 대응 방식으로 전사했습니다.
  • UV 범위는 (0.007336, 0.027650)–(0.986122, 0.979067)이며 FBX 재가져오기에서도 정점 분할 없이 9,975정점을 유지했습니다.
  • 기존 장검 242면과 승인 장검 전체 표면을 강체·균일 배율 정합해 배율 12.345491599084를 적용하고 기존 왼쪽 허리 경계 중심과 길이를 맞췄습니다.
  • 승인 장검은 Armature 루트 아래의 별도 메시이며 버텍스 그룹, Armature modifier, 애니메이션은 연결하지 않았습니다.

새 색·무늬·형상을 AI로 생성하지 않았습니다. 제공된 텍스처는 픽셀 가공 없이 복사했고, 형상에는 감량과 원본 UV 표면 전사만 수행했습니다.
