이슈판트 장검 분리 비교

사용자가 지정한 옆구리의 긴 장검을 원본 išpant-new.fbx 메시에서 분리하고, 장검 뒤에 원래 없던 왼쪽 허벅지 면은 오른쪽 다리 원본의 대칭 대응 영역으로 복구한 검토용 샘플입니다.

왼쪽 다리 대칭 복구 완료 · Unity 적용

분리 기준과 보존 범위

  • 최초에 잘못 선택했던 머스켓 일부 17개 UV 섬·215면은 폐기하고, 사용자 재지정 이미지의 오른쪽 허벅지 옆 은색 검 부품을 다시 식별했습니다.
  • 두 번째 19개 UV 섬·99면 결과는 검신만 포함하고 검자루가 빠진 불완전 결과였으므로 폐기했습니다.
  • 세 번째 29개 UV 섬·242면은 하나로 이어지는 장검 표면으로 유지했습니다.
  • 이후 칼자루로 추정해 추가했던 17개 UV 섬·270면은 실제 신체 면으로 확인되어 장검 선택에서 폐기했습니다.
  • 16개 섬·242면은 왼쪽 허리·골반, U530 28면은 왼쪽 전완이며 원본 좌표·UV·웨이트 그대로 본체에 복구했습니다.
  • 장검 뒤에 원본 왼쪽 다리 면이 없음을 확인하고, 오른쪽 다리를 본 대칭축 X=-0.691260815로 반전해 기존 왼쪽 다리와 2.5 이상 떨어진 유일한 연결 성분을 복구 대상으로 고정했습니다.
  • 대칭 복구분은 오른쪽 다리 원본 13정점·12면이며, 오른쪽 본 이름만 대응하는 왼쪽 본으로 치환하고 UV·머티리얼 배정은 그대로 유지했습니다.
  • 장검은 식별된 원본 242면을 그대로 분리했으며 장검 형태 보정, 덮개 면 또는 두께 보강은 하지 않았습니다.
  • 원본의 모든 면 서명은 본체와 장검에 보존됐고 추가 서명은 대칭 복구 12면뿐입니다.
  • 검토용 FBX 재임포트 후 본체 4,895정점·9,798면과 장검 143정점·242면을 다시 확인했습니다.

원본 신체 270면과 왼쪽 다리 대칭 패치 12면을 포함한 본체를 Unity 직접 원본 Ispant_New_Direct_Source.fbx에 적용했습니다. FBX의 기존 GUID와 CargoRunMvp.unity 배치 12개 및 Transform은 바꾸지 않았습니다.
