# 쿠르사 방패 자세 진입 이펙트 시안

## 시각 구성

- 형태: 사용자 제공 이미지처럼 상단이 넓고 좌우 세로 구간이 수직으로 내려오며 하단이 뾰족한 5각형 방패 실루엣
- 본체: 내부가 비어 있지 않은 완전 불투명 푸른색
- 테두리: 밝은 청록색
- 발광: 불투명 본체 바깥쪽에만 퍼지는 푸른색 광원
- 방향: 쿠르사 머리 위에서 정면 카메라를 향하는 2D 형태
- 시안 이미지의 짙은 회색 배경은 발광 확인용이며 실제 Unity 이펙트에는 포함하지 않는다.

## 기준 이미지

- 사용자 제공 원본: `Kursa_ShieldShape_Reference.png`
- 반영 요소: 좁고 긴 전체 비율, 넓은 상단, 수직으로 내려오는 좌우 측면, 중앙으로 모이는 뾰족한 하단
- 반영하지 않는 요소: 원본의 금속 재질, 문양, 갈색·회색 색상과 흰 배경

## Unity 적용 예정 동작

- `Kursa_05_ToShieldStance`에서 왼 무릎을 굽히고 오른발을 뒤로 빼 방패 자세로 진입한다.
- 진입 완료 시 이 2D 방패 이펙트가 머리 위에 나타난다.
- 방패 자세와 이펙트를 2초간 유지한 뒤 시작 자세로 돌아가 진입 모션부터 반복한다.
- 별도 `Kursa_06_ShieldStance` 모션은 만들거나 수정하지 않는다.

## 승인 상태

- 현재 상태: Unity 적용 전 시각 확인 대기
- Unity 씬, 애니메이션, 머티리얼에는 아직 연결하지 않았다.
