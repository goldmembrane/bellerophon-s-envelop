  • 검토용 FBX: exports/Kursa_Appearance_ReferenceSync.fbx

쿠르사 모델 한계와 추론 범위

  • 현재 FBX의 형태는 기준 이미지보다 단순합니다. 기준 이미지의 볼트·세부 패널·케이블·안면 프레임을 새 메시나 가짜 형상으로 보완하지 않았습니다.
  • 방패에 가려진 부위와 기준 이미지에서 보이지 않는 후면은 확인 가능한 색 체계의 연속성만 적용했습니다.
  • 후드·목도리·흉부의 청록 문양과 눈은 기준 이미지의 해당 영역만 분리해 기존 표면에 투영했습니다. 눈은 별도 메시를 추가하지 않고 USER_EYE_TARGET_MAP.json에 기록한 사용자 지정 이미지 영역의 두 표면 적중점에 맞춘 뒤, 중심 위치를 유지한 채 투영 크기만 2배로 확대했습니다. 새로운 기호나 도안을 생성하지 않았고, 분석용 몸체·방패 표면 크롭은 최종 재질에 사용하지 않았습니다.
  • 발광은 눈의 청색 안광만 낮은 세기로 사용하며 VFX는 생성하지 않았습니다.
  • FBX 재가져오기는 원본 수치를 유지합니다. GLB는 4개 초과 본 영향 제한과 머티리얼 프리미티브 분리로 정점·면이 분할되므로, 형상 보존 판정은 Blend와 FBX 및 GEOMETRY_PRESERVATION.json을 기준으로 합니다.
  • Blender 종료 시 사용자 설치 Auto-Rig Pro의 정리 핸들 경고가 발생했으나 생성·저장·FBX 재가져오기 결과에는 오류가 없었습니다.
