# 레지스탕스 리그·Unity 적용 메모

- 이 결과는 원본 형상에 색상·재질만 동기화한 외형 승인용 샘플이며 애니메이션 샘플이 아닙니다.
- 원본 모델 메시 오브젝트는 `char1` 하나이며, 정점 3,004개·엣지 9,055개·면 6,037개를 유지합니다.
- 원본 `Armature` 24본, UV `uv`, 바운드와 형상 서명을 그대로 유지합니다.
- 새 모델 부품, 스킨 웨이트, 피벗, 본 부모, Shape Key, Geometry Nodes 또는 변위는 추가하지 않았습니다.
- Blender 파일의 바닥·카메라·조명은 검토용 스튜디오 요소이며 모델 형상에 포함되지 않습니다.
- 이 샘플 승인만으로 Unity 씬, 기존 14개 배치, 런타임 모델·머티리얼 또는 애니메이션을 변경하지 않습니다.
- 이동·공격·피격·사망·무기 탈취 애니메이션은 별도 사용자 지시에 따릅니다.
