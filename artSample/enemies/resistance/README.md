# 레지스탕스 원본 모델 재질 동기화 샘플

## 상태

- 승인 상태: 사용자 검토 대기
- 기준 이미지: `image/résistance(레지스탕스).png`
- Unity 런타임 적용: 미적용
- 원본 FBX 변경: 없음
- 샘플 형상 변경: 없음

## 검토

- `index.html`에서 기준 이미지와 원본 형상 유지 샘플을 비교합니다.
- Blender 검토 파일은 `exports/resistance_current_model_material_sample.blend`입니다.
- `exports/Resistance_source_geometry_unchanged.fbx`는 원본 FBX와 SHA-256이 같은 보존 복사본입니다.
- 형상 불변 결과는 `geometry/geometry_invariance_report.json`에 있습니다.

## 적용 범위

- 원본 `char1` 메시, `Armature`, 정점·엣지·면·UV·본·실루엣을 변경하지 않았습니다.
- 기존 면의 머티리얼 분류와 표면 셰이더만 사용했습니다.
- 마모된 은백색 외장, 암회색 내부 기계부, 제한된 황동·올리브색 영역을 적용했습니다.
- 청록색 전용 면 배정은 제거했습니다. 검은 프레임과 청록 표시부는
  기준 이미지의 어깨 원형 인셋, 흉갑 아래쪽 바, 복부 중앙 4단 표시,
  전완 슬롯, 허벅지 3단 표시, 정강이 세로 인셋 위치에만 표면
  셰이더 마스크로 배치했습니다.
- 정면 비교 카메라는 기준 이미지와 같은 쪽의 약한 3/4 시점으로 맞췄습니다.
- 거칠기와 미세 범프는 표면 음영만 바꾸며 변위는 사용하지 않습니다.

## 제한

- 고정된 원본 실루엣 때문에 기준 이미지의 장갑 분할 형상을 실제 입체 부품으로 재현하지 않습니다.
- 전완 표시는 원본 팔의 굽은 곡면과 기본 자세 안에서 보이는 범위로 제한됩니다.
- 눈·코·입은 요청에 따라 제작 대상에서 제외했습니다.
- 이 샘플 승인만으로 Unity 씬, 기존 14개 배치, 런타임 머티리얼 또는 애니메이션을 변경하지 않습니다.
