그라베 기준 이미지 재현 아트 샘플

사용자 검토 대기 · Unity 미적용

재현 기준은 image/grave(그라베).png입니다. 기존 enemies model/grave.fbx의 메시와 24본 리그를 유지하면서 정면 실루엣, 비율, 턱시도 선화, 회색 직물 알베도·노멀·거칠기를 적용한 검토 샘플입니다. 사용자 승인 전에는 Unity 씬, 프리팹, 런타임 에셋에 연결하지 않습니다.

기준 이미지와 생성 렌더 비교

정면 재현 카메라

추론 표시: 기준 자료는 정면 이미지 한 장뿐입니다. 측면·후면의 의상 선화는 새로 만들지 않았고, 정면에서 확인되는 회색 직물 표면만 연장했습니다. 아래 준측면과 사선 렌더는 그 추론 범위를 검토하기 위한 시점입니다.

생성 렌더

모델·재질 적용 기준

  • 재현 치수: 폭 0.748327m, 높이 1.598500m, 깊이 0.525680m.
  • 원본 구조 유지: 2,296정점, 4,582폴리곤, 24본, Armature 연결.
  • 전면: Grave_Suit_Front_Mat과 GraveReferenceUV로 턱시도 선화를 투영합니다.
  • 후면·옆면: Grave_Textile_BackSide_Mat으로 회색 직물 표면만 연장합니다.
  • 표면 성질: 비금속, 높은 거칠기, 교차 섬유형 미세 노멀을 사용합니다.
  • 검토용 3D 파일: exports/grave_reference_reproduction.glb.

승인 후 Unity 반영 범위

이 샘플이 승인되더라도 Unity 적용은 별도 작업입니다. 별도 승인을 받은 뒤 CargoRunMvp의 Approved Grave Enemy Placement 아래 7개 슬롯에서 기존 Grave_Model의 보이는 모델과 머티리얼만 교체하는 방식을 우선 검토합니다. 슬롯 위치, Player, 카메라, 다른 씬 루트, 애니메이션·AI·물리·전투 로직은 승인 범위에 포함되지 않으면 유지합니다.
