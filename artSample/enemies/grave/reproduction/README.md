# 그라베 재현 아트 샘플

## 검토 목적

이 폴더는 `image/grave(그라베).png`를 재현 대상으로 삼아, 기존 `enemies model/grave.fbx`의 메시와 24본 리그를 보존하면서 실루엣·비율·턱시도 무늬·회색 직물 표면을 맞춘 승인용 아트 샘플입니다. 아직 Unity 씬, 프리팹, 런타임 에셋에는 적용하지 않았습니다.

가장 먼저 확인할 파일은 `review/grave_reference_comparison.png`입니다. 왼쪽이 기준 이미지, 오른쪽이 같은 1408×768 정면 카메라로 렌더한 아트 샘플입니다.

## 재현 범위

- 기준 이미지의 세로형 둥근 몸통, 긴 팔, 짧은 다리 비율에 맞게 원본 메시의 휴식 형상을 보정했습니다.
- 기준 이미지의 턱시도 앞면을 별도 `GraveReferenceUV`로 투영했습니다. 나비넥타이, 라펠, 조끼, 단추, 주머니와 세로 줄무늬를 포함합니다.
- 회색 직물의 밝기 편차와 교차 섬유 패턴을 알베도에 반영하고, 거칠기와 미세 요철용 텍스처를 별도로 연결했습니다.
- 전면 및 정면에서 보이는 옆면은 `Grave_Suit_Front_Mat`, 보이지 않는 후면은 `Grave_Textile_BackSide_Mat`을 사용합니다.
- 원본 FBX의 2,296정점, 4,582폴리곤, 24본 리그와 Armature 연결을 유지했습니다.

## 추론 및 한계

- 기준 이미지는 정면 한 장뿐이므로 후면의 의상 선화나 별도 구조는 확인할 수 없습니다. 후면은 보이는 회색 직물 재질을 연장한 것으로 명시적으로 추론했습니다.
- 손과 발 각도에는 원본 FBX의 비대칭 휴식 포즈가 남아 있습니다. 기준 이미지에 없는 새 손가락·관절 형상을 창작하지 않고 기존 메시 범위에서 비율과 표면을 재현했습니다.
- 기준 일러스트의 바닥 그림자는 모델 일부가 아니므로 FBX에는 포함하지 않았습니다.

## 검증 결과

- FBX 빈 장면 재임포트: 통과
- 재임포트 치수(X 폭 / Y 높이 / Z 깊이): `0.748327 / 1.598500 / 0.525680m`
- 정면 시각 비교: 실루엣 IoU `0.799839`
- 기준 대비 바운딩 박스 오차: 폭 `2.424%`, 높이 `1.153%`
- 중심 오차: `1.000px`
- 전경 명도 중앙값 차이: `3.0`
- 상세 보고서: `review/fbx_validation.txt`, `review/visual_validation.txt`

## Unity 승인 후 적용 의도

사용자가 이 샘플을 승인한 뒤 별도 Unity 적용 승인을 받으면, 현재 `CargoRunMvp`의 `Approved Grave Enemy Placement` 아래 7개 그라베 슬롯에서 기존 `Grave_Model` 표시 메시와 머티리얼을 이 승인본으로 교체하는 방식을 우선 검토합니다. 슬롯 루트 위치, Player, 카메라, 다른 씬 루트, 애니메이션 상태는 별도 승인 범위에 포함되지 않는 한 변경하지 않습니다.
