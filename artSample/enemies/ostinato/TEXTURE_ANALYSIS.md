# 오스티나토 텍스처·머티리얼 직접 전사 분석

## 제작 목표

- 기준 이미지를 분위기 참고가 아닌 재현 대상으로 사용한다.
- 새 색, 절차 노이즈, 임의 장식선, 반복 관절 띠를 만들지 않는다.
- 정면·측면·후면 기준 이미지의 실제 픽셀에서 색, 명암, 산화 얼룩, 갑각 결, 복안 렌즈, 가위날 반사를 추출한다.
- 현재 `Ostinato.fbx`의 실루엣·메시·UV·리깅은 바꾸지 않고, 추출한 표면 정보만 현재 모델의 대응 시점에 전사한다.

## 기준 이미지 실측 결과

- 갑각 중앙색: `RGB(69, 71, 39)` / `#454727`
- 적갈 조직 중앙색: `RGB(65, 40, 23)` / `#412817`
- 가위날 중앙색: `RGB(83, 88, 80)` / `#535850`
- 시점별 갑각 면적 비율: 정면 `18.42%`, 측면 `20.44%`, 후면 `30.94%`
- 시점별 적갈 조직·산화부 면적 비율: 정면 `66.68%`, 측면 `66.31%`, 후면 `55.75%`
- 수치와 전체 분위기는 생성 시마다 세 기준 이미지에서 다시 추출해 `exports/ostinato_current_model_material_spec.json`에 기록한다.

## 샘플 반영

- `ostinato_olive_rust_chitin_albedo.png`: 정면 흉부의 갑각판, 녹색 안료, 적갈 산화부, 판 경계와 마모를 원화에서 직접 잘라 확대한 표면 패치.
- `ostinato_red_brown_soft_tissue_albedo.png`: 정면 하체의 적갈 관절 조직과 표면 기공을 원화에서 직접 잘라 확대한 패치.
- `ostinato_worn_hook_blade_albedo.png`: 정면 가위날의 은회색 금속, 어두운 내측면과 밝은 날 경계를 원화에서 직접 잘라 확대한 패치.
- `ostinato_red_compound_eye_albedo.png`: 정면 복안의 녹색 미세 렌즈, 적색 중심 반사와 백색 고광택을 원화에서 직접 잘라 확대한 패치.
- `ostinato_shell_tissue_normal.png`: 원화 갑각 패치의 실제 명암 변화에서 도출한 요철 기준.
- `ostinato_material_roughness.png`: 원화 갑각 패치의 국부 명암 차이에서 도출한 거칠기 기준.

## 시점별 전사 방식

- 정면은 정면 기준 이미지를 최우선으로, 후면은 후면 기준 이미지를 최우선으로 전사한다.
- 측면과 사선은 측면 기준 이미지를 최우선으로 전사한다.
- 현재 모델 자세 때문에 주 기준 이미지의 흰 여백과 겹치는 픽셀은 다른 두 기준 시점의 실제 전경 픽셀로 보완한다.
- 세 기준 시점 모두 전경이 없는 곳만 해당 시점 원화의 조밀한 표면 패치를 대칭 반복해 채운다. 반복은 색을 새로 만들지 않으며 원화 픽셀만 사용한다.
- 현재 FBX 조명은 형상을 읽기 위한 `0.92~1.08` 범위의 약한 명암 보정에만 사용한다.

## 고정 조건과 한계

- 현재 FBX의 형상과 원화의 형상·자세가 서로 다르므로 실루엣과 부품 형태까지 똑같아지는 것은 이 작업 범위에서 불가능하다.
- 이 샘플이 맞추는 대상은 현재 모델에서 표현 가능한 색 분포, 표면 무늬, 명암, 산화, 금속 반사, 복안 질감이다.
- 실제 Unity 적용 전에는 기존 FBX의 UV 또는 정점 기반 부위 마스크를 별도 승인 범위에서 확인해야 한다.
- 모델링·UV·리깅·애니메이션·Unity 런타임 자산은 이번 샘플에서 변경하지 않는다.
