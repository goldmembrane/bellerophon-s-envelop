# 아타 돌파 태세 이펙트 검토 시안

- `Ata_BreakthroughStanceEffect_Preview_v2.png`: 현재 승인 후보인 투명 배경 검토용 시안입니다.
- `Ata_BreakthroughStanceEffect_128px_Review_v2.png`: 머리 위 표시 크기를 고려한 축소 검토본입니다.
- `Ata_BreakthroughStanceEffect_Chroma_v2.png`: 현재 승인 후보의 투명 처리 전 원본입니다.
- 이름에 `v2`가 없는 파일은 크로마키 경계 개선 전 비교본입니다.

- 예정 위치: 기존 수호 태세 이펙트와 같은 아타 머리 위 중앙입니다.

- 현재 상태: 검토 시안이며 Unity에는 연결하지 않았습니다.
