Bellerophon Art Direction Reference Board

상세 구현 이후 1단계 검사용 샘플. 모델링, UI, 애니메이션, 머티리얼, VFX, 사운드 제작 전에 공유할 기준 보드입니다.

이 파일은 검사용 샘플입니다. Unity 씬, 프리팹, 런타임 자산, UI 흐름에는 연결하지 않았습니다. 사용자가 승인한 뒤에만 실제 게임 제작물로 이어질 수 있습니다.

Visual Pillars

Heavy Industrial Ship

낡은 금속, 케이블, 브래킷, 스트랩, 수리 흔적 중심. 깨끗한 고급 SF가 아니라 실제 운송선 같은 표면감.

Navigation Under Stress

어둡지만 길과 상호작용 장치는 읽혀야 함. 방마다 한눈에 구분되는 실루엣과 조명 cue를 둠.

Threat By Signal

위협은 먼저 소리, 깜빡임, 화면 노이즈, 멀리 보이는 실루엣으로 전달. 자세한 텍스처보다 인식 우선.

Functional UI

정산, 수리, 계약, 상점은 반복 조작 도구. 정보 밀도와 숫자 가독성이 장식보다 우선.

Material Targets

Worn Painted Metal

주요 벽/패널. 모서리 벗겨짐, 때, 낮은 채도 도장.

Exposed Dark Metal

프레임, 브래킷, 문턱. 묵직한 구조와 기름때.

Cargo Strap / Rubber

화물칸 정체성. 고정 스트랩, 손잡이, 씰.

Cockpit / Screen Glass

제한적 반사, 오염, 낮은 강도의 화면 glow.

Warning Paint

상호작용, 위험, 통로 방향에만 제한적으로 사용.

Organic Intrusion

씨앗체/외계 생명체 잔재. 배경 금속과 즉시 구분.
