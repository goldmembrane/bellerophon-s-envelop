# artSample

This folder holds user-reviewable samples for art-heavy work before those results are attached to actual game scenes, prefabs, runtime assets, or UI flows.

Current samples:

- `art_direction_reference_board.html`: stage 1 material, lighting, palette, silhouette, and first-slice reference board.
- `ship_interior_modeling_sample.html`: stage 2 ship interior modeling preview for cargo hold, corridors, cockpit, and armory turret station.
- `gameplay_props_equipment_sample.html`: stage 3 gameplay props, first-person equipment, cargo kit, device surfaces, and material variant preview.
- `refs/`: user-provided reference images displayed by the stage 3 sample.

Approval status:

- Stage 1 direction was reviewed and approved by the user on 2026-06-09.
- Stage 2 ship interior modeling sample was reviewed and approved by the user on 2026-06-09.
- Stage 3 gameplay props and equipment sample was reviewed and approved by the user on 2026-06-10.
- Nothing in this folder is attached to the Unity runtime game.
