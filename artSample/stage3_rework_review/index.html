Stage 3 게임플레이 소품 재검수 샘플

현재 씬에 붙은 Stage 3 소품을 전면 교체하기 전에 보는 아트 검수용 샘플입니다. 각 보드는 부품별 클로즈업과 실제 구역 적용 모습을 함께 보여줍니다.

승인 전 검토용입니다. 이 샘플은 현재 Unity 씬, 프리팹, 런타임 자산, UI 흐름에는 새로 연결하지 않았습니다. 2026-06-12 수정본은 통제실 CCTV를 단일 대형 스크린 구조로, 막대기를 빠루형 갈고리 끝단이 있는 양손 무기로 읽히는 길이와 자세로 고쳤습니다.

조종실 조타 장치와 상태 화면

조종실 조타 맵 상태 화면

포함 항목

  • 조종 콘솔 받침대, 기울어진 화면, 수동 출항 준비 상태 화면
  • 조타 기둥, 조타 맵 조각, 좌우 손잡이
  • 상태 화면 받침대와 발광 화면

적용 기준

  • 조종대 상호작용 거리와 1인칭 시야를 가리지 않아야 합니다.
  • 화려한 함교가 아니라 낡고 실용적인 화물선 조종석으로 보여야 합니다.

통제실 단일 대형 CCTV 스크린

통제실 대형 스크린 가로형 보조 스크린 세로형 스크린

포함 항목

  • 벽면 대형 CCTV 스크린 1개
  • 대형 스크린 왼쪽 상단의 가로형 보조 스크린
  • 대형 스크린 오른쪽의 세로형 구역 스크린
  • A/D 전환 버튼과 기능 버튼, 케이블 레일

적용 기준

  • 모니터 여러 개가 나란히 달린 CCTV 뱅크로 만들지 않습니다.
  • CCTV는 대형 스크린 한 장에서 구역을 넘겨 보는 구조여야 합니다.
  • 세로형 스크린은 구역 임시 폐쇄와 내부 정화 시스템 화면으로 이어질 수 있어야 합니다.

동력실 전력 단말

동력실 오버클럭 차단기

포함 항목

  • 단말 캐비닛, 전력 화면, 오버클럭 경고 표시
  • 좌우 차단기와 상단 파이프, 하단 케이블

적용 기준

  • 동력실 벽에 붙어 있는 전력 제어 장치로 보여야 합니다.
  • 경고 표시는 화면 텍스트에 의존하지 않고 색과 형태로 읽혀야 합니다.

비품창고 보관장

비품창고 보관장 슬라이딩 문

포함 항목

  • 보관장 뒤판
  • 슬라이딩 문 1~6
  • 손잡이 1~6

적용 기준

  • 비품창고의 3칸 보관 루프를 시각적으로 뒷받침해야 합니다.
  • 가정용 가구가 아니라 선박용 금속 보관장으로 보여야 합니다.

운송창고 소품과 입출력 단말

운송창고 화물 상태 의뢰 화물 개인 화물

포함 항목

  • 화물 상태 패널, 적재 상태 화면, 고정/과적 표시등, 클램프, 케이블 지지대
  • 의뢰 화물 컨테이너 본체, 프레임, 가로/세로 스트랩, 브래킷, 잠금 태그
  • 개인 화물 컨테이너 본체, 수평 레일, 전면 스트랩, 이름판
  • 화물/비품/무기고 경고 라벨, 다이제틱 단말 받침대와 버튼

적용 기준

  • 기존 Cargo Hold Central Cargo와 상태 상호작용 앵커에 맞아야 합니다.
  • 화물은 직접 집는 물건이 아니라 운송 대상과 상태 오브젝트로 보여야 합니다.

무기실 포탑 손잡이 마운트

무기실 수동 포탑 조작 패드

포함 항목

  • 포탑 손잡이 레일과 회전축
  • 왼쪽 손잡이, 오른쪽 손잡이
  • 조작 패드와 방아쇠 바

적용 기준

  • 손에 드는 총이 아니라 선박 포탑 조작 장치로 보여야 합니다.
  • 상호작용 프롬프트 위치는 포탑 화면 진입 동선을 유지해야 합니다.

1인칭 장비와 양손 막대기

1인칭 막대기 머스켓 방호복 손목 표시 장치

포함 항목

  • 양손으로 잡을 수 있는 긴 막대기 본체, 상하 길이감, 양손 그립 간격
  • 빠루처럼 굽은 갈고리형 프라이 팁, 손잡이 감김, 금속 보강 링
  • 머스켓 참고 형상과 방호복 손목 표시 장치

적용 기준

  • 끝부분은 빠루처럼 갈고리 느낌이 나야 하지만, 전체 비율은 짧은 한손 크로우바가 아니라 양손 막대기로 보여야 합니다.
  • 1인칭 적용 장면에서 두 손으로 들고 위에서 아래로 내려찍을 수 있는 자세가 보여야 합니다.
  • 중앙 조작 시야, 오른쪽 하단 맵, 왼쪽 하단 체력/보호막 영역을 과하게 가리면 안 됩니다.
