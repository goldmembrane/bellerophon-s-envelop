# Shotgun Muzzle Flash V3 아트 샘플

## 목적

현재 Unity의 머스켓식 파티클 구조는 유지하되, 샷건에 맞게 발사 순간의 크기·밝기·압력감·불티 밀도를 크게 강화하기 위한 신규 시각 기준입니다. 이 폴더는 사용자 승인 전 검토용이며 Unity에는 아직 적용하지 않았습니다.

## 최종 시각 방향

- 화면 왼쪽의 작은 백색 지점을 총구 결합 원점으로 사용합니다.
- 원점에는 이전보다 크고 선명한 백색 고온 코어를 둡니다.
- 짧은 거리에서 위·아래로 크게 벌어지는 비대칭 황백색·황금색 압력 부채를 사용합니다.
- 둥근 폭발구 대신 서로 다른 깊이의 얇은 고온 가스층과 갈라진 화염 가지를 겹칩니다.
- 전방에는 고밀도 불티와 화약 입자를 방사형으로 분산합니다.
- 화염 뒤에는 회백색·갈색 화약 연기가 넓고 불규칙하게 말려 나갑니다.
- 길게 이어지는 화염방사기, 로켓 배기, 균일한 삼각형, 단일 평면 카드 형태는 사용하지 않습니다.

## 색채 강화 수정본

- `renders/02_intense_color_shotgun_muzzle_flash_v3.png`에서 실사형 고온 색채와 연기 대비를 확정했습니다.
- `01` 원본의 총구 원점, 부채꼴 윤곽, 크기, 화염 분기, 연기 및 불티 배치는 유지했습니다.
- 백색 고온 코어 주위의 금색·호박색·주황색을 더 선명하고 깊게 만들고, 불티의 발광 대비를 높였습니다.
- 연기는 미세한 결을 유지하면서 짙은 차콜·갈회색으로 조정해 화염이 밝은 배경에 씻겨 보이지 않도록 했습니다.
- 네온·판타지 색채, 붉은 단색화, 새로운 화염구나 형상 추가는 하지 않았습니다.

## 규모·밀도 보강본

- 현재 V3 검토 대상은 `renders/03_spectacular_dense_shotgun_muzzle_flash_v3.png`입니다. 별도 V4가 아니라 V3 샘플의 보강 렌더입니다.
- `02`의 왼쪽 총구 원점, 오른쪽 발사 방향, 흰색→금색·주황색→짙은 연기의 실사형 색채 구조를 유지했습니다.
- 백색 점화 코어와 총구 직후의 상·하 압력 부채를 확대하고, 전방 화염층이 더 긴 구간을 촘촘하게 채우도록 보강했습니다.
- 갈라진 고온 가스와 화염 가지의 수·두께, 차콜·갈회색 화약 연기 덩어리, 외곽 불티와 화약 입자의 밀도를 함께 높였습니다.
- 둥근 폭발구, 화염방사기형 긴 제트, 균일한 삼각형과 평면 카드 형태는 사용하지 않았습니다.

## Unity 적용 전 사전 시각화

- `previsualization/01_v3_unity_mockup.png`는 기존 Unity `Shotgun_Fire` 검토 시트의 캐릭터·샷건·포즈·어두운 배경을 참고하고, 총구에 V3가 재생되는 모습을 합성한 예상 이미지입니다.
- `previsualization/02_v3_unity_previsualization_comparison.png`는 `V3 아트 샘플 / 현재 Unity 참고 / 적용 전 예상 이미지`를 한 장에 배치한 비교본입니다.
- 가운데 패널은 기존 Unity 캡처를 그대로 잘라 붙인 것이 아니라 캡처를 참고해 재구성한 상태이며, 오른쪽도 실제 적용 캡처가 아닌 합성 시각화입니다. 이 사실을 이미지 하단에 직접 표시했습니다.
- 예상 이미지에서는 V3의 백색 코어가 샷건 총열 개구부에 붙고, 총열 축을 따라 큰 화염·연기 부채와 불티가 얼굴을 가리지 않으면서 전방으로 퍼지도록 표현했습니다.
- 이 사전 시각화를 만들면서 Unity 에셋·씬·프리팹·파티클·머티리얼·스크립트는 열거나 변경하지 않았습니다.

## 향후 Unity 재현 기준

- 대상: `CargoRunMvp/PlayerAnimationLayout/Shotgun_Fire`
- 결합: 현재 검출된 샷건 총구 원점과 축
- 시점: 기존 3초 동작 시작 후 `0.15초`
- 방식: 현재 적용된 머스켓식 다층 파티클 구조를 확장하고 FlashCore·HotGas·Smoke·Embers를 서로 다른 깊이·크기·속도로 분리
- 크기 의도: 현재 Unity 발화보다 화면상 확산 폭과 백색 코어를 명확히 키우되, 1인칭 시야 전체를 가리는 독립 폭발은 피함
- 금지: 이 PNG 전체를 단일 또는 교차 평면 카드로 표시하는 방식

## 생성 및 파일 상태

- 생성 방식: Codex 내장 `imagegen` 기본 모드
- 생성·추론 여부: 사용자 요구를 바탕으로 새로 고안한 AI 생성 이미지
- 해상도: `1536×1024`
- PNG 색상 형식: RGB, color type `2`
- 투명 알파: 없음. 생성기가 투명 요청과 달리 밝은 체크 프레젠테이션 배경을 포함했으므로 현재 파일은 시각 승인용으로만 사용합니다.
- 기존 렌더 보존: `01_realistic_shotgun_muzzle_flash_v3.png`와 `02_intense_color_shotgun_muzzle_flash_v3.png`는 변경하지 않았습니다.
- Unity 적용 여부: 미적용
