Shotgun Muzzle Flash V3

현재 머스켓식 입체 파티클 방식은 유지하면서, 샷건에 맞는 크기·광량·압력감·화염·연기·불티 밀도를 크게 보강한 V3 실사형 시각 기준입니다.

사용자 승인 대기 · Unity 미적용

강화한 부분

  • 점화: 크고 선명한 백색 고온 코어
  • 압력: 짧은 거리에서 위·아래로 크게 벌어지는 비대칭 방사형 부채
  • 깊이: 서로 다른 위치와 크기의 얇은 고온 가스·화염층
  • 잔류: 고밀도 불티와 넓게 말리는 회백색 화약 연기
  • 색채: 흰색 코어·금색·호박색·주황색 화염과 짙은 연기의 강한 명암 분리

Unity 재현 원칙

  • Shotgun_Fire의 현재 총구 원점과 `0.15초` 시점 유지
  • FlashCore·HotGas·Smoke·Embers를 별도 파티클로 분해
  • 머스켓보다 넓고 밝되 1인칭 화면 전체를 가리는 독립 폭발은 피함
  • 전체 PNG를 단일·교차 카드로 표시하지 않음

색채 수정 전후 직접 비교

총구 원점, 전체 부채꼴 윤곽, 화염 분기, 연기와 불티 배치는 유지하고 색상 포화도와 국부 대비만 강화했습니다.

V3 규모·밀도 보강 전후

V4를 만든 것이 아니라 V3의 총구 원점과 색채 구조를 유지하면서 백색 코어, 부채꼴 확산 폭, 화염·연기·불티의 가시 질량을 키웠습니다.

Unity 적용 전 예상 비교

Unity를 변경하기 전에 기존 캡처 자료를 참고해 만든 합성 시각화입니다. 가운데는 기존 Unity 캡처 참고 재구성, 오른쪽은 V3 적용 예상 합성이며 실제 Unity 적용본이나 새 캡처가 아닙니다.

이 이미지는 예상 크기·방향·밀도를 검토하기 위한 사전 시각화입니다. 실제 구현 결과는 승인 후 Unity에서 같은 기준 구도로 별도 검증해야 합니다.

현재 Unity 결과 비교

아래 이미지는 현재 적용된 머스켓 방식 Shotgun_Fire입니다. V3는 이 방식의 입체감은 유지하면서 발사 순간의 백색 코어, 확산 폭, 화염 가지와 불티 밀도를 강화하는 목표입니다.

파일 상태

Codex 내장 imagegen으로 기존 V3의 방향과 실사형 색채를 유지하고 규모와 밀도를 보강한 `1536×1024` RGB 검토 이미지입니다. 사용자 승인 전에는 Unity 에셋·씬·프리팹에 연결하지 않습니다.

생성기가 실제 투명 알파 대신 밝은 체크 배경을 포함했습니다. 따라서 현재 PNG는 시각 승인용이며, 승인 후 레이어별 투명 마스크를 별도로 준비해야 합니다.
