적용 원칙

  • 기존 공간실·복도 모델의 메시·Transform·활성 상태를 변경하지 않음
  • 기존 복도 머티리얼만 참조하며 신규 머티리얼·텍스처·문을 만들지 않음
  • 각 접점은 중앙 통행구를 비운 단일 곡면 셸 메시로 생성함
  • 내부 바닥·좌우 벽·천장과 외부 셸은 공통 경계를 사용하며 임시 덧댐·쐐기·앞치마 메시를 만들지 않음
  • 양 끝 가장자리 띠만 원본 경계에 맞닿고 중앙 통행구를 가로지르는 마개 면은 생성하지 않음
  • 추가 메시가 원본 구조를 변형하거나 통행구를 가리지 않음
