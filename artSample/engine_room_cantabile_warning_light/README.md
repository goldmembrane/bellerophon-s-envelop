# 칸타빌레 공명 경고등 샘플

## 목적

이 샘플은 동력실 내부 원통이 칸타빌레와 공명 중일 때, 플레이어가 즉시 위험 상태를 알아볼 수 있도록 천장에 설치되는 경고등을 검토하기 위한 것입니다. 참고 이미지를 기준으로 검은 원통형 베이스와 붉은 투명 돔 렌즈가 있는 형태를 천장 부착 방향으로 재구성했습니다.

## Unity 반영 전제

- 위치: 동력실 천장.
- 기능: ER-20 칸타빌레 공명 상태에서 붉은 점멸 또는 회전광으로 경고를 표시합니다.
- 동력실 내부 원통의 빛이 강해지는 이펙트와 함께 사용합니다.
- 승인 전에는 실제 Unity 씬, 프리팹, 런타임 자산에 연결하지 않습니다.

## 상태 전환

- 평상시: 경고등 렌즈와 내부 코어가 꺼진 상태입니다.
- 칸타빌레 공명 중: 붉은 렌즈, 내부 코어, 아래 방향 경고광이 켜진 상태입니다.

## 형태

- 천장에 붙는 검은 원통형 베이스.
- 베이스 주변 회색/흰색 링과 고정 볼트.
- 아래로 돌출되는 붉은 투명 돔 렌즈.
- 렌즈 내부 발광 코어.
- 공명 활성 상태에서 아래 방향으로 퍼지는 붉은 경고광.

## 승인 기준

- 브라우저에서 `index.html`로 대표 렌더와 여러 구도 렌더를 한 번에 확인할 수 있어야 합니다.
- 샘플은 천장 설치물로 읽혀야 하며, 벽면이나 바닥 장치처럼 보여서는 안 됩니다.
- 공명 경고는 동력실 내부 원통의 빛 강화 이펙트를 보조하는 별도 경고 표시로 보이면 됩니다.
