# 승인 체크

## 샘플 대상

동력실 천장에 설치할 칸타빌레 공명 경고등입니다.

## 승인 후 Unity 반영 방식

- `CargoRunMvp`의 동력실 내부 천장에 배치합니다.
- ER-20 칸타빌레 공명 상태와 연결합니다.
- 평상시에는 꺼진 상태로 두고, 공명 중에는 붉은 점멸/회전광 상태로 전환합니다.
- 기존 동력실 룸 쉘, 스크린, 오버클럭 레버, 손전등 충전기는 건드리지 않습니다.

## 샘플 검토 항목

- `index.html`에서 꺼진 상태와 공명 활성 상태가 한 화면에서 비교되는지 확인합니다.
- 참고 이미지처럼 검은 원통형 베이스와 붉은 투명 돔 렌즈가 읽히는지 확인합니다.
- 천장 패널에 붙어 아래로 돌출된 경고등으로 보이는지 확인합니다.
- 공명 활성 상태에서 붉은 렌즈, 내부 코어, 아래 방향 경고광이 분명히 보이는지 확인합니다.
- Unity 반영 시 동력실 내부 원통 공명 이펙트와 함께 보조 경고 표시로 사용 가능한지 확인합니다.

## 보류된 구현

- 실제 점멸 애니메이션.
- 공명 상태 로직 연결.
- Unity 씬 배치.
- 충돌체와 상호작용 로직.
