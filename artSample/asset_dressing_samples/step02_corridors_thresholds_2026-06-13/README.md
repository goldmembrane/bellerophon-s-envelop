# 이단계 복도와 입구 실제 에셋 적용 시안

이 폴더는 현재 임포트된 에셋 중 복도와 입구에 맞는 후보를 골라, 임시 배치한 뒤 여러 시점에서 렌더링한 검토용 시안입니다. 현재 유니티 씬에 이미 적용된 결과는 기준으로 삼지 않습니다.

이 시안이 승인되기 전에는 같은 구성을 실제 게임 씬, 프리팹, 런타임 자산, 상호작용 흐름에 추가 적용하지 않습니다.

## 적용 방향

- 직선 복도는 완성형 직선 복도 프리팹을 기본 골격으로 사용합니다.
- 꺾이는 구간은 직선 복도 프리팹을 직각으로 맞물리고, 바닥 연결부 후보로 이음새를 덮습니다.
- 빈 벽처럼 보이는 구간은 막힌 벽판 후보를 뒤에 받쳐 투명하게 보이지 않게 합니다.
- 입구는 중앙을 막는 문판이나 통과 가능한 벽처럼 보이는 덩어리를 쓰지 않고, 좌우 기둥과 상단 보강재만 씁니다.
- 바닥 보강판, 낮은 난간, 벽 조명, 천장 조명은 장식과 방향 인지용으로만 얹습니다.
- 충돌체와 이동 경로는 이 시안 단계에서 다루지 않습니다.

## 검토할 부분

- 복도가 비어 보이거나 투명하게 보이지 않는지
- 입구 중앙이 막힌 벽처럼 보이지 않는지
- 통로 폭과 시야가 답답하지 않은지
- 바닥, 벽, 천장, 입구 장식이 한 배 안의 부품처럼 보이는지
- 꺾이는 구간의 연결부가 뒤틀리거나 튀어나와 보이지 않는지
