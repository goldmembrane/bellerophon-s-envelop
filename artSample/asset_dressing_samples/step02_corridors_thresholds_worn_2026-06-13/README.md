# 이단계 복도와 입구 낡은 버전 시안

이 폴더는 기존 이단계 복도 시안과 같은 에셋 후보를 사용하되, 더 낡고 거친 화물선 내부처럼 보이도록 변형한 검토용 시안입니다. 실제 유니티 씬에는 아직 적용하지 않았습니다.

이 시안이 승인되기 전에는 같은 구성을 실제 게임 씬, 프리팹, 런타임 자산, 상호작용 흐름에 추가 적용하지 않습니다.

## 변형 방향

- 원본 에셋 프리팹은 직접 수정하지 않습니다.
- 프로젝트 안에서 복제한 낡은 금속 머티리얼을 임시로 입힙니다.
- 바닥에는 때, 녹, 긁힘, 흐려진 경고 띠를 추가합니다.
- 벽과 입구 기둥에는 녹 자국, 검은 그을음, 벗겨진 모서리를 추가합니다.
- 천장에는 어두운 먼지 띠와 약한 조명 얼룩을 넣습니다.
- 조명은 깨끗한 새 조명보다 어둡고 탁하게 보이도록 낮춥니다.
- 통로 중앙과 입구 중앙은 막지 않습니다.

## 검토할 부분

- 기존 시안보다 새것 같은 느낌이 충분히 줄었는지
- 녹과 때가 과하지 않고 화물선 내부처럼 보이는지
- 통로가 더럽게 보이더라도 이동 공간이 막힌 것처럼 보이지 않는지
- 입구 기둥과 바닥 보강판의 마모가 읽히는지
- 어두운 분위기가 시야를 너무 죽이지 않는지

현재 상태는 미승인입니다. 사용자가 명시적으로 승인하기 전에는 이 시안을 유니티 런타임 결과물에 반영하지 않습니다.
