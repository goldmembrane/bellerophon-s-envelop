ShipRepair 앞 작업점 · 용접 이펙트

전체 배치

효과 중심은 양손 사이의 몸통 앞 작업점에 있으며 캐릭터 실루엣을 크게 가리지 않습니다.

작업점 확대

청백색 중심 아크와 얇은 청색 전기광, 주황색 하강 스파크, 중심 근처의 짧고 옅은 연기만 사용합니다.

고정 조건

  • 진행 바는 두 개체에 개별로 생성하며 각각 자신의 머리 위치를 추종합니다.
  • 진행값은 개체별 실제 수리 진행률을 사용하며 샘플은 두 개체 모두 50%입니다.
  • 용접 이펙트는 ShipRepair의 앞 작업점에만 표시하고 SabotageRepair에는 적용하지 않습니다.
  • 수송자 모델, 리깅, 애니메이션, 메시, 머티리얼과 자세는 변경하지 않습니다.
  • 대형 폭발, 화염구, 과도한 연기, 화면 전체 플래시와 추가 장비는 포함하지 않습니다.

제작 및 적용 경계

진행 바는 현재 Unity 검증 이미지에서 ShipRepair와 SabotageRepair를 같은 크기로 분리한 뒤, 50% 수치를 픽셀 단위로 고정해 합성했습니다.

용접 이펙트는 내장 이미지 생성 도구로 투명 배경 VFX 레이어만 생성하고, 이를 원본 ShipRepair Unity 이미지 위에 별도로 합성했습니다. 따라서 최종 샘플의 수송자 픽셀과 자세는 원본과 동일하며 생성된 부분은 용접 광원·스파크·연기 레이어뿐입니다.

이 폴더는 시각 승인용 아트 샘플입니다. Unity 씬·프리팹·런타임 UI·VFX 자산에는 아직 연결하지 않았습니다.
